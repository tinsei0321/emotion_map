1. **演示逻辑链（最高优先级）**：张力图面 → 引导点击突出要素 → 交互分析 → 定位关注区 + 主题倾向 + 排序优先级（宏观诊断信号，非精确识别）。三环=表现力（张力图面）/有用性（宏观定位+排序）/交互（点击→归因）。**视野-数据-结论三端同步**（hover/click 即时联动）。UI/UX 表现力 = 与架构/代码同等的承重维度。
2. **项目设计哲学**：4×5 归因 = 宏观主题倾向矩阵（多归属，非指标清单）；归因底层逻辑 = 政策→情绪→项目方向性锚；**空间落位口径铁律 7**（体检数据第一性落位 = 4 维度控件对象[城区/街区/小区/住房]，**片区/重点片区 = 结论**由问题聚集推导而来，禁把片区当输入口径）；**铁律 13 禁非专业概念创造**（分类术语须源文档可溯，无则罗列事实不造词）。
3. **AI·Copilot 内核（三支柱）**：Smart Agent（两端·理解+表达）+ Dumb Tool（中间·纯执行不推理）+ Orchestrator（确定性编排不调 LLM）。**纯回答稳定性 = 本地知识库完备度 + EMC 架构（分类→范式映射）+ LLM 归纳总结**，三者缺一不可，任何方案不得砍任一支柱。
4. **出口抽象层三铁律（立项根本目标）**：① EMC 找市场接口（结果能填进行业哪张表/指标/任务板块）② 三段式线性（意图→结果→成果范式，禁一竿子到底）③ 定性+定量+地理按尺度。软指标可信性缺口 = 情绪地图填补的切入点。
