### "43423" 研究路径（修编 0809·最新方法论）

```
"4" 四个以：安全韧性为底线 / 人民需求为目标 / 经济平衡为动力 / 片区化实施为路径
"3" 三张清单：体检问题清单 + 潜力资源清单 + 更新动力清单 → 明确任务与重点区域
"4" 四类分类指引：围绕重点区域划更新片区 → 4 类分类
"2" 两类项目：必须干 / 谋划干
"3" 三类机制：规划传导 / 规划衔接 / 项目库动态维护
```
