## 归纳总结（核心方法论）

### 一、规划背景
- **国家战略**：城市发展由外延扩张转向**存量提质**阶段，城市更新进入**法定化、系统化**新阶段
- **省部要求**：湖北省推动「更新提质和精明增长」转型；住建部明确**更新专项规划 + 片区策划 + 项目实施方案**三级体系（编制导则）
- **宜昌需求**：国家城市更新试点城市，更新项目需统领性规划支撑

### 二、更新问题点（三大痛点）
1. 投入产出失衡·更新动力不够
2. 点状更新为主·缺乏片区统筹
3. 体制机制处于探索阶段

### 三、研究着力点
1. 厘清更新任务（以安全、民生为重点）
2. 明确更新重点（划定更新片区提出指引）
3. 确保更新实施（项目库 + 更新实施机制）

### ★ 四、总体思路 + "43423" 研究路径（核心）
**总体思路**：以人民为中心，秉持民生逻辑/需求逻辑/运营逻辑三大导向，以**安全韧性为底线、人民需求为目标、经济平衡为动力、片区化实施为路径**。

**"43423" 路径**：
- **"4"** 四个以：安全韧性为底线 / 人民需求为目标 / 经济平衡为动力 / 片区化实施为路径
- **"3"** 三张清单：体检问题清单 / 潜力资源清单 / 更新动力清单 → 明确任务与重点区域
- **"4"** 四类分类指引：围绕重点区域划定更新片区 → 4 类分类指引
- **"2"** 两类项目清单：必须干 / 谋划干
- **"3"** 三类机制创新：规划传导机制 / 规划衔接机制 / 项目库动态维护机制

### 五、三张清单
- **潜力资源清单**：8 类要素资源（危旧房/老旧小区/城中村/低效楼宇/闲置地/老旧街区/老旧厂区/老旧基础设施）分类潜力评价（高/低）
- **体检问题清单**：2025/2026 体检·安全韧性底线 + 民生基础需求空间落位
- **更新动力清单**：城市重点发展方向 + 资金重点投向（国家工程/单项目超 5 亿）

**重点区域**（三张清单叠加）：葛洲坝西坝区域 / 环三峡大学区域 / 老城中心区域

### 六、更新重点
- **23 个更新片区**（0.5-3 平方公里·潜力要素聚集/临江临湖高价值优先/主体想做且项目成熟）：
  龙园文旅片区 / 建设路片区 / 下西坝文旅片区 / 镇镜山片区 / 夜明珠建材市场片区 / 沙河公…
- **四大片区类型**：
  1. **功能活力焕新**（老旧商圈/文旅核心/零星工业转型·激活存量·集聚商气人气）
  2. **宜居品质提质**（居住短板补齐·房屋安全/公共服务补位/环境微改造·完整社区配套）
  3. **产业迭代升级**（存量产业腾笼换鸟·园区转型升级·培育新业态）
  4. **历史街区活化**（保护优先/活态利用·传承文脉·兼顾民生与文旅）

### 七、更新实施
- **项目库**：重点更新片区内必须干 + 安全韧性底线/民生基础保障必须干 + 其余储备干 → 两类（必须干/储备干）
- **实施机制**：① 更新规划-片区策划-项目实施方案传导 ② 与国土空间规划体系联动 ③ 项目动态维护更新 ④ 资金争取
