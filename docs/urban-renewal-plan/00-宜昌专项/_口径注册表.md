# 口径契约注册表（需求契约卡·首批）

> **定位**：口径与数据治理的**单一权威契约源**（文件名下划线=不进 RAG·治理台账）。检索命中本表即权威；与本表冲突的任何数字按作废/待裁处理。
> **性质**：需求契约卡（PT-CB4 T2·2026-08-19 主手主笔）——**契约=资产·数据内容=耗材**（R22 纪律）：本表登记的是算法规格/适用边界/枚举语义/规则，不是数据行。
> **卡片格式（元契约）**：每张卡必含——`卡ID / 业务名 / 定义（算法规格） / 适用 / 禁用 / 值锚点（引用成文出处·不内联数据） / 状态 / 来源 / 变更`。缺任一字段=不合格卡。
> 状态枚举：`current`（现行）/ `superseded`（被明确替代·留档）/ `作废`（禁用·检索命中须引本表声明）。
