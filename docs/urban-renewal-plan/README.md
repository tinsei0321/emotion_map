## 四、提炼纪律（防张冠李戴·用户硬要求）

- **每份资料固定 13 字段**（见 `_提炼模板.md`）：完整名称/文号/机构/城市/时段/版本状态/采集状态/来源/位置/参考位置/指标数据/归纳/EMC 对应
- **适用城市精确标注**（国家/湖北/宜昌/杭州/上海…）——不同城市方法指标严格一一对应，禁混用
- **版本状态必标**（正式/试行/征求意见/修编中/已到期）——防把草案当定稿
- **指标数值带来源+年度**（如"42 栋=结构隐患·2025 体检附件1"）——防张冠李戴
- **GIS 图层 ↔ 附件数值**一一对应（`_INDEX` 反查）
- 原始资料**只读不移动**；`_raw/` 只放下载副本
