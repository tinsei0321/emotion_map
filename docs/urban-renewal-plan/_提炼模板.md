# 提炼笔记统一模板（13 字段）

> **用途**：三组（claude/codex/glm）读 G 盘资料后产出的每份文件提炼笔记统一格式。
> **纪律**：适用城市/版本状态/指标数据/来源 必填，防张冠李戴。
> **存放**：`docs/urban-renewal-plan/_笔记/{组名}_{目录}_{日期}.md`

---

## 模板

```markdown
## {编号} · {完整名称}

| 字段 | 内容 |
|---|---|
| **完整名称** | {含文号/年份的完整文件名} |
| **文号** | {如 建科〔2023〕63号 / 无} |
| **发布机构** | {住建部/中办国办/湖北省住建厅/宜昌市住新局/杭州市建委…} |
| **适用层级-城市** | {国家 / 湖北省 / 宜昌市 / 杭州市 / 上海市…} |
| **适用时段** | {2025-2030 / 长期有效 / 2021-2025（已到期）…} |
| **版本状态** | {正式发布 / 试行 / 征求意见稿 / 修编中 / 草案 / 已到期} |
| **采集状态** | {原文已下载 / 仅链接+摘要 / 待核实 / OCR} |
| **来源链接** | {官网 URL / 无（G 盘本地文件）} |
| **本地位置** | `{URENEWAL_ROOT}/…{相对路径}`（禁 G:\ 绝对路径） |
| **参考位置** | {章节 X / 第 X 页 / 指标 N} |
| **指标数据** | {数值/标准/分档·如 泊车比 1.11·带年度·无则"—"} |
| **归纳总结** | {关键条款/机制/要点·3-8 行} |
| **EMC 对应** | {domain_key + element + outlet 契约·若适用·否则"—"} |
```

## JPG 识图笔记（glm 专用·额外 2 字段）

在模板上追加：

```markdown
| **识图质量** | {清晰 / 部分模糊 / 难辨（底部乱码标注）} |
| **原始出处** | {IMG_20250704_080440.jpg·时间戳} |
```

## GIS 图层笔记（claude 专用·额外字段）

```markdown
| **图层对应** | {图层名/维度/指标·如 车位缺口@小区维度↔附件3} |
| **GIS 路径** | `{URENEWAL_ROOT}/1 宜昌市城市体检/3_gis数据/…gdb/图层` |
```

## 规模控制（三层筛选·三组一致）

| 层 | 范围 | 笔记深度 |
|---|---|---|
| **全量登记** | 875 文件每行入 `_INDEX` | 13 字段 + 文件大小/格式（机械可并行） |
| **核心深提炼 ~30 份** | 部委 7 + 湖北 4 + 宜昌体检 3报告/6附件 + 杭州 3 + 沪穗京蓉各 1-2 | 每份 300-800 字 |
| **指标数值入库** | 附件 1/2/3/4/5 数值 | L0 提炼笔记表（供出向层引用） |
