## 一 白话摘要（零术语）

**壳，就是情绪地图门诊大厅。**

用户来"问诊"（问区域情绪、做空间分析），壳负责：叫号（收问题）、记录过程（工具在干什么）、转科室（调数据工具）、最后把"体检报告"交回用户（图+数+建议）。壳本身**不看病**——看病的是"医生团队"（引擎/大脑）。

**三个保障**（盖这栋门诊大厅时立的三条承诺）：

1. **换脑**：医生团队可以整个换掉（今天内置轻循环引擎，以后可换 dsh、换 Codex），**大厅不用翻修**——壳只认"叫号单格式"（ACP 事件流），不认具体哪位医生。
2. **同等质量**：换医生不许降诊疗水平——每个新医生上岗要过"质检"（事件格式校验器）+ 同题对照考核（10 题两医生对答案）。
3. **流式**：医生要**边想边说**（思考过程实时可见）；真不会流式的"代班医生"必须**明说自己是模拟进度**，不许把动画装成真思考。

**当前状态**：大厅已翻新（事件化改造完成）· 第一支医生团队已上岗（轻循环引擎发射层落地）· 前台小件齐了（追问建议条/事件质检/出厂自检）· 今天挂上这张"科室导览牌"（本卡）· 预留了"新增科室位"（垂直域切换位，S9）。

## 五 垂直域切换位（S9 · 只预留不实现）

平台化终局 = 平台层（共享不变量）× N 个 Vertical Profile（**六件套**）：

数据包 / 知识库（**分两槽**：语料槽=向量·范式槽=prompt 结构化知识）/ 口径注册表 / 身份卡 / 工具预设（**切换位第一清偿对象**——默认参数现散落 mcp_server_emc.py）/ 渲染预设（受管色带词表垂域子集·禁自带色值）。
