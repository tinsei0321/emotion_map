## 一、followup_cue 契约（追问接话）

### 1.1 两级结构（schema 冻结）

```jsonc
// 参数级 cue（确定性派生规则可写：top_n±/by 翻转/boundary 切换/同链相邻工具）
{
  "cue_text": "那第 8 个呢？（top_n 7→8 重跑）",
  "tool": "rank",
  "params": {"boundary": "base_community_area", "layer": "subj_12345_safety_community_point",
             "top_n": 8, "by": "worst", "sort_by": "point_count"}   // resolved_params：完整可执行参数集·幂等自包含·不依赖历史
}
// 提示级 cue（跨工具建议·不强行推断参数）
{"cue_text": "想换成方格分布图看看吗？（可用 grid_aggregate）"}
```

- **params 必须完整**（resolved_params）：派生时从本轮调用参数复制+改一处，禁止只存增量（增量=把会话状态耦合进重放路径）；
- 派生零 LLM（与 rag_query 的 `_derive_followup_cues` 同谱系）；
- 每工具输出 `followup_cues` ≤3 条·价值序。

### 1.2 续接路由与验收

- 路由决策在宿主；EMC 侧保证 cue 机读。前端胶囊一键重放=跳过 LLM 直接按 params 调工具（机读结构的第一消费方）；
- **验收**：续问第二轮工具调用 ≤1 次重跑（参数增量级·不重跑 list_data→zonal→rank 全链）。

### 1.3 接口锁版本化路径（rag_query 专项）

- rag_query 为 G4 接口锁覆盖工具：现有 `followup_cues`（纯文本数组）**保留一个版本周期**；
- 新结构以**新键名 `followup_actions`** 并存（对象数组·两级 schema）；
- 过渡期后旧键退役须走 CB 裁决+消费方清零确认。

## 二、选择请示契约（关键分支）

### 2.1 与缺槽 ask 的划界（冻结）

| 类型 | 既有「缺槽 ask」（信息不足/失败恢复） | 本机制「分支 ask」（双解合法需定夺） |
|---|---|---|
| 触发 | 缺必填参数/链中断/可恢复失败 | ①不可逆分支（正例：render_file >60 自动登记写 manifest）②两解合法且成本差大 ③口径分叉（如 130 vs 193） |
| 规则 | 沿用现状（harness `_missingSlotAsk`/失败恢复） | 单轮 ≤1 次硬选择 + 跨轮累积预算（引 `_consecutiveAsks` 基座） |
| 混用禁令 | 分支 ask 不得用于补槽（补槽走缺槽规则）；缺槽 ask 不得用于定夺分支 |  |

### 2.2 预算耗尽=告知式软降级（文案冻结）

> 「这个分支我替你选了 **X**——依据是 **Y**（一句话）。如果想换，直接说『换成 Z』即可。」

- 预算：单轮 ≤1 硬选择；跨轮连续 ≥2 次后不再 ask（既有 `_consecutiveAsks` 基座）→ 降级为告知式；
- 研究档多次请示归 plan 模式（方案一次性打包审批）；plan 未排期前各档统一 ≤1；
- 触发清单与划界表双写：人设文本 + 相关工具描述（D-c 纪律）。

## 三、规模分级契约（scale）

### 3.1 枚举与第一保险

`scale ∈ {brief, analysis, research}`；入口档位定默认（快分析档默认 brief）。

### 3.2 确定性倒推判据表（第二保险·冻结）

由工具调用行为**确定性倒推**实际规模，与入口声明比对（零 LLM·引擎无关）：

| 倒推信号 | brief | analysis | research |
|---|---|---|---|
| 单轮工具调用数 | ≤2 | 3-6 | >6（或含方案输出） |
| 跨工具链长度（不同工具种数） | ≤2（list_data+一件分析为典型 brief 链·实测校准） | 3-4 | ≥5 |
| 估算耗时 | <60s | 60-180s | >180s |

- 判对=声明与倒推一致 → **静默**；判错（如声明 brief 实际倒推 analysis/research）→ 一条结构化注记进对话流（不打断不新开 UI）：「本次实际调用了 N 件工具（约 X 秒），规模接近 analysis——若需更快可收窄问题，若需更深可转研究档」；
- **scale 不跨档改预算**：快档 15 步硬顶不因声明放宽；作用域=防降级滥用+快档诚实提示；
- 落点：出口卡链路（确定性组装）挂 `scale_check` 字段。
