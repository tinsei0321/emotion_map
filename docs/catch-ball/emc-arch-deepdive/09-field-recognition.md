## 一、定位

> Diagnose Agent Stage 1。纯规则·本地 JS·<100ms。不调 LLM。

## 二、流程

```
可见图层的字段列表
  → resolveRole() → 字段角色集合
  → FIELD_TO_TOOLS 映射 → 工具候选集（取并集）
  → GEOMETRY_TOOLS 几何过滤（取交集）
  → NL 关键词累积匹配（取并集）
  → 候选集:
      = 0 → 短路·提示导入数据
      = 1-4 → 交 Flash 填卡
      ≥ 5 → 触发追问（6 场景预写模板）
```

## 三、追问场景

| 场景 | 触发条件 | 示例 |
|:---:|------|------|
| 1 | 全为分析类（density/hotspot/zonal/rank/compare） | "你想从哪个角度分析？" |
| 2 | 全为空间操作（clip/buffer/overlay/merge/extract/filter） | "你想对数据做什么处理？" |
| 3 | 分析+空间操作混合 | "你想直接分析，还是先做数据处理？" |
| 4 | 分析为主+统计（area_stats/nearest） | "你想看分析结果，还是做统计？" |
| 5 | 仅 density（analysis 维度分歧） | "你想看综合分布，还是看特定情绪？" |
| 6 | 兜底·无关键词+字段丰富 | "数据挺丰富的，你想从哪个方面开始？" |

- 追问文案和选项预写·不调 LLM
- 选项动态生成·只列实际候选工具
- 纯中文 + 英文专业术语
