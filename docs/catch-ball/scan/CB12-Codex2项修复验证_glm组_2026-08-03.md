### ⚠️ 既存 limitation（P2·非 3abb503 引入）

`_GEO_TOOLS`（`harness.js:806`）不含 `density`：
```javascript
const _GEO_TOOLS = ['extract_feature','overlay','clip','filter_attr','merge',
  'buffer','zonal_stats','rank','area_stats','nearest','hotspot','ensure_zone'];
// density 不在列表（前端委托工具·非 /geo/ 后端调用）
```

**影响**：多步计划含 density（如"先裁剪再热力图" method=`['clip()','density()']`）→ `_plannedGeoSteps` 只计 clip（plan=1）→ clip 执行后 exec=1 → 1≤1 早停 → density 步被截断。

**但这不是 3abb503 引入**——density 从 `_GEO_TOOLS` 创建起就不在列表。3abb503 的计划完成度守卫对**所有 GEO_TOOLS 内的多步组合**（clip+overlay / clip+zonal / extract+merge 等）**正确生效**——只对含 density 的组合有盲区。

**建议**（P2·不阻塞 B3）：`_GEO_TOOLS` 补 `'density'`（density 在 while-loop 中通过 `TOOLS['density']` 执行·toolHistory 记录 `动作: density(...)` → `_executedGeoSteps` 能匹配）。

```javascript
// 建议
const _GEO_TOOLS = [..., 'ensure_zone', 'density'];
```
