## 第一节：5 环节逐项核验

### ① _extract_emc_value 统一收 rows/features：✅ 正确

**实测代码**（build_outlet_schema.py:78-104）：
```python
def _extract_emc_value(result, emc_field):
    if not result or not isinstance(result, dict): return None
    if emc_field in result: return result[emc_field]           # 1. 顶层 dict（统计型）
    rows = result.get('rows')
    if isinstance(rows, list) and rows:
        feats = [{'properties': r} for r in rows if isinstance(r, dict)]  # 2. rows 型
    else:
        feats = result.get('features') or []                    # 3. features 型
        if isinstance(feats, list):
            feats = [f if 'properties' in f else {'properties': f} for f in feats]
    if not feats: return None
    p = feats[0].get('properties', {})                          # Top-1 取值
    return p.get(emc_field) if isinstance(p, dict) else None
```

**三级兜底顺序核验**：顶层 dict → rows → features——**合理**。顶层优先保证统计型 result（如 `{polarity_index: -0.3}`）直接命中；rows 和 features 互斥（有 rows 不查 features）。

**既有 features 用例是否破坏？** 不破坏。单测 15 passed（含既有 features 型 + 新增 rows 型）。features 兜底逻辑（:96-97）兼容裸 dict 和 {properties:{}} 两种结构。

**Top-1 取值合理性**：rows[0] = 按 |polarity_index| 降序的首行（geo_routes.py:367-370 已排序）= 最消极/最优先单元。对 renewal_object_identify（识别最需更新片区）语义正确。

### ② _lastToolRows 缓存×3 + 门放宽：⚠️ 2 对 1 缺陷（P1 bug）

**三路径缓存核验**：

| 路径 | 位置 | 缓存写法 | hasRows 判定 | 守护条件 | 判定 |
|---|---|---|---|---|---|
| runTemplatePath | :559 | `if (...rows.length) _lastToolRows = ...` | :574 独立 `hasRows` | :575 `newLayerCount===0 && !hasRows` | ✅ 正确 |
| runChainPath | :757 | `if (...rows.length) _lastToolRows = ...` | :758 独立 `hasRows` | :764 `newLayerCount===0 && !hasRows` | ✅ 正确 |
| **runAllToolCalls** | :1868 | `if (...rows.length) _lastToolRows = ...` **`else failedSteps.push`** | ❌ **无 hasRows** | :1875 `if (newLayerCount===0)` **漏 hasRows** | 🔴 **缺陷** |

**🔴 P1 bug 详情（runAllToolCalls:1867-1869 + 1875）**：

```js
// :1867-1869（当前·有缺陷）
if (r && r.data && r.data.layerId) newLayerCount++;
if (r && r.data && Array.isArray(r.data.rows) && r.data.rows.length) _lastToolRows = r.data.rows;
else failedSteps.push(i + 1);   // ← else 挂在 rows 缓存的 if 上！rows 型工具无 layerId → else 触发 → 误判失败

// :1875（当前·漏 hasRows）
if (newLayerCount === 0) {   // ← rows 型 macro 分析无 layerId → newLayerCount=0 → 走降级"均未产出新图层"
  ...return { degraded: true, skipped: 'multi-zero' ...}
}
```

**后果**：macro 多步链（如 FC 选 multi 走 runAllToolCalls 执行 zonal→rank）场景下：
1. zonal/rank 成功返回 rows（无 layerId）→ rows 被缓存 ✅ → 但 else 触发 `failedSteps.push` 🔴 **成功被误判失败**
2. 链结束 newLayerCount=0（rows 型无图层）→ :1875 守护拦截 → 走降级"均未产出新图层" 🔴 **不出正常结论 + 出口卡不触发**（降级路径不走 _maybeBuildOutletCard）

**对比正确写法**（runChainPath:756-758 + 764）：
```js
if (r && r.data && r.data.layerId) newLayerCount++;
if (r && r.data && Array.isArray(r.data.rows) && r.data.rows.length) _lastToolRows = r.data.rows;
if (r && r.data && Array.isArray(r.data.rows) && r.data.rows.length) hasRows = true;  // ← 独立 hasRows
// 守护：
if (failedObs.length || (newLayerCount === 0 && !hasRows)) { ... }  // ← hasRows 放行
```

**修复建议**（对齐 runChainPath）：
```js
// :1867-1869 改为三独立 if（去 else）
if (r && r.data && r.data.layerId) newLayerCount++;
if (r && r.data && Array.isArray(r.data.rows) && r.data.rows.length) _lastToolRows = r.data.rows;
if (r && r.data && Array.isArray(r.data.rows) && r.data.rows.length) hasRows = true;
else if (!(r && r.data && r.data.layerId)) failedSteps.push(i + 1);  // 仅真无产出（无图层无 rows）才失败

// :1875 守护加 hasRows
if (newLayerCount === 0 && !hasRows) { ...降级... }
```

**影响范围**：
- **单步 macro 场景**（FC 选 zonal/rank single 走 runTemplatePath）：**不受影响** ✅（runTemplatePath 正确）
- **多步 macro 链**（FC 选 multi 走 runAllToolCalls）：**受影响** 🔴（rows 误判失败 + 降级）

**严重程度**：交接卡核心场景"各行政区更新优先级排序"若走 single（zonal single）则可用；若 FC 判 multi（如先 zonal 再 rank）则撞此 bug。**取决于 FC 选型**——非确定性触发，但 macro 多步链是合理路径，建议修。

**门放宽核验**（_maybeBuildOutletCard:1577-1578）：
```js
const _hasRows = !!(Array.isArray(_lastToolRows) && _lastToolRows.length);
if (!_hasRows && newLayerCount <= 0) return null;   // 空 rows 不出卡·防空卡 ✅
```
✅ 门放宽正确——「rows 非空 ∨ newLayerCount>0」放行，空 rows 不出卡。**但前提是 _lastToolRows 被正确缓存**（runAllToolCalls 路径虽缓存了，但降级路径根本走不到 _maybeBuildOutletCard）。
