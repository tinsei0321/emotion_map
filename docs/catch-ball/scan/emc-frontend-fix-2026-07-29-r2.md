## 二、本轮回合修复清单

### Fix 1 · 回到底部按钮（B009）

| | 之前 | 之后 |
|------|------|------|
| **位置** | 右下角 sticky `bottom:8px` | 右上角 sticky `top:8px` |
| **背景** | 深绿填充 `#143a35`·白字 | 透明磨砂 `rgba(255,255,255,0.88)`·绿字·细绿边框 |
| **文本** | `回到底部 ↓`（6 字） | `↓`（1 字） |
| **阴影** | `0 4px 14px` 深影 | `0 1px 6px` 浅影 |
| **动画** | 从下往上淡入 | 从上往下淡入 |

**设计决策**：
- 右上角——不遮挡输入框/胶囊区
- 透明磨砂——低调不抢眼，仅提示可操作
- 单箭头——极简传达"往下滚"语义

**文件**：`ai_qa.css` L430-447，`panel.js` L1793

### Fix 3 · L2·e2e 图层命名（B010）

**根因**：`e2e-seam.js` `loadPoints()` 硬编码组名 `'L2 · e2e'`。飞轮运行时该名称暴露在 Layers 面板，用户困惑其来源。

**修复**：`'L2 · e2e'` → `'测试数据 · 情绪点'`

**文件**：`e2e-seam.js` L55

### Fix 4 · 行政区图层堆叠（B011）

**根因**：`e2e-seam.js` `loadRange()` 每例飞轮测试直接 `addLayer`，无去重检查。25 例 FC全链路测试中多次调用 `loadRange('行政区')` → 堆叠多个同名「行政区」面层。

**修复**：在 `addLayer` 前加检查：
```javascript
if (getLayers().some((l) => l.kind === 'polygon' && l.srcName === 'e2e_range' && l.name === label)) {
  return { ok: true, count: 0, reused: true };
}
```

**文件**：`e2e-seam.js` L134-137
