try:

### ② + 多字段合成：✅ 正确

**实测代码**（build_outlet_schema.py:149-160）：
```python
_expr_clean = _re.sub(r'\[scale=[a-z]+\]', '', str(emc_expr))
_field_parts = [_re.split(r'\s*(?:降序|占比|排序|负数|正数|TOP\d+)', p)[0].split('（')[0].split('/')[0].strip()
                for p in _expr_clean.split('+')]       # + 分隔·每段独立 qualifier 解析
_field_parts = [p for p in _field_parts if p and p not in ('图层', '评论')]
if _field_parts:
    _vals = [str(_extract_emc_value(result, p)) for p in _field_parts if _extract_emc_value(result, p) is not None]  # 逐字段取·空值跳过
    if _vals:
        card['fields'][industry_field] = {'value': '、'.join(_vals), ...}   # 非空 join
    else:
        card['fields'][industry_field] = {'value': '暂无数据', ...}
```

**核验**：
| 特性 | 实现 | 判定 |
|---|---|---|
| 逐字段取 | `for p in _field_parts` 每段独立 `_extract_emc_value` | ✅ |
| 非空 join | `_vals` 只收集非 None·`'、'.join(_vals)` | ✅ |
| 空值跳过 | `if _extract_emc_value(result, p) is not None` | ✅ |
| qualifier 后缀解析 | 每段独立 `_re.split(降序\|占比\|...)` | ✅ 保留 |
| 既有单字段用例 | 无 + 的表达式·`split('+')` 返回单元素列表·逻辑等价 | ✅ 不破坏 |

**source 标注**（:158）：`'、'.join(f'{p}（确定性）' for p in _field_parts)`——但这里 `_field_parts` 是**全部 parts**（含空值跳过的）·而 `_vals` 是非空子集。**轻微瑕疵**：source 列了所有 parts（含取空跳过的）·value 只 join 非空。若 field_mapping = `'a + b + c'`·b 取空·则 value='a、c' 但 source='a（确定性）、b（确定性）、c（确定性）'——**source 多列了 b**。非阻塞（source 是审计字段·非用户可见）·但 P2 可优化（source 也只列非空 parts）。
