## 一、early-stop 计划完成度修复（`harness.js:1215-1223`）

### 正确部分（agree）

- `_planned = _plannedGeoSteps(diagnose.method)` / `_executed = _executedGeoSteps(toolHistory)`；
- 已知计划场景：单步问（method=[clip()]·planned=1·executed=1 → 停 ✓）；多步问（method=[clip(), density()]·第 1 步后 planned=2 > executed=1 → **不停·续轮** ✓）——与定向验证一致。

### 边界缺陷（partial）

- **degraded-FC 路径：`method` 为空 → planned=0**。`_plannedGeoSteps(undefined)` = 0（`(method || '')` → 空串 → 0）；while-loop 第 1 轮 LLM 产层 → `0 <= 1` → **早停**；
- **后果**：FC 失败（recover 未命中）→ while-loop 的多步问句（如"先裁剪西陵区情绪点，再生成热力图"）仍会在第 1 步产层后被截断——**"只做一半"在 degraded 路径残留**（定向验证只覆盖了 FC 成功+method 填充的场景）；
- **修复**：`if (_planned > 0 && _planned <= _executed)`——**计划已知且执行完才早停**；planned=0（计划未知）时**不早停**，交给 while-loop 自然结束（LLM 自主 answer）。代价：degraded 单步问不再早停（慢一点·正确性优先）。
