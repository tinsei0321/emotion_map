### 0.3 sjoin 性能基线（glm组 独立）

现有 `aggregate_by_polygons`（spatial_analysis.py:230）已用 `gpd.sjoin(points_gdf, polygons_gdf, predicate='within')`——这是**点×面** sjoin（点在哪个面）。草案①要加**格×POI** sjoin（POI 在哪个格）——是**第二次 sjoin**（同一次聚合里跑两次）。

geopandas sjoin 默认用 rtree/STRtree 空间索引（若装了 rtree/pygeos）。3220 POI × N 格的 sjoin：
- 有空间索引：O(N + M + k)（k=匹配对数）·3220×100 格 ≈ 毫秒级·可接受
- 无空间索引（rtree 未装）：O(N×M) 暴力遍历·3220×100 ≈ 32 万次 contains·秒级·**性能风险**

**建议**：实施时 `pip list | grep -i rtree` 确认 rtree 已装（geopandas sjoin 依赖）。若未装·sjoin 会 fallback 暴力遍历·需在 requirements.txt 补 rtree。

## 第一部分：7 问独立判断

### 1. place_name 双源融合：✅ 方向对

**草案**：聚合时对每格 sjoin 格×POI → 格内 POI 清单 → place_name = 格内最高频 POI 名称（sjoin 优先）→ fallback spatial_hotspot 众数 → fallback area_seed 众数。

**glm组 判断：方向正确，保旧 sim 兼容合理。**

**逻辑核验**：
- sjoin POI 优先：治 glm 致命发现（真实数据无 spatial_hotspot 标注 → place_name 恒空）·sjoin 给真实 POI 名称。✅
- fallback spatial_hotspot：保旧 sim 数据兼容（带标注的旧数据仍用原逻辑）。✅
- fallback area_seed：再兜底。✅

**"最高频 POI 名称"的合理性**：一格内可能有多个 POI（如网格内有"万达广场"+"麦当劳"）·取最高频（同类别聚集）或最近质心。**建议取最近格质心的 POI**（而非最高频）——因为格内 POI 可能类别混杂（商业+住宅）·最高频未必代表性强·质心最近更稳定（几何确定性）。

### 2. poi_names 输出：✅ 合理·需定 N

**草案**：格内 POI 清单 top-N·逗号分隔·防全量清单配额爆。

**glm组 判断：逗号分隔够用·N=5。**

**理由**：
- 逗号分隔 vs JSON 数组：前端渲染都是 split·逗号更轻量·CSV 导出友好。**选逗号**。
- N=? ：格内 POI 通常 1-5 个（50-200m 格·城市 POI 密度）·N=5 覆盖大多数。超过 5 个的密格（商圈）截断 + 标"等N处"。
- **配额**：poi_names 是本地 sjoin 产出（非高德调用）·**零配额消耗**——"防配额爆"指的是前端展示 token / 下游 LLM context·不是高德配额。逗号分隔 top-5 ~50 字符·安全。

**结构化补充建议**：poi_names 逗号串之外·可加 `poi_count`（格内 POI 总数·整数）——让"等N处"语境有数可依（place_layer.reverse 已有 poi_count 先例）。

**glm组 建议（适配层·P0 必修）**：
```python
# place_layer.py 加 _read_pois_geojson 方法（适配 geojson feature 格式）
@staticmethod
def _read_pois_geojson(path):
    """读 GeoJSON FeatureCollection POI（3220 格式：geometry+properties）→ place_layer POI dict。"""
    if not os.path.exists(path):
        return []
    with open(path, 'r', encoding='utf-8') as f:
        gj = json.load(f)
    out = []
    for feat in gj.get('features', []):
        geom = feat.get('geometry') or {}
        if geom.get('type') != 'Point':
            continue
        coords = geom.get('coordinates') or []
        if len(coords) < 2:
            continue
        p = feat.get('properties') or {}
        out.append({
            'name': p.get('name', ''),
            'lng': float(coords[0]),
            'lat': float(coords[1]),
            'area': '',                                    # 3220 无·用 district 兜底
            'baidu_level1': p.get('category', ''),          # category → baidu_level1 映射
            'baidu_level2': p.get('keyword', ''),           # keyword → baidu_level2
            'domain': '',                                   # 3220 无·待 L4/规则补
            'element': '',                                  # 3220 无·待 L4/规则补
            'source': 'yichang_pois_geojson',
        })
    return out

# _load 里加：
_YICHANG_POIS_GEOJSON = os.path.join(_ROOT, 'DATA', 'POI', 'yichang_pois_wgs84.geojson')
# _load() 末尾：
self.yichang_pois = self._read_pois_geojson(_YICHANG_POIS_GEOJSON)
self.all_pois = self.amap_pois + self.landmark_pois + self.yichang_pois  # 合并 3220
```
