## 各类问题速查（按类别·遇到即记）

### A 类 · 渲染/图层问题
灰框无填充 / 图例缺失或错误 / 悬停无值 / 色带不随面板变 / 图层残留（刷新后旧层复活）

### B 类 · 工具/分析问题
答非所问（问 A 答 B）/ 工具调用绕圈（>3 次）/ 结论无口径标签 / 数字可疑（与基线不符）/ 不落图

### C 类 · 引擎/对话问题
无流式（轻量引擎应逐字）/ 卡死无响应 / 「暂时无法直接回答」（**记时间点**）/ 追问条缺失或点了没反应 / dsh 引擎等待超长（>240s）

### D 类 · 体验问题
窗口/按钮找不到 / 文案术语化（看不懂）/ 加载异常慢 / 版本角标缺失
