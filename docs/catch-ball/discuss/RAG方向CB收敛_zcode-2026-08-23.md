## 一 收敛答案（对用户三问的直接回答）

**问一：EMC 的 RAG 拥有 Agentic RAG 特性吗？**
**一半——且这一半是定位使然而非缺陷**：路由（A2）/工具化检索（MCP 双工具）/追问线索（喂外脑循环）已有；迭代循环/运行时自评/知识自维护无。三组+学界三方汇流（A-RAG 三原则判定：agentic 性 100% 在循环层、工具层只需「分层+友好」；Letta 原话「RAG 是 agent 记忆的工具而非记忆本身」）：**EMC 检索服务按定位就不该是 agent——循环的主人=外置 Harness（架构裁定）**。Qoder 措辞修正采纳：A2 路由等=「服务深化项」而非「agentic 雏形」（A-RAG 判 Adaptive 路由为非 agentic）。

**问二：最前沿的 RAG 是什么？**
六范式+两组补盲共**八范式**（2026 全景）：Agentic RAG（循环智能）/ GraphRAG / Self-RAG·CRAG（自评纠错·循环时代被外脑纠错覆盖）/ Adaptive RAG / **LLM Wiki·agent 记忆**（Karpathy 三层/STORM/Letta·**「RAG→记忆」=学界认定的终局方向**——HippoRAG 2 论文标题即 From RAG to Memory）/ RAPTOR（分层摘要·EMC 事实卡=其手工版实证）/ FaithfulRAG（事实级冲突显式建模优于压制）。

**问三：EMC 的 RAG 开发方向？**
**双支柱（收敛建议·报终裁）**：

> **支柱一「自知之明的检索服务」（A·立即）**：确定性信号字段族（confidence 三档/coverage_hint/thin_result/retry_cue——Kimi 与 Qoder 的字段设计合流）+ 渐进披露可选参数（默认全文·防 finalStep 素材支柱隐性退化——Qoder 关键盲点提醒）。零 LLM·零二次检索·零循环——「告知不足·不替外脑补救」。
