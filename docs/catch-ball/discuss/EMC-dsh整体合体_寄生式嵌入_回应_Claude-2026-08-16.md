## 三 议题5：数据纪律 → 工具面硬约束映射（claude组 主答）

| # | 现行纪律 | 工具面映射（硬实现） |
|---|---|---|
| C1 | PII/脱敏铁律（编码规范 7·test_pii_guard） | MCP server 输出过滤器：复用 PII 字段白名单逻辑·工具返回值过滤后才出进程；办件编号类准标识符沿用"图层保留/RAG 层丢弃"双轨裁定 |

| C3 | gdb 只读 / 中转站纪律 | MVP 六工具**不暴露任何 gdb/中转站直接操作**（保持）；未来若暴露·只读模式 + 路径前缀白名单 |
