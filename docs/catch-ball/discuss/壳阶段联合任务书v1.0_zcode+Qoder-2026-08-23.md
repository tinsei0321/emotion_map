## 一 架构裁定（v1.0 定稿）

1. **Q1 大脑接口**：双轨制——壳对话框架按 ACP 事件模型建·首引擎=自持轻循环（**辩护地基换为「既有资产复活」**·不涉裁定争议）·BrainAdapter 接口位预留（dsh 降级/Codex 全量后插）；**增双轨对照口径**（同题 10 题两引擎对照·架构证据归档）。
2. **Q2 壳与现前端**：渐进升级（8080 ai_qa 对话框→ACP 客户端）；**先做隐藏重构坑侦察**（现前端与四阶段直连的耦合面清单·S3 前置半日）。
3. **Q3 编排归属**：编排权=引擎层·壳不直调 MCP；补**防误伤边界**（壳的诊断类只读调用白名单·明确豁免面）。
4. **Q4 ACP v1.1**：四项增补+provenance 字段+载荷结构模式（Qoder 三处表述修正采纳）；**approval.req 首个真实消费者=支柱二 kb_inbox 写入**（接线点登记）。
5. **Q5 垂直域抽象**：五件套扩**六件套**（+渲染预设——受管色带词表垂域子集·样式权威仍在 EMC 平台层）；**主手裁定：知识库件内分两槽**（语料槽+范式槽——范式库是 prompt 组装用结构化知识·与向量语料不同形态·分槽显式化）；**共享不变量清单入契约附录**（ACP 事件语义/MCP 工具签名/渲染契约七段/治理字段 schema/四态出口——垂域②试点的核心观察项：有一个要改=抽象划线错了·早发现早便宜）。
