### 焦点 2：知识库层级（L0 放 docs/urban-renewal-plan/）— **agree**

**方案**：L0 资料库放 `docs/urban-renewal-plan/`（与 ai_qa/ 分离）·L1 浓缩层在 `ai_qa/industry_kb/`。

**glm组 判断：agree——L0 放 docs/ 合理·不应放 ai_qa/。**

**理由（3 点）**：

1. **职责分离**：
   - `ai_qa/` = **EMC 运行时**（.py 注入 prompt·被 `industry_kb_text()` 消费·走 `@track`/test_industry_kb schema 守卫）。
   - `docs/` = **文档资料**（markdown/PDF·人读 + zcode 读·非运行时注入）。
   - L0 是**原始资料库**（原文/来源/页码）·非 EMC 归因浓缩——放 ai_qa/ 会**混淆运行时与资料**·且 .py 格式不适合存原文。

2. **体积隔离**：
   - `industry_kb_text()` 注入 prompt（agent_step 全量 / final_brief 精简 <5KB·CB-14 守卫）。
   - 若 L0 放 ai_qa/·`industry_kb_text()` 可能误注原始资料（几十 KB）·**撞 D019 final 极瘦红线**。
   - L0 放 docs/·物理隔离·`industry_kb_text()` 只读 .py 浓缩字段·不会误注原文。

3. **打包独立**：
   - zcode 独立项目读 `docs/urban-renewal-plan/`（markdown + PDF）——**与 EMC 运行时无关**。
   - 若放 ai_qa/·zcode 要读 .py（需 Python 环境 + import 链）·**增加 zcode 侧负担**。

**glm组 补充（L0 → L1 → L2 流向）**：
```
L0（docs/urban-renewal-plan/·原始资料）
  ↓ 人工提炼（归纳总结 + EMC 归因对应）
L1（ai_qa/industry_kb/urban_renewal.py·浓缩 schema）
  ↓ industry_kb_text() 注入 prompt
EMC 运行时（agent_step / final_brief）
  ↓ build_outlet_schema 出口卡片
L2（ai_qa/outlet_kb/·出向契约）
```
**单向流动**：L0 → L1 人工提炼·L1 → L2 出向映射·禁反向（L2/L1 不写 L0 原文）。
