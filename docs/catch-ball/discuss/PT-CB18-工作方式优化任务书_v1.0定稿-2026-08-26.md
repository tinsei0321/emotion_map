## 白话摘要

这次不是给产品加功能，是给「我们自己干活的方式」做瘦身体检。要干六件活：①造一个自动生成「项目当前状态」的生成器，以后状态只有一份、永不过期；②把 309 行的规矩手册瘦到 150 行以内，全仓同一条规矩只写一次；③造一个「编号→业务名」术语表生成器，治「看不懂编号」的病；④定「一个话题一个文件」的新规矩（下一批生效）；⑤定「评审分三档」的新规矩；⑥做两个写作模板（派发单、白话摘要）。后续还有四件（档案喂检索、输出压缩器评估、会话切分纪律、规则除草）排在验证之后。总工期 2.75~3.25 天，每件活都配了「拿尺子量得出」的验收判据。

## 一、目标与边界

**目标**：降 token（开工入场费减半 / 单话题文档 1 份 / 返工下降）+ 优体系（单一状态源 / 评审分级 / 规则预算）。

**边界（本批不做）**：不动业务代码与测试门禁基线；不推翻现有资产（进度生成脚本 / 规则库 / 接口锁 / 任务书制度），只做接驳与瘦身；历史档案不删除，只改读取方式。

**红线**：精简对象 = 重复、过期、低信息密度内容；「目标 / 边界 / 验收」三要素不得以省字为名删减。

## 二、用户拍板记录（2026-08-26 · 三项已决）

1. 工期按校准值 **2.75~3.25 天**执行（采纳 Qoder 校准）；
2. 采纳 `_board.yaml` 决策区方案，**收敛者每批维护待拍板清单**（新增持续性义务）；
3. 手册双阈值：**150 行 = 工作上限**（常态不得超，超须说明理由），**200 行 = 报警线**（超过即触发除草）。

### W1 基建批（零代码风险 · 2.25~2.75 天）

#### W1-1 单一交接文档 STATE.md（1~1.25 天）

**执行路径**：
1. `_board.yaml` 增 `decisions:` 决策区，结构 = 编号 / 事项 / 候选 / 状态（收敛者维护）；结构示例写入文件头注释；
2. 新建 `tools/gen_state.py`（参照 `tools/gen_progress.py` 既有链路）：消费 `_board.yaml` + git，生成 `STATE.md`——**首行 = 生成时间 + HEAD 短哈希**；骨架五栏 = 当前分支 / 在途批次（每批一行）/ 待拍板项（消费决策区）/ 门禁基线 / 最近 5 提交；
3. 新建 `check_state.py` 或 pytest 契约用例（照抄 `tests/test_progress_contract.py` 漂移门禁先例）：断言「重生成 diff=0 且分支 / 最近提交与 git 输出一致」；

5. 旧载体处置：workspace 记忆在途段 + 会话交接卡**冻结**（观察一阶段后退役）；每日记忆改一行式（只记结论与决策，状态字段禁写）；换机交接卡（HOME/OFFICE）**保留不动**。

**验收（硬判据）**：①契约用例通过（重生成 diff=0）；②「在途状态」唯一落点 = STATE.md；③决策区至少 1 条真实记录驱动「待拍板」栏非空。

### 8.2 偏离字面的工程判断

1. **board 补录**：任务书只要求加 `decisions:` 区；但 stages 停在 PT-CB13 与 git 史漂移，不补则「在途批次」栏失真——补录 PT-CB14~18（逐条可对 git log 核证），同时把 PT-CB13 状态 in_progress→done。
2. **`gate_baseline` 区**：任务书五栏含「门禁基线」但未定数据源——定为 `_board.yaml` 新键（收尾批更新），避免 STATE.md 硬编码。
3. **STATE.md 首行与确定性**：任务书要「首行=生成时间+HEAD」，与 progress「禁时间戳」先例不同——采用「首行豁免」方案（契约用例剥离随变行后比骨架），既保人判新旧又保漂移门禁。
4. **手写区机制**：八字段交接段落点定为 STATE.md 末尾「## 手写区」，生成器逐字节保留（专项用例验）——任务书未定落点，此为工程自定。
5. **判据 C 异构实现**：「全新会话」以隔离子代理实现（只注入新手册·不共享本会话上下文），非另开人工会话——验证等效，记录备查。
6. **git 读数显式 UTF-8**：Windows 下 text=True 默认 GBK 解不开中文提交题，生成器/契约均显式 `encoding='utf-8'`（首跑实证修复）。
7. **多会话仓并发**：全量测试期间另一会话提交（`9590b1e`）致 HEAD 变化，契约误报一次——豁免行集补齐后稳定；此为该仓多智能体并工的结构性事实，非生成器缺陷。
8. **术语表紧凑格式**：F/D 号 214 条超百行预算——按模块聚簇单行串接，R 规则名 40 字截断，信息不丢（可回源）。
