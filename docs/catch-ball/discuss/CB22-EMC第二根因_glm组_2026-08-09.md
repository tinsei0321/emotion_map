// harness:1004（rag_query 短路·RAG 注入后）

**glm 判定**：rag_query 短路**直接 finalStep**——FINAL_TEMPLATE 虽有"纯问答排版"段（:152）·但：

- vs quick-general（:940）：general 问句（"什么是情绪地图"）天然无图层素材·LLM 靠纯问答排版兜底。

## 二、3 修复方向评估（glm 逐条）

### 方向 A · 改 FINAL_TEMPLATE 加"知识问答禁图层"约束 — **❌ disagree（撞 D019 + 治标）**

**计划**：FINAL_TEMPLATE 加"知识问答禁用图层主出口"约束·或专用模板。

**glm 判断：disagree——撞 D019 红线 + 治标（约束 LLM 不可靠）。**

**理由**：
1. **撞 D019 final 极瘦**——FINAL_TEMPLATE 现 2957B（CB-22 出口三段式软扩后）·加"知识问答禁图层"约束 + 判别条件·体积必破 3KB 红线。
2. **治标**——与 R3 计划案"约束 LLM 不编"同病：LLM 受"图层主出口"强约束 + "知识问答禁图层"弱约束冲突时·可能仍走图层（强约束赢）。
3. **影响 general/分析**——改 FINAL_TEMPLATE 影响所有 finalStep 路径（general/分析/rag_query）·回归风险大。

**glm 判定**：方向 A 撞红线 + 治标 + 回归风险——**不取**。

### 方向 B · 确定性组装回答（零 LLM） — **✅ agree（根治·glm 推荐）**

**计划**：RAG 注入成功 → 不走 finalStep LLM·确定性组装回答（事实卡/检索结果拼接 + 来源 + 维度声明）。

**glm 判断：agree——根治·与 glm 上轮 R3 一脉相承。**

**glm 立场脉络**：
- **上轮 R3**（RAG 不可用）：glm 建议"EXIT_CONCEPT 确定性兜底·禁 finalStep LLM 编"。
- **本轮方向 B**（RAG 可用）：延伸——RAG 可用时也**确定性组装检索结果**·禁 finalStep LLM 受图层模板干扰。
- **统一原则**：**rag_query 短路全程禁 finalStep LLM**——不可用走兜底模板·可用走组装模板·都是确定性（Dumb Tool）。

**glm 方案（确定性组装·harness rag_query 分支改）**：

```javascript
// harness rag_query 分支（:978）·RAG 注入成功 → 确定性组装·不走 finalStep
if (!ctx.resume && _quickIntent(ctx.question) === 'rag_query') {
  try {
    const _res = await fetch('/api/v1/aiqa/rag_search', {...});
    const _data = await _res.json().catch(() => null);
    if (_data && _data.ok && _data.results && _data.results.length) {
      // ★ 确定性组装（零 LLM）——拼接检索结果 + 来源 + 维度声明
      const _lines = _data.results.map((r, i) => {
        const _src = String(r.source || '').split('/').pop().split('#')[0];
        return `${i + 1}. **${_src}**（${r.data_dim || '社区'}维度·[来源](${r.source})）`;
      });
      const _final = `## 知识库检索结果（Top-${_data.count}）\n\n`
        + _lines.join('\n')
        + `\n\n> **数据维度声明**：以上结论不超过检索数据的维度标注·未引用他城具体数值。`;
      if (hooks.onFinalDone) hooks.onFinalDone(_final);
      return { ok: true, rounds: 0, final: _final, degraded: false,
               diagnose: { degraded: true, intent: 'general', quick: true, rag: true },
               defense: { degraded: false, fixes: [], skipped: 'rag-direct-assemble' } };
    }
    // RAG 不可用 → EXIT_CONCEPT 兜底（glm 上轮 R3）
    const _gap = `## 知识库检索未就绪\n\n建议稍后重试...`;
    if (hooks.onFinalDone) hooks.onFinalDone(_gap);
    return { ok: true, final: _gap, degraded: true, ... };
  } catch(_e) { /* 兜底 */ }
}
```

**glm 方案优势**：
- **零 LLM**——禁 finalStep·禁 FINAL_TEMPLATE 图层导向·零幻觉/零模板错位。
- **确定性组装**——检索结果 + 来源 + 维度声明·对齐颗粒度原则。
- **对齐 AI·Copilot 内核**——rag_query 短路 = Dumb Tool（确定性组装）·非 Smart LLM。
- **不影响 general/分析**——rag_query 分支独立·不改 FINAL_TEMPLATE·general/分析路径零影响。

**vs 方向 A**：
| 维度 | A 改模板 | **B 确定性组装** |
|---|---|---|
| D019 红线 | ⚠️ 撞（加约束破 3KB） | ✅ 不撞（不走 finalStep） |
| 幻觉风险 | 🟡 中（LLM 受约束仍可能编） | 🟢 零（不走 LLM） |
| 回归风险 | 🔴 高（改 FINAL_TEMPLATE 影响全路径） | 🟢 零（rag_query 分支独立） |
| 根治度 | 治标 | **根治** |

### 方向 C · 分类为 general（EXIT_CONCEPT） — **⚠️ partial（语义不准 + general 也走 finalStep）**

**计划**：RAG 问题分类为 general·走纯问答路径。

**glm 判断：partial——语义不准 + 治标。**

**理由**：
1. **语义不准**——RAG 问句（"宜昌有哪些更新项目"）不是纯概念问答（"什么是情绪地图"）·是**知识检索问答**。分类 general 会混入概念问·diagnose 语义混乱。
2. **general 也走 finalStep**——quick-general（:940）也调 `stages.finalStep`·受 FINAL_TEMPLATE 图层导向约束。general 问句靠"纯问答排版"段兜底·但**RAG 注入素材后同样可能走图层**（与 rag_query 同病）。
3. **方向 C 不如 B**——C 仍走 finalStep（模板错位风险）·B 禁 finalStep（根治）。

**glm 判定**：方向 C 治标 + 语义不准——**不取·B 更优**。
