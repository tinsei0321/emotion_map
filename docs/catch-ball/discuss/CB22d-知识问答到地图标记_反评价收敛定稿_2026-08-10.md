## 二、修正版定稿 plan

### P0-0 前置接线（harness 编排器层·红线安全·最先做）

1. **路由使能重构**（修 glm B.1 + Codex 焦点 B）：放弃 `ctx.resume &&` 条件（恒 false）。改**在 FC diagnose 前置**（harness.js:1124 前）检测 `priorTurn.intent==='knowledge_qa' && /标记|标到地图|在地图上|点位|位置/` → 无条件注入上下文提示「用户要把上一轮知识问答的项目标记到地图·选 generate_point_layer 并从上轮回答提取项目/片区名入 names[]」+ **上轮 final 文本片段**（修 glm F.1）。**不翻转 resume·不进 1197 续作分支·走正常 FC**。
2. **_dataGate 豁免**（修 Codex A-2）：`_dataGate` 加条件——`priorTurn.intent==='knowledge_qa' && /标记|标到地图/` 时跳过（或窄化「点位」正则须含情绪/极性语义）。
3. **runTemplatePath 零图层诚实出口特判**（修 Codex A-1）：对 `generate_point_layer`——`data.layerId===null && Array.isArray(data.unmatched)` → 跳过 ask_user·带 toolHistory 走 finalStep 诚实文字出口（exit='result'/answered·零图层）。
4. **quick-rag 轮知识问答标记**（修 Codex 焦点 B）：`_assembleKnowledgeQA`/panel 补独立于 diagnose 的知识问答轮标记（`_curTrace.rag=true`·防 quick-rag 轮 `priorTurn.intent=''` 死代码）。

### P0-1 工具层：`generate_point_layer({names, as})`

- 逐名 `GET /api/v1/place/search`（limit=1~3）→ point FeatureCollection（properties: name/address/source/category/score）
- **显式 circle 样式**（`defaultPaint` 无 point 分支·Codex 挑战 2）·`addToolboxLayer({kind:'point', paint: circle})`
- **并发/超时预算**（Codex + glm）：上限 50 名·并发 ≤10·单请求 5s 超时·总预算兜底（防 55 名挂死）·未完成者落第三级文字
- **匹配结果属性**：`{name, source: local|amap|preset, match_type: point|area|none}`（溯源铁律·防 LLM 自创地址）
- **三级面化回退**：① search_place 命中→点 ② 片区/行政区名→面（**自建 name→面 containment 匹配·扫已加载 preset 要素·不复用 FIXED_ADMIN_DISTRICTS 白名单**·葛洲坝不被拒·匹配不到退行政区面+名称标注）③ 聚合类无地点→文字列「未匹配坐标」+ 原因·**绝不 request_upload**
- observation「命中 n/N + 未命中列表 + 来源标注」·`_SLOT_HINT.names` 补文案
- SKILL_DEFS 镜像（required_slots: ['names']）
- `_deterministicRecover`（harness.js:1813）加「标记/地图 + 上轮 knowledge_qa → generate_point_layer」确定性兜底（glm A.2·绕开 `_polys.length` 前置守卫·本场景无图层·双保险防 FC 方差）
