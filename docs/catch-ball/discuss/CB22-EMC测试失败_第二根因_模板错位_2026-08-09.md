## 二、第二根因定案：RAG 问答走 finalStep 分析模板（模板错位）

### 代码证据（FINAL_TEMPLATE·prompts.py:127）
```
**三句骨架**（必守）：① 动作 ② 产出 ③ 交互（{{show:图层名}} 按钮引导）。**图层是主出口**——分析类必产图层·严禁只给文字。
```

### 链路
```
rag_query 短路 → rag_search 注入成功 → finalStep（FINAL_TEMPLATE·图层导向）
→ LLM 看到"图层是主出口"→ 生成"分析图已生成·{{show:图层名}}"
→ 纯问答（知识引用）被强塞进分析模板 → 结论与问题不搭
```

### 根因
- **general 短路**（:940 quick-general）→ finalStep（FINAL_TEMPLATE·分析模板）·LLM 靠「纯问答排版」段兜底
- **rag_query 短路**（:978）成功时**直接 finalStep**·连「纯问答排版」都不判·→ LLM 按图层导向生成
- **RAG 问答 = 纯问答（知识引用）·不应走分析模板**·应走**纯问答排版**（条目式·知识引用·非图层）
