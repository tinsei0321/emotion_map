## 〇、任务背景

用户收到《城市更新专项规划》（宜昌市城区）研究型任务，需要**权威性资料**（城市更新/城市体检的政策、指标、案例、文件），非情绪地图分析内容。这些资料同时也是 EMC 开发背景（更新/体检指标体系）。要求：
1. 分类整理（政策文件国家/省/市 + 指标体系/标准/指南/方法 + 案例/新闻等）+ 归纳总结
2. **架构系统清晰 + 防"张冠李戴"**（不同城市的方法论/指标/标准严格一一对应）
3. 收集案例资料（**必须含杭州市案例**）
4. 资料收集意见 / 多收集内容
5. **严格标注来源**（链接/本地位置）+ 完整名称 + 参考位置（章节/页码）
6. 加入 EMC 底层知识库（并优化层级架构）
7. 生成"汇总资料集"可打包提取供 zcode「城市更新专项规划」独立项目读取

## 一、现状摸底（claude组 已核实）

**EMC 最底层知识库现状**：
- **L1 语义浓缩层**：`ai_qa/industry_kb/`（.py 单一权威源·四领域规划/更新/运营/治理·每领域含政策gist/术语/底线/项目/案例/归因映射）——面向 EMC 归因，**非原始资料库**
- **L2 出向接口层**：`ai_qa/outlet_kb/`（出口卡片契约 + 案例库 6 案例：宜昌望洲岗/上海/广州/南京/宁夏 + 体检指标映射）
- **L0 国标层**：`ai_qa/landuse_codes_2023.py`
- **概览**：`docs/industry-knowledge-base.md`

**关键缺口**：缺「L0 原始资料库层」（原文/来源/页码/城市对应/分类整理）——industry_kb 是浓缩归因层，不能当资料库。城市更新 `urban_renewal.py` 未做厚（体检 76 指标细节/各地更新条例/杭州案例缺）。本地无政策原文文件。

## 二、拟议方案

### 2.1 知识库层级优化（问题 6）

```
ai_qa/industry_kb/            L1 语义浓缩层（EMC 归因·现有）—— 做厚
docs/urban-renewal-plan/      L0 原始资料库层（新建）—— 本研究任务权威资料集
ai_qa/outlet_kb/              L2 出向接口层（现有）—— 按需扩展
```

L0（新）= 原文/来源/页码/城市对应/归纳；L1（现有）= 从 L0 提炼的 EMC 归因浓缩；不混层。

### 2.2 资料库分类架构（docs/urban-renewal-plan/）

```
docs/urban-renewal-plan/
├── README.md                      # 总览 + 使用说明 + 打包指引
├── _INDEX.md                      # 全量资料总索引（名称/城市/层级/来源/位置/状态）
├── 01-政策文件/{01-国家级,02-省级-湖北,03-市级-宜昌}/
├── 02-指标体系-标准-指南-方法/{01-城市体检指标体系,02-标准指南,03-方法}/
├── 03-案例资料/{01-杭州,02-上海,03-广州,04-北京,05-武汉,06-其他}/
├── 04-新闻报道-相关材料/
├── 05-本地已有文件/               # 登记 docs/ 现有 PDF（成都论文/制图规范·不移动）
└── 00-宜昌专项/                   # 宜昌本地：葛洲坝/二马路二期/西坝/更新单元台账
```

### 2.3 防张冠李戴机制（问题 2 核心）

每份资料固定元数据表头：完整名称（含文号/年份）/ 适用层级-城市（精确标注防混用）/ 发布机构+来源链接 / 本地落盘位置 / 参考位置（章节/页码）/ 归纳总结 / EMC 产出对应（若适用）。

**已核实差异（写入资料库防混淆）**：
- 宜昌专项规划（市住新局 2025 修编）≠ 杭州专项规划（2024-2035）≠ 湖北省级指引（试行）
- 体检指标：住建部基础框架 ≠ 恩施 76 项 ≠ 武汉细化 ≠ 杭州 86 项——各城对应各城

### 2.4 EMC 知识库回填

1. `ai_qa/industry_kb/urban_renewal.py` 做厚（TOP_DESIGN 补宜昌专项/省指引·METRICS 补体检四维度框架·CASES 补杭州/武汉/宜昌）——**遵守 schema，不破坏 tests/test_industry_kb.py**
2. `docs/industry-knowledge-base.md` 概览加 L0 资料库层指向
3. `ai_qa/outlet_kb/urban_checkup_outlets.py` 补「体检-更新衔接」契约
4. 不碰承重红线（diagnose prompt/四态出口/@track）

### 2.5 汇总资料集打包（问题 7）

`docs/urban-renewal-plan/` 整目录 = 自包含资料集（markdown 为主 + 落盘 PDF）；`_INDEX.md` = 提取清单；README 含打包指引（压缩/目录说明）；zcode 侧读 markdown + 按链接溯源原文。

### 2.6 联网收集（首轮聚焦核心·混合获取）

核心文件（国家/湖北/宜昌政策 + 体检指标 + 杭州案例）尝试下载原文；次要材料链接+摘要。**受网络动荡约束，链接+摘要为主、尽力下载。**
