## 〇、结论先行

**总评：框架方向成立（三类分色 + 深浅 + 双轨互证叙事专业），可定稿推进；但有 1 个承重的方法论次序问题必须先解决——Q1「选几个」与 Q4「图底口径」是耦合的，高社区数随图底社区数浮动。**

三条核心发现：

1. **Codex 的「59 个高社区」基本可信**（独立复现得 58，差 1 个边界社区），但**该阈值（28.57/146.67）是图底全样本（含双0社区）的 p81，不是有数据社区的 p81**（有数据社区 p81=34.31/167.38）。两者差 ~6 点 / ~21 点。
2. **阈值与高社区数对图底样本极敏感**：图底 125 社区（有数据）→ p81=34.31 → 高社区 45；图底 130 社区（含双0）→ p81≈28.57 → 高社区 59。**图底口径未定，则「59」未定。**
3. **Q2 等距分档不专业**：体检/诉求密度是右偏分布（万达 726 vs 多数 <90），等距会让低档扎堆、高档稀疏；业界 choropleth（分级着色）标准是自然断点（Jenks）或分位数。

## 二、五焦点逐项评审

### Q1 · 选 25 个（双高5+客观高10+主观高10）是否合适？

**判定：partial（方向对，但选量逻辑需对齐分档，且依赖 Q4 口径）**

- **证据**：用 Codex 阈值（客观≥28.57/主观≥146.67）在我 125 有数据样本上分类 = 双高 5 / 客观高 27 / 主观高 26 = **58 高**（Codex 称 59，差 1 个边界社区，基本吻合）。高社区池约 59 个客观存在，全列进 PPT 表过多（放不下），现稿 20 个偏少（漏客观高/主观高的长尾头部）。
- **图全着色 ✓**：120/130 社区全部着色（三类分色 + 其余浅灰），表只列重点——这个"图全、表精"分工合理，agree。
- **表选 25 比 20 合理**：双高 5 全要（稀缺）+ 客观高/主观高各 TOP10（各占该类 27 的 37%），补回了长尾头部（如客观高的桃花岭/环城东路/东门外正街、主观高的鑫鼎/张家湾/临江溪，现稿 20 漏列）。
- **问题①（机械等分）**：客观高 27、主观高 27 各选 10 是对称机械切。若两类总量不等（实测恰好都 27，巧合），等分尚可；但更稳健的做法是**表选量 = 图分档的"深档"社区数**（见 Q2），让表与图的深浅档一一对应，而非另设"TOP10"。
- **问题②（口径依赖）**：59 这个池子大小依赖图底口径（Q4）。若图底从 130 收到 125，高社区从 59 降到 45，表选 25 的代表性也随之变。

**定稿建议**：图全着色保留；表选量改为"双高全要 + 客观高/主观高各取图分档的深档（约各 9 个，分位数 3 档每档 ~9）"，总量约 23-25；**Q4 口径定稿后复算高社区池再定表选**。

### Q2 · 深浅 3 档合理吗？分档阈值用哪种方法更专业？

**判定：disagree（3 档合理，但等距不专业，应改自然断点或分位数）**

- **证据①（右偏分布）**：客观高密度跨度 28→150（金安岭 150 / 西峡 116.7 / 幸福路 112.1 / 镇境山 105.1 / 深圳路 84.3 / 桥北 77.1 / ... 多数 <90），是典型右偏；主观高 146→726（万达 726 / 朝阳 707 / 建设 563 / ... 多数 <450）同样右偏。
- **证据②（等距失衡）**：Codex 等距 3 档（客观 28/60/100、主观 146/300/500）下，深档（客观>100）仅 4 个（金安岭/西峡/幸福路/镇境山），浅档（<60）扎堆；主观深档（>500）仅 3 个（万达/朝阳/建设）。**图面深档稀疏、浅档拥挤，"程度"对比出不来。**
- **业界标准**：分级着色（choropleth）单变量分类，首选 **Jenks 自然断点**（最小化类内方差，最适偏态）；次选**分位数**（每档等量要素，图面均衡，小样本更稳）。等距仅适合均匀分布，偏态数据不推荐。

**定稿建议**：
- 客观高 / 主观高**各用分位数 3 档**（27 社区÷3≈每档 9 个，图面均衡、小样本稳健）或 **Jenks 自然断点**（若分布有明显聚类断点）；**弃用等距**。
- 双高 5 个 1 档深红 ✓（样本太小不分档，agree）。
- 阈值用所选方法重算（非 28/60/100、146/300/500），并在图注标明分类法（如"按分位数分 3 档"），专业且可复现。
- 注意：分档只在"高"社区内（已过 p81 的 27 个）再分 3 档，样本小，自然断点与分位数差异不大——但仍比等距优。

- **片区划分指导意义**：双高=重点片区首选落点 ✓ 已点明；但可再显化"三类统筹 = 片区划分的空间依据"（双高先划、客观高补短板、主观高回应诉求，三类共同构成片区边界与优先级）。

**定稿建议**：
- 三段文字保留，微调：客观独证加"补齐体检底线短板"、主观独证加"回应急难愁盼"（与 page2 双线术语对齐）。
- 整体价值句补半句：三类统筹"为城市更新片区划分与重点片区选定提供**空间依据**"（凸显"在哪里划片"的指导意义）。

### Q4 · 口径 120/130/118 用哪个做底？

**判定：partial（图底用西陵+伍家城市社区全集做几何底；用户"先按120走标差异"同意，但必须注明图底社区数影响 p81 阈值与高社区数）**

**实测四数厘清**：

| 口径 | 数字 | 含义 | 适合做图底？ |
|---|---|---|---|
| 体检对象范围 | **130** | 西陵+伍家岗城市社区面全集（几何范围） | ✓ **推荐（最客观）** |
| 有12345落点 | **118** | 主观轨覆盖的社区子集 | ✗（是子集，非全集） |
| 用户口径 | **120** | 待厘清来源（疑为去村后或某筛选） | 待定 |
| 我实测 | **125** | 体检∪诉求∩分母（有数据的社区） | ✗（排除双0） |

- **证据（口径敏感性·承重）**：图底 125（有数据）→ p81=34.31/167.38 → 高社区 45；图底 130（含双0）→ p81≈28.57/146.67 → 高社区 59。**社区数差 5，阈值差 6 点 / 21 点，高社区差 14 个**——口径直接决定"哪些社区算高"。
- **根因**：p81 是分位阈值，双0/低密度社区越多，分位被压得越低，阈值越宽松，高社区越多。Codex 现行阈值 28.57/146.67 隐含图底≈130（含双0），方法论正确，但 130 这个数本身需确认（是范围全集还是含边界社区）。

**定稿建议**：
- **图底 = 体检对象西陵+伍家岗全部城市社区（去村）**，所有社区着色：三类分色（双高/客观高/主观高）+ 双0/低密度浅灰（标"暂无突出问题数据"）。这是几何底，最客观。
- **p81 在此全集（含双0）上算** = Codex 现行口径（28.57/146.67），agree 保留。
- **120/130/118 三数标注差异**（图注或口径说明）：130=范围全集 / 118=有诉求落点 / 120=用户口径（建议 Codex 厘清 120 来源——是去村？还是某筛选？）。
- **用户"先按120走标差异"同意**，但需在图注注明"阈值基于 N 社区全样本 p81，N 的口径（120/130）会影响高社区判定"，最终口径定稿后复算阈值与高社区数确认。

### Q5 · 图例与 page2「两个方面」衔接是否成立？

**判定：partial（衔接成立，但需厘清「两个方面（领域）」vs「双轨（来源）」是两个不同层次，别混淆）**

- **证据（层次厘清·承重）**：
  - page2「两个方面」= **安全韧性问题 + 民生基础需求**——这是**问题领域**（what：聚焦哪两类问题）。
  - page7 三类 = **体检（客观轨）+ 诉求（主观轨）双轨的证据强度**——这是**数据来源**（where+why：哪类社区优先、为何）。
  - **两者维度不同**：page2 讲"问题分类"，page7 讲"空间优先"，是互补关系，非同维度重叠。
- **衔接成立处**：
  - 双高 = 体检（对应 page2 体检线 25 项：安全5+民生20）+ 诉求（对应 page2 市民线 12345 九类）**两源都高** = page2 两个方面都有突出表现 → **两源互证 ✓**。
  - 客观独证 = 体检发现隐患（page2 体检指标）但市民没投诉 → **补齐体检底线短板 ✓**。
  - 主观独证 = 市民诉求高（page2 的 12345）但体检没查到 → **回应急难愁盼 ✓**。
  - Codex 的三句衔接（两源互证/补齐短板/急难愁盼）**逻辑成立**。
- **要避免的混淆**：别把 page7 三类说成"安全/民生两个方面"——page7 是按**双轨来源**（客观/主观）分，不是按**两个方面**（安全/民生）分。两类社区内部都横跨安全+民生（如双高营盘路=民生体检高+诉求高，非安全高）。

**定稿建议**：
- 图例显式标注两轨来源：**客观轨 = 体检指标（安全5+民生20 项）/ 主观轨 = 12345 诉求（九类）**，与 page2"体检线 / 市民线"呼应。
- 衔接句强调互补：page2 定"聚焦哪两类问题"（what），page7 定"哪类社区优先治理"（where）——page7 是 page2 的空间落地。
- 避免表述"三类=两个方面"，改为"三类=双轨证据强度，横跨 page2 安全+民生两个方面"。

## 三、承重提醒：Q1 与 Q4 耦合（方法论次序）

**这是本轮评审最重要的发现，单列强调：**

Codex 把「59 个高社区」当作既定事实推进 Q1（选几个），但 59 依赖**图底全样本的 p81 阈值**，而图底口径（Q4：120/130/118）还在待定状态。**正确次序应是：先定 Q4 图底口径 → 在该全集算 p81 阈值 → 得高社区池 → 再定 Q1 表选量与 Q2 分档。**

- Codex 现行阈值 28.57/146.67 隐含图底≈130（含双0），**方法论正确**，不否定。
- 但 130 这个数需 Codex 确认（范围全集 vs 含边界），且用户口径 120 的来源需厘清。
- **建议**：报告/图注统一标注"阈值基于 N 社区全样本 p81"，Q4 口径定稿后复算一次阈值与高社区数，确认 59/45 之争的最终值。这是数字实事求是的要求——不附和"59"也不否定，而是指出其前提条件。
