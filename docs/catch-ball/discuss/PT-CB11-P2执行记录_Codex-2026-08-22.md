### ③ nearest_analysis（F_036·最近邻锚定）

- 签名照派发单：`(layer, target, k=1, top_n=10, layer_output=False)`；target 必填（契约 required_slots）、k cap 5、top_n cap 20。
- backing：锚点 `resolve_points(layer)` → 目标先 `resolve_points(target)`（失败降级 `resolve_boundary`，面层路径过 G-2 守卫）→ 双方投影 **EPSG:4546**（照 area_stats 先例）→ 投影平面距离矩阵 → 每锚点 top-k。
- 实现注记（向主手报备）：派发单 backing 的 `gpd.sjoin_nearest` 仅覆盖 k=1；为统一支持 k≤5，采用**同一投影坐标系下的 numpy 距离矩阵 + argsort top-k**（k=1 时语义与 sjoin_nearest 等价），EMC 数据规模（千点×百目标=1e6 float）内存可控。
- 返回：`pairs=[{anchor,target,dist_m}]`（dist 升序·锚点名 place_name 如有/目标名 name 如有）+ `stats{mean_dist,max_dist,pair_count}`；layer_output=True 输出锚点→目标 **LineString 连线 FeatureCollection**（对齐契约 yields「连线层」）。
- 空集边界：锚点层空/目标层空 → 语义化拒绝；未知层 → _UNKNOWN_HINT。

### ④ overlay_analysis（F_038·叠置交叉）

- 签名照派发单：`(layer_a, layer_b, how='intersection', top_n=10, layer_output=False)`；how 四值白名单（intersection|union|difference|symmetric·契约同）。
- backing：双 `resolve_boundary`（各自 G-2 守卫）→ 只带 geometry+规范名进 overlay（防同名列后缀冲突，输出稳定 `name_a`/`name_b`）→ `gpd.overlay` → 面积 EPSG:4546（照 area_stats）→ 面积降序 top。
- 返回：`rows=[{name_a,name_b,area_km2}]` + `result_count` + `stats{total_area_km2}`；layer_output 复用 `_layer_output_geojson`。
- 空集边界：两图层无交集/差集为空 → 「叠置结果为空——两图层无交集/差集为空（请换 how 或检查图层范围）」。

  - conclusion：问题 + 有效结果计数 + 口径缺失计数拼接（不推理）；

- **不编造纪律**：无 caliber / 非 dict 输入 → evidence 标「口径缺失」+ conclusion 计数披露；refs 空则空数组。
