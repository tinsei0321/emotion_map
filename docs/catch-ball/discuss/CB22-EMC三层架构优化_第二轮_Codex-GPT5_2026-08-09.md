## 0b · EMC RAG vs 官方窗口价值定位 — agree（+ 3 点强化）

**同意定位**：

| 维度 | 官方窗口（问答机） | EMC RAG（工作台） |
|---|---|---|
| 资料接入 | 人工粘贴全量塞上下文 | 索引 + 检索 Top-K |
| 容量/注意力 | 容量有限·全量稀释 | 聚焦·精准注入 |
| 持久化/可成长 | 无（每次重贴） | 有（知识库增量·重向量化） |
| 来源保证 | 无（不追溯） | 有（出处标注·防张冠李戴） |
| 产出形态 | 纯问答（文字） | 三通道：问答 + 图层 + 出口卡/CSV（行业可交付物） |

**3 点强化（定位核心）**：
1. **EMC 差异化 = 三通道 + 行业出口**——不只是"问答更准"·是**产出可交付物**（图层/出口卡/CSV/对标对表）——问答机只出文字·工作台出"行业接口可消费的成果"——这是 0b 定位的落点
2. **聚焦反而更准的前提 = 知识问答通道修好**——本地化+可追溯的专业问答（宜昌专题）在通道修好后应**优于**官方窗（官方窗对宜昌专题无本地库）——0b 与 0c 的关系：定位对·但当前 0c 差距让"更准"未兑现
3. **诚实边界**：通用领域（非宜昌专题）EMC 不如官方窗（受限 harness + 无泛知识）——**定位即边界**（聚焦专业·非泛问答）

### 补⑤（更深根因·建议加入）

**EMC 的"限制"是为分析确定性设计的·但知识问答通道需要"自由综合"——两套需求共用一个受限 harness**——根因不是"中介层太限制"·是**中介层未按通道区分约束**（分析类=确定性约束·问答类=自由综合）——这正是第一轮"分类→范式映射"（PARADIGM_MAP）要解的·0c 的"限制型→增强型"应落实为**分通道增强**·非全局放开。

1. **通道化增强·非全局放开**：增强限定知识问答/概念通道（理解归 LLM + 检索补强 + 提示词增强）·**分析类的确定性红线不动**（图层主出口/四态出口/演示逻辑链是产品核心·防回归）——"增强型" = 问答通道自由综合·分析通道保持确定性
