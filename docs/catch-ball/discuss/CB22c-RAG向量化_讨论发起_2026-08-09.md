## 〇、用户架构定性（最高指引）

> ② **RAG** = 情绪地图项目（尤其 EMC outlets）的**底层数据库**·本次知识库是 RAG 的一部分（城市更新/城市体检专题）
> ③ **RAG 作用**：a) 支撑项目开发（大方向正确 + 颗粒度对齐）b) 让我直接使用（EMC 问答 → 承接知识库功能）
> **要求**：各任务产出什么/怎么架构·成果**互相消费**·RAG 后期**可维护**

## 一、RAG 定位

```
L0/L1 知识库（城市更新/城市体检专题）→ 向量化 → RAG（EMC 底层数据库）
                                                    ├→ 支撑开发（方向/颗粒度对齐）
                                                    ├→ 直接使用（EMC 问答承接）
                                                    └→ B 路径复杂语义查询（跨文档综合）
```

**RAG = EMC outlets 的底层数据库**：outlets 出卡时引用知识库 → 现在向量化后供 EMC 检索引用。

## 二、现状（已核实）

- **CB-14（08-03）判定不建 RAG**：知识库 150KB 静态注入够用 + DeepSeek embedding 硬阻塞
- **现状已变**：知识库暴涨（875 文件 L0）·需求从语境注入变**数据检索**·用户明确要 RAG
- **embedding 约束**：现有 provider（DeepSeek/火山 Ark/讯飞）都是 chat 模型·无 embedding

## 三、方案草案

### 1. embedding 选型（需验证）

| 方案 | embedding 来源 | 可行性 | 说明 |
|---|---|---|---|
| **A 火山 multimodal embedding** | 火山引擎（volcengine-vision） | 需验证 | 可向量化多模态（图表/GIS）·现成 MCP |
| **B 智谱 embedding** | 智谱（zai 栈·全局） | 需验证 | 智谱优先策略 |
| **C 本地 embedding**（sentence-transformers） | 本地模型 | 需装依赖 | 离线·无 API 成本·支持中文 |

**推荐**：验证 A/B（智谱优先·火山备选·CLAUDE.md MCP 策略）+ C 作离线兜底。

### 2. 向量库（本地持久化）

| 方案 | 说明 |
|---|---|
| **sqlite-vss / chroma** | 本地·轻量·适合中小规模（L0 数百文件） |
| FAISS | 高性能·需装依赖 |
| 内存 | 会话级·不持久 |

**推荐**：chroma（本地持久化·RAG 后期可维护 = 更新知识库重向量化·增量）。

### 3. 向量化对象（分层）

| 数据源 | 向量化 | 说明 |
|---|---|---|
| **L0 资料库** `docs/urban-renewal-plan/` | ✅ 全量 | 提炼笔记 + 事实卡 → 向量 |
| **L1.5 事实卡**（CB-22b） | ✅ | 结构化条目 → 向量 |
| **outlet_kb 案例库** | ✅ | 案例 point → 向量 |
| **L1 industry_kb** | ❌ | 已注入 prompt·不需检索 |

**颗粒度**：按笔记/段落/事实卡条目（结构已知用事实卡·开放语义用全文向量）。

### 4. 检索工具 `rag_search`（Dumb Tool）

```python
'rag_search': {
    'name': '知识库检索',
    'slots': {'query': '自然语言问题', 'k': 'Top-K 条数'},
    'desc': '向量相似度检索 L0 知识库·返回 Top-K 片段+来源',
    'dumb': True,
}
```

### 5. 接入（B 路径复杂语义承接）

- diagnose 识别「开放语义/跨文档综合」检索意图 → 调 `rag_search`
- 检索 Top-K → 注入 prompt（Smart 生成回答）·标注来源
- **与 B 路径分工**：简单查询（city+topic）走确定性 query_knowledge_base·复杂语义走 rag_search

### 6. 后期可维护（用户要求）

- **更新知识库 → 增量重向量化**（只重嵌变更文件·不全量）
- 事实卡 + 原文双源：结构已知走事实卡·开放语义走原文向量

### 7. 体积守卫

- rag_search 结果 intent-gated 注入 + Top-K（≤5）+ 来源
- 新增「RAG 注入后 <8000B」断言
