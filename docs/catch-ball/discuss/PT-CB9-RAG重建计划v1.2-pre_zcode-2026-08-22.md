## 一 定稿件（共识·直接生效）

### D1 · A2 路由契约（Kimi 版结构化）

- **主防线**：`rag_query` 与 `kb_facts` 工具描述写明分工——精确名词/口径数字→kb_facts（注册表直查）；叙述/方法/对比→rag_query。调用前分流·零运行时成本。
- **二道防线（结构化字段·替代自然语言附注）**：rag_query 命中口径类时返回
  `caliber_ref: { kind: 'caliber_class', suggest: 'kb_facts', topic: '<命中主题>' }`
  ——宿主确定性改道（检测 suggest→直调 kb_facts·一次到位）。窄面：仅口径类命中出现。
- **观察项**：返回统计 caliber_ref 出现率——两周 ≈0 则下版删字段（缺省省略·删除无破坏）。

### D2 · H1 followup_cue（Kimi 四红线+价值序+边界声明）

- 派生规则价值序：**维度相邻 > 口径关联 > 小节邻接（兜底·过滤修订/附录/索引类小节）**。
- 四红线：①cue 目标必须库内真实存在（先验证有 chunk）②cue 是问题不是答案（零事实断言·防绕口径校验）③2-3 条上限④排序固定=价值序。
- 口径类 cue 文案翻译为用户语言（「这个数是怎么算出来的」·禁裸 K-C1 编号——用户沟通纪律 2）。
- 无 cue=**省略字段**（非空数组）。
- **边界声明**：MCP 侧 cue（知识结构派生·喂宿主编排）≠ 壳内侧 `_followupCue`（harness.js:67·用户话术分类）；H1 产物未来可作壳内候选源——两套不打架。

## 二 A1 前注·护栏五合一（定稿）+作用域挂判决点

**护栏（全部并入泳道①任务书·缺一降级）**：
1. 前注文本=**权威资产进 git**（chunk_id→ctx_prefix 映射·版本化）——索引重建只重算 embedding **不重生成前注**；chunk 新增/修改才增量生成（Kimi·防双机/跨时模型漂移）。
2. schema 三字段（P0-6 契约收编）：`ctx_prefix`（生成态·None=未启用）/ `ctx_prefix_model`（模型名+版本溯源）/ `ctx_prefix_hash`（与 content_hash 分离·build 校验「正文变→前注必重算」）（Codex 6a）。
3. `content_hash` 覆盖**正文+前注**整体——失配则 build 不更新（强制一致性）（Codex 护栏 1）。
4. 重建命令一体化：`rag_index.py --build` 串「（增量）生成前注→入库→索引」禁拆手工两步（Codex 护栏 2）。
5. 前注质量门禁 1 条刚性：黄金集抽 N 条验证前注含出处要素（文档名/小节/口径状态任二）（Codex 护栏 3）。

**作用域（挂 P0 判决点·研判悬置 1）**：黄金集分类占比出数后定——
- 名词类占比高（>50%）→ A1 缩为「口径/叙述类 chunk 专用」；
- 均衡或叙述类占高 → A1 全量；
- 消融独立成层（前缀/前注/BM25+RRF 分 commit）·前注层增量 <2pp 收口降级为口径类专用（Codex 判据）。
- 呈现纪律：验收报告按**分类增量**呈现·防整体均值掩盖结构（Codex 挑战采纳）。
