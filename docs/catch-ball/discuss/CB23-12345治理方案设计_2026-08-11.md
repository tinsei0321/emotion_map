## 一、对齐后的决策（用户 4 点）

### 决策 1 · 情绪 5 级映射（用户纠正·对齐 EMC 枚举）
- **EMC 5 级固定枚举**：`Very Negative / Negative / Neutral / Positive / Very Positive`（非常消极/消极/中性/积极/非常积极·L2 情绪五级·polarity_index/色带/4×5 归因都依赖）
- **12345 诉求类型 → 情绪 5 级**（结合标题+内容·非仅诉求类型硬映射）：
  | 诉求类型 | 情绪 5 级 | 理由 |
  |---|---|---|
  | 投诉类 | 消极 / 非常消极 | 按严重度（结合内容·如紧急/强烈→非常消极） |
  | 求助类 | 消极 | 有诉求但非强烈负面 |
  | 咨询类 | 中性 | 中性 |
  | 建议·期盼类 | 中性偏积极（积极） | 建设性意见（对标「期盼」·但归入 Positive 不造新级） |
  | 表扬类 | 非常积极 | 正面 |
  | 其它/营商环境 | 中性 | 兜底 |
- **关键**：**不造「期盼」级**（会撞 polarity_index 公式/色带/归因）·把期盼归入 Positive/Neutral·用 `emotion_aspect` 或 `topic` 保留「期盼」语义（`_followupCue`/`_keywordRank` 层面）

### 决策 2 · 地点推断（用户同意）

- **方法**：内容地点词提取 → 主办部门街办归属 → 区域兜底 → 三级推断

## 二、两份输出文件 schema

### 文件 1 · `12345_治理清洗版.csv`（8 条要求）

| 输出字段 | 来源/处理 |
|---|---|
| `办件编号` | 保留 |
| `投诉时间` | 办件编号前 8 位（YYYYMMDD）·事件时间未知默认=投诉时间 |
| `事件时间` | 从诉求内容/办理结果提取·未知=投诉时间（区分） |
| `诉求类型_归` | 系统化：投诉 / 建议·期盼 / 表扬 / 求助·咨询 / 其它（参考标题+内容归纳） |
| `诉求标题_简` | 简化（噪声/停车/交通/垃圾…·参考大类中类小类） |
| `诉求内容_构` | 结构化：「时间 + 地点 + 事件 + 态度（积极/消极/中性）+ 诉求」 |
| `事发地` | 原始保留 |
| `地点推断` | 三级推断：内容地点词 → 主办部门街办 → 区域·细到区/街办/小区/道路·留空不强加 |
| `区域_清洗` | 代码→区名（420502→西陵区）·保留 |
| `大类_归` / `中类_归` / `小类_归` | 整合入归类（不删·映射到统一分类）·或保留参考 |
| `主办部门` | 保留 |
| `评价结果` | 保留（满意度·可作情绪佐证） |
| ~~大类/中类/小类~~ | 删除（整合入归类） |
| ~~协办部门/城运中心/办理结果/回复市民结果~~ | 删除（办理结果/回复作整理参考） |

### 文件 2 · `12345_情绪地图中转版.csv`（EMC 消费）

| 字段 | 内容 | EMC 对齐 |
|---|---|---|
| `办件编号` | 保留 | — |
| `投诉时间` | YYYYMMDD | time 维度（全局时间轴·manifest） |
| `polarity` | 情绪 5 级（Very Negative~Very Positive） | **L2 枚举·polarity_index 计算** |
| `polarity_score` | 5→1 数值（Very Positive=5…） | score 列（L2 用） |
| `emotion_intensity` | 强度（结合内容·语气/紧急度） | L2 intensity |
| `domain` / `element` | 4×5 归因（由大类/中类映射） | 4×5 归因·`_attach_4x5_attrs` |
| `topic` / `issue_label` | 中类/小类·问题标签 | topic/keyword |
| `place_name` | 地点推断（区/街办/小区/道路） | place_name |
| `lon` / `lat` | 地点坐标（可坐标化时） | 空间落图·geo_registry |
| `region` | 区域 | 行政区 |
| `source` | 2024年12345投诉数据_raw | 来源可溯 |
| `emotion_aspect` | 期盼/建议/表扬/投诉（语义保留） | 不撞 5 级·保留原始语义 |

> **EMC 消费链路**：geo_registry 注册为 `checkup_12345_*` 层（点层）→ density/grid/zonal 用 polarity/score 分析 → RAG 双轨对照（市民声音↔体检缺口）→ 空间落图（lon/lat 或 片区面层）
