## 〇、用户明确的基本原则（最高指引·已沉淀 KNOWLEDGE.md）

### 1. 纯回答稳定性 = 三支柱缺一不可
> ① **本地知识库完备度**（素材·事实卡/笔记/政策/案例）② **EMC 架构**（分类→范式映射·正确路由）③ **LLM 归纳总结能力**（综合素材+引用来源）。三者缺一不可。

### 2. EMC+RAG 产品定位
> 纯问答 → 得到**稳定、准确、全面**的相关信息（宜昌城市更新/城市体检专题）。核心价值 = 区别于网络搜索/其他 AI——**本地化 + 聚焦 + 专业 + 可追溯**的专业知识蒸馏。

## 一、修正后的知识问答路径（已实施·e2e 5/5）

```
rag_query 短路 → RAG 检索素材（知识库·第一支柱）
  → 架构路由知识问答范式（EMC 架构·第二支柱·注入知识问答指令·禁图层）
  → finalStep LLM 综合总结 + 引用来源（LLM 能力·第三支柱）
```

**关键**：RAG 检索出相关文件后**必须走 LLM 综合**（非零 LLM 拼列表）。零 LLM = 砍第三支柱·把检索结果当答案·用户验证否定。
