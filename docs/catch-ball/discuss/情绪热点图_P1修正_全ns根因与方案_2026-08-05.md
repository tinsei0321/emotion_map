## 〇、A/B 验证实测（真实 L2 数据·xiling_wujia_L2_T2·2500 点）

| 项 | 逐点 Gi\*（现状） | 500m 网格 Gi\* | 200m 网格 Gi\* |
|---|---|---|---|
| 输入 | 2500 点·score | 208 格（point_count≥3）·score_mean | 310 格·score_mean |
| 显著格 | **全 ns（0/2500）** | **全 ns（0/208）** | **全 ns（0/310）** |
| Gi_Z 范围 | -1.07 ~ 1.26 | -0.99 ~ 1.11 | -1.07 ~ 1.07 |

**根因（实测）**：
1. **score 方差小**：`score` std **0.377**（值域 0~1·分布集中在均值 0.558 附近）→ Gi* 是"局部 vs 全局期望的偏差/波动"·波动小 → z 全小（<1.96）→ 全 ns
2. **KNN 尺度漂移（glm 第一轮 B2 证实）**：k=8 平均邻居 **181m**（中位 132m·**50m~2.5km 跨度 50 倍**）
3. **网格化平滑了 Z 但未改变全 ns**——单元修正（500m/200m）**不是全 ns 的解药**（Z 分布几乎不变）

## 一、待两组评估的焦点

### 焦点 1：全 ns 根因判定（实测·agree/disagree）

- 根因 = score 方差小（0.377）+ 阈值 1.96 过严 + KNN 尺度漂移？还是另有？
- 网格化未改变全 ns——是否说明"输入粒度修正"（原 P1 核心）**不足以让 Gi\* 出热点**？

### 焦点 2：修正方案（3 候选）

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 降阈值 + 分级** | 保留 1.96 显著性分级·另加"倾向聚集"软分级（\|Z\|>1.0 即标·90% 档）·演示可见热点 | 演示有热点·统计诚实（标注置信度）| 阈值放宽=显著性弱化 |
| **B. 换 value_col** | 用 polarity_index（-2~2·std 0.696·方差大）替代 score（0~1·std 0.377）| 方差大 → z 更大·更易显著 | 极性≠强度语义·invert 语义要重设 |
| **C. 网格粒度 + 阈值协同** | 500m 网格 + polarity_index value_col + 阈值降到 90%（1.65）| 综合 A+B·演示可出热点 | 改动最大 |

**claude组 初步倾向**：**B 或 C**——方差小是根本（score std 0.377 vs polarity_index std 0.696·近 2 倍）；单降阈值（A）治标。

### 焦点 3：演示价值 vs 统计严谨

- 全 ns 下"显著聚集点"工具**演示空转**（与用户"情绪热点图要重做·效果不对"直接相关）——须让演示**有可见的热点**（聚焦关注区·演示逻辑链）
- 但 Gi\* 是显著性检验·不能为演示造假——**降阈值/换 value_col 是否算"为演示放水"**？还是合理的统计参数选择（置信度档位选择本就是分析者决策）？

### 焦点 4：与 KNN 尺度漂移的关系

- KNN 邻居 50m~2.5km 跨度 50 倍——**距离带权重（threshold=500m·transform='R'）**能否救？（glm 第一轮 P2 实验项）
- 但 P3 已后置（距离带实验在 P2·热点图内）——本轮是否提前做距离带？

### 焦点 5：改动范围（若修正）

- 修正在 P1 网格化内（core/spatial_analysis.py 新 grid-Gi\* 函数 + value_col 参数化 + 阈值参数化）·还是需要独立评估？
