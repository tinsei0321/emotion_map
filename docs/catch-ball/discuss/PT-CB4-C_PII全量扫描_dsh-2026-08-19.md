## 一、扫描方法

1. **字段名扫描**：自定义敏感字段名清单 + 正则匹配：
   - 清单：`电话`、`手机`、`姓名`、`联系`、`证件`、`身份证`、`办件编号`、`手机号`、`联系方式`、`证件号码`、`身份证号`
   - 对 GeoJSON 的 properties 键名、CSV 表头逐项匹配。
2. **值抽样正则**：
   - 手机号：`1[3-9]\d{9}`
   - 身份证/长数字：`\d{17}[\dXx]`
   - 对 GeoJSON 属性值、CSV 单元格、文本文件内容逐项匹配。
3. **脱敏规则**：
   - 手机号：前 3 位 + `****` + 后 4 位，如 `138****5678`
   - 身份证/长数字：前 3 位 + `*` + 后 4 位，如 `110***********1234`
4. 扫描脚本为临时 Python 脚本（未落盘），命令见文末可复现说明。
