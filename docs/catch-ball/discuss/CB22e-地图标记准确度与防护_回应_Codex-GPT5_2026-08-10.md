### 1.2 新增取证：降级结论 N/M 断链确认（焦点 1 的 ② 实锤）

- toolHistory 格式：`harness.js:670` 推 `第1轮·动作: generate_point_layer(...) → ${obs}`；obs 为 `tools.js:1384-1386` 的**三行**文本：① `地点标记：命中 N/M → 已生成图层...（来源：...）` ② `未匹配到坐标（诚实列出·不编造）：...` ③ tip 行（`已命中项目 → 点位图层...`）。

### 焦点 3：P1.2 jieba 用户词典全局污染 — **partial（影响面确认·方案建议独立 Tokenizer）**

- 影响面（全仓检索 `rg jieba`）：仅 3 处真实调用——`place_layer.py:133`（`jieba.lcut`，搜索路径）、`SCRIPT/emotion_analysis_v1.py:233`（`jieba.analyse.extract_tags`，L2 情绪关键词）、`SCRIPT/sim_performance_data.py:564`（同）。`core/topo_scanner.py`/`SCRIPT/emotion_lexicon.py` 仅为文档字符串提及。
- **同进程证据**：`api/routes.py:110` import `run_analysis_task`（emotion_analysis_v1）与 `api/geo_routes.py:427` import place_layer 在同一 uvicorn 进程——模块级 `jieba.load_userdict` 会**全局改变该进程的 L2 关键词分词**。反向污染（情绪文本被宜昌专名影响）实际存在但影响小（词典只加专名）、且测试出现顺序依赖。
- 方案建议：**place_layer 内建独立 `jieba.Tokenizer()` 实例 + 其 `load_userdict`**（jieba 官方支持多实例），零全局污染；`jieba.analyse` 走默认实例不受影响。若坚持全局 `load_userdict`，至少懒加载 + `try/except` 守卫。
- **词典文件缺口**：`DATA/place/` 当前**无 `yichang_places.txt`**（仅有 place_keywords.json / pois_wgs84*.geojson / zone_typology.json）——`load_userdict` 对不存在文件会抛异常，P1.2 必须随代码一并新建文件。
- 词典粒度：**仅专名**（葛洲坝/西坝/二马路/大南门/红星路/铁路坝/献福路/土门/三峡青年城/磨基山/至喜桥/三峡机场 等 20-50 条），可从 `DATA/place/zone_typology.json` 的 `area_subtags`（如 :24 二马路/大南门/红星路…）派生；不掺「中心/青年/老城」类泛词。

### 焦点 4：P1.3「老城中心」归类 — **partial（根因修正：挡「中心」而非「老城中心」）**

- 根因推导：`jieba.lcut('老城中心')` 预期拆为 `[老城, 中心]`；`place_layer.py:149-150` 「老城」被 `_ZONE_SUFFIXES`（:114 含「老城」）剥掉、余长 <2 被弃；「中心」2 字不在 `_AGGREGATE_WORDS`（:116）、不以任何后缀结尾 → 存活候选 `[中心]` → forward substring 全库扫「中心」→ 误导命中「中心人民医院」。与 claude组 实测现象完全自洽。
- **结论**：`_AGGREGATE_WORDS` 是**逐 token 精确匹配**（`place_layer.py:147`），jieba 不会产出「老城中心」整词 → 把「老城中心」加入 `_AGGREGATE_WORDS` **大概率无效**。正确落点 = `_AGGREGATE_WORDS` 加「中心」；「老城中心」仅对无 jieba 回退路径（`place_layer.py:135-140` 整串剥后缀）有意义，可作 `_ZONE_SUFFIXES` 双保险。
- 顺带评估：「中心人民医院」若 jieba 拆 `[中心, 人民医院]` → 挡中心后 best=人民医院 正确；若拆 `[中心, 人民, 医院]` → best=人民 仍偏泛——建议「人民」一并入评估清单，用纯函数测试锁住断言。
- 可定位性：`zone_typology.json:19` `ermalu_oldstreet` =「二马路-解放路核心老街」（area_subtags 含 二马路/大南门/红星路/解放路）即宜昌老城核心——「老城中心」语感上≈该区，但 `generate_point_layer` 只产**点**要素（`tools.js:1373-1377`），无单点/面 preset 可标 → 本轮诚实 unmatched（符合 B1「聚合类不强匹配」哲学），tier-2 面化留 A1 轮。不建议本轮为它建面 preset。
