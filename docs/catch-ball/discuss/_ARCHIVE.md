## 二 归档规则

1. **判据 = 主题生命周期**（非日期）：收敛定稿落盘 + 实施完成 + 无待办 → 该主题的**过程稿**（发起/评估/回应/执行记录/回收）可归档；**定稿/终审/拍板版常驻 `discuss/` 顶层**（结论永远一步可达）。
2. **触发时机**：每逢 CB 轮次收官（终审通过），收敛方顺手归档当轮过程稿——防 550 文件堆积重演。
3. **归档动作四步**：①`git mv` 进 `archive/<卷宗>/`（保历史）②更新 `_INDEX.md`（活跃索引·移除下沉条目）③卷宗 `_DIGEST.md` 补一行（如有关键结论）④全仓 grep 被移文件名·同步引用路径（cb-journal/KNOWLEDGE/_cb-index/交接卡）。
4. **在途保护**：卷四/卷五及相关交叉件永不自动归档——归档脚本/人工清单须带排除表（关键词+日期上限）。
5. **digest 纪律**：卷宗 `_DIGEST.md` 只做**导览**（每主题一行结论+指向现行权威源），**不复制权威内容**（口径注册表/CLAUDE.md/总账仍是单一权威源——防双头）。

