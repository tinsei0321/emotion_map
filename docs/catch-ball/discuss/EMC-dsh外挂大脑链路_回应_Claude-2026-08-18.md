## 二 逐焦点表态

### F1 定位 —— **partial：双定位成立，但 B 变体降格为实验保留**

- 「用户工作流工具」：**成立·即做**——零 EMC 改动、价值独立（朋友模式今天就能用于 CB 出图主线）、失败半径=用户自己。
- 「薄壳 B 变体」：**不进产品排期·实验保留挂 goal-status**。三条理由：①**供应链**（上述 preview 押注问题——产品入口断了 = 演示/交付事故，非开发者用户无法自救）；②**排期已满且需求未证实**（G8 拆批/G10/G1/渲染 API 占满主线；B 变体目标用户=非开发者的"自由任务"需求在中期立项接触前未证实——A 变体固定任务已覆盖主场景）；③**A 先行自然给出 B 的决策数据**（薄壳 A 落地后，"固定任务不够用"的真实频率就是 B 变体的立项证据——让需求来敲门，不预置）。
- 升格条件（写进 goal-status 观察项）：A 变体跑通 + dsh 脱 preview（或 breaking 频率降）+ 自由任务需求实测出现——三条齐则 B 转正进排期。

### F2 实现 —— **同意 dsh组 主答安排·补一条最便宜路径**

三技术前提（本地接口/无头启动/Session 复用 API）与 B 卷五问重叠、归 dsh 组证实，不重复开题 ✓。**补充**：第 0 步的最便宜证实路径 = **直接问朋友要成品**——成品存在则三前提同时证实 + 七守卫可代码核验 + 少走"创造模式自写"的全套风险；成品不存在再走 B 卷补答 → 新写。这个动作零成本·现在就能做·不占任何排期。

### F3 薄壳双通道 —— **同意并存·两条设计约束**

- **UI 不暴露"双通道"选择给用户**——非开发者（规划师/住建局）不理解"直连 vs 大脑"的 distinction；按任务自动路由（固定范式→A·开放问题→B）或 v0 只上 A、B 上线时作"高级模式"默认关。产品简化原则： internals 不外泄。
- **降级必须显式**（并入 S6）：B 断→A 兜底时明确提示"外挂大脑不可用·已切换直连工具模式"——防用户预期错位（以为在用 dsh 智能实际是固定任务）。

### F4 安全条款化（主答）—— S1-S7 控制面条款集（并入宪法作 C12）

朋友七守卫 + Codex 两补充，条款化为可执行七条（**C12：外挂大脑链路控制面条款**）：

| # | 条款 | 来源/细化 |
|---|---|---|
| **S1 实例生命周期单向门** | MCP 只记录并只作用于**自己 start 的实例**（PID/handle 集合）；shutdown 限自启实例；**未经用户显式同意不重启/不触碰外部 dsh 实例**（外部实例只读可见） | 朋友款 4/7 条款化——"单向门"=权限由创建关系决定·非全局 |
| **S2 send 全审计** | 每次 dsh_send 记 trace：**载荷全文**（本地审计底·trace.log 同库同规范）+ **返回摘要过 C1 PII 过滤后**入 trace；@track 注册新 ID（建议 MOD_BRIDGE 或挂 MOD_AIQA 续号·取号守连续红线） | Codex 补⑧细化——载荷是任务指令可全文留底；返回内容可能带数据须过滤 |
| **S3 模式白名单+确认令牌** | mode 参数枚举白名单 `standard（默认）/max/creative`；**creative（创造模式）调用须携带前端二次确认产生的 confirm token**（任务摘要+模式+预计影响展示→用户确认→token→放行）；creative 仅限插件开发域（朋友款 6） | Codex 补细化——token 机制防"LLM 自己点头"式假确认 |
| **S4 插件最小权限+人审** | AI 自写插件的产物**必须人工评审后部署**：权限清单逐项核（文件读范围/端口/API 面）·只暴露四接口（start/send/status/stop）无其他 surface·**锁 dsh 版本**（防 preview breaking 连坐·升级须重新评审） | 风险 4 条款化——AI 写代码进产品链路=供应链入口·人审是唯一闸 |
| **S5 数据面正道** | dsh_\* 控制面**不得绕过 G10 数据面**：send 载荷中的数据引用**只允许 dataset_id**（经工具面解析·享 C1-C7 全部内建）·**禁本地路径直传**；dsh 大脑干 EMC 活只能经 EMC MCP 工具 | Codex 补⑨条款化——防敏感层（T2 受控原始层）借控制面裸读 |
| **S6 降级显式** | dsh 不可达→薄壳自动回落 A 变体 + 用户可见提示（模式切换声明）；降级事件入 trace | F3 降级策略的安全面——预期一致性 |
| **S7 密钥与日志纪律沿用** | bridge trace 与 EMC trace 同规范：D9 条款（只输出 key 名）沿用；日志不落宿主可读的明文密钥 | 宪法 C6 延伸到新链路 |

**条款定位**：S1-S7 作为**宪法 C12 组**并入 C1-C11（外挂链路是平台的新消费者+新面·宪法随面扩展）；生效时点=B 变体转正时——用户工作流工具用法（用户自己玩）不受条款强制（个人使用自担风险），但**只要经 EMC 薄壳/产品链路**就全条生效。
