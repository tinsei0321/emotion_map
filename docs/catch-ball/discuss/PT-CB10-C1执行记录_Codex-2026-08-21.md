## 一、实现要点

### 1. 对话注入

固定文本：

```text
请打开 EMC 情绪地图：用 emc_status 轮询 8080 服务状态（每 5 秒一次，预热约 30-60 秒），
就绪(ready=true)后用一两句话欢迎我（可引 kb_facts 的 EMC 身份卡），并告诉我地图已在浏览器打开。
```

实现链路：

```text
currentWorkspace(ctx)
  → workspaces.connectWorkspace(workspaceId)
  → sessions.open(sessionId)
  → sessions.scope(sessionId).get('conversation')
  → conversation.send(SEND_TEXT)
```

证据：

```text
src/client/index.ts:16   固定文本
src/client/index.ts:85   startConversation
src/client/index.ts:98   conversation.send()
```

### 2. 服务启动与浏览器打开

插件源码不写死 office / home 用户目录，而是：

1. 从当前 dsh Workspace 的 `path` 取 EMC 仓根；
2. 拼接 `start_silent.vbs`；
3. 拼接 `vendor/dsh-emc-entry/emc-open.html`；
4. 全部经 `workspaces.openPath()` 调 host 正规通道。

路径推导：

```text
src/client/index.ts:102  currentWorkspace()
src/client/index.ts:109  joinWorkspacePath()
src/client/index.ts:133  start_silent.vbs
src/client/index.ts:135  vendor/dsh-emc-entry/emc-open.html
```

office rc.8 实测发现：直接 `host.openPath(http://127.0.0.1:8080/...)` 返回 ok 但未稳定弹出页面；改为打开仓内 `emc-open.html` 后，系统默认浏览器稳定打开并跳转 8080。

### 3. 状态与防连点

实现：

- 模块级 `running` 标志；
- 按钮 `busy` 状态；
- `pointer-events: none`；
- 90 秒 deadline 恢复；
- 就绪或打开完成后清理轮询。

连点实测：

```text
连续两次 click 后，EMC 会话数量 delta = 0
```

截图：`docs/c1-05-no-double-dialog.png`

### 4. 视觉与 token

按钮继续占用 `sidebar.footer.action` 插槽，视觉保持 v1。

自查结果：

```text
--dsw-alias-* 引用：7 处
硬编码 hex / rgba：0 处
```

证据：`src/client/index.ts:225-233`。
