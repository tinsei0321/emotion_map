## 一、技术接点（已核实）

- **harness `_quickIntent`**（harness.js:57-65）：已有 general 短路模式（概念/清单查询词 → general 直答）——B 路径可仿此加「数据查询」短路
- **diagnose intent**：含 `general`（prompts.py:200/291）——数据查询可判 general
- **L0 项目库数据形态**（结构化可查）：55 项目 51.33 亿/葛洲坝 12 个 11.07 亿/红星路 3 个 7.57 亿（260713）·危旧房 16.4 亿/汉宜村 18.06 亿（伍家岗）·体检数值（附件1/3）

## 二、方案草案

### 1. L1.5 事实卡数据层（Codex CB-22 建议）

新文件 `ai_qa/outlet_kb/urban_renewal_knowledge.py`：从 L0 提炼**结构化事实卡**（每条 ≤80 字 + source 指针）：

```python
PROJECTS = [
    {'id': 'URP-P01', 'city': '宜昌', 'name': '2025-2027 更新典型片区+机制项目',
     'detail': '55 个·总投资 51.33 亿', 'source': 'docs/urban-renewal-plan/_INDEX#00-03(260713)'},
    {'id': 'URP-P02', 'city': '宜昌', 'name': '葛洲坝片区项目', 'detail': '12 个·11.07 亿',
     'source': 'docs/urban-renewal-plan/_INDEX#00-03'},
    {'id': 'URP-P03', 'city': '宜昌', 'name': '危旧房改造', 'detail': '16.4 亿（伍家岗区）',
     'source': 'docs/urban-renewal-plan/_INDEX#00-04(伍家岗十五五)'},
    ...
]
INDICATORS = [  # 体检数值卡（结构隐患 42 栋等）
    {'id': 'URP-I01', 'city': '宜昌', 'name': '结构安全隐患住宅', 'value': '42 栋',
     'source': 'docs/urban-renewal-plan/_INDEX#03-01(附件1)'},
    ...
]
CHECKUP_ISSUES = [...]  # 问题清单
```

**数据来源**：三组提炼笔记 + L0 分类目录（00-宜昌专项/03-指标）——确定性提取·非 LLM 编造。

### 2. 查询工具 `query_knowledge_base`（Dumb Tool）

```python
# tool_contracts 注册
'query_knowledge_base': {
    'name': '知识库查询',
    'slots': {'city': '宜昌/伍家岗/葛洲坝...', 'topic': '项目/指标/体检问题/案例/政策'},
    'desc': '从 L0 知识库（城市更新/城市体检专题）查询结构化事实·返回 Top-N 条目+来源',
    'dumb': True,  # 确定性·无 LLM
}
```

**查询逻辑**：`city + topic` 过滤 L1.5 事实卡 → 返回 Top-N（≤5 条）+ source 指针。
- 简单查询（项目/指标）：确定性 WHERE（city/topic 精确匹配）
- 复杂语义（跨文档综合）：CB-22c RAG 后置

### 3. 接入（general 短路 + 知识查询意图）

- harness `_quickIntent` 加「知识数据查询词」（项目/指标/体检问题/更新项目）→ 短路
- 调 `/aiqa/knowledge_query`（新端点）→ `query_knowledge_base` → 返回事实卡 + 来源
- finalStep 注入查询结果（intent-gated·Top-N + 来源标注）

### 4. 与 A 路径/出口契约的关系

- **B 不产出口卡**（直答文本·不走 outlet_card）——glm 强调勿混
- B 查的是 L0 知识库（事实卡）·A 引用的是 case_library/L0 路径——**数据源同源·用途不同**
- 出口契约 = 分析结果格式化·B = 数据查询——互补

### 5. 体积守卫

- query 结果 intent-gated 注入（仅命中知识意图）+ Top-N（≤5 条）+ 来源
- 新增「知识查询注入后 <8000B」断言
