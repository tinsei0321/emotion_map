## 一、任务与定位

**目标**：基于前 6 页的落图结果，形成 page7「问题与需求小结」，用图、数、表三种形式，证明中心城区的问题**空间上集中在少数社区**，落到结论——城市更新必须优先在这几个地方开展、重点片区应划在这里。

**底层逻辑**：体检（客观·能发现市民感知不到的隐患）+ 12345 热线（主观·能发现体检没测的需求）双轨互补 → 聚焦两个方面（安全韧性=底线 / 民生基础=急难愁盼）→ 双轨落图 → 空间聚集 → 双高社区 → 重点片区结论。

**红线**：两个方面 + 片区 = 结论（分析过程不消费 board）；三大片区边界无需在本任务内精确界定（片区由问题聚集推导，本任务只负责"问题集中区域"这一份叠合内容）。

## 二、双高社区定义（方法论·待 zcode 复核）

### 数据源（三张社区级矩阵）

| 轨 | 文件 | 类别 | 社区数 |
|---|---|---|---|
| 体检安全 | `DATA/analysis/安全韧性/安全韧性_社区3类矩阵.csv` | 市政管网 / 安全消防 / 住房 | 70 |
| 体检民生 | `DATA/analysis/民生基础/民生_社区5类矩阵.csv` | 公服 / 住房 / 停车 / 交通 / 物业 | 92 |
| 12345 | `DATA/analysis/12345主观/12345_社区x9类.csv` | 安全4（管网/出行安全/消防/环境）+ 民生5（噪声/停车/住宅/出行/物业）+ 其他 | 145 |

### 双高定义（Codex 建议）

- **安全量** = 体检安全（3 类之和）+ 12345 安全（管网安全 + 出行安全 + 消防安全 + 环境安全）
- **民生量** = 体检民生（5 类之和）+ 12345 民生（噪声 + 停车 + 住宅 + 出行 + 物业）
- 民生总量（8873）约为安全总量（2419）的 3.7 倍，**不可比绝对值** → 各自转**分位排名**标准化
- **双高社区 = 安全 ≥ p75 且 民生 ≥ p75**（各自前 25%）

### Codex 初算结果（社区并集 161，待 zcode 复核）

- 双高社区（p75 双阈值）= **27 个**
- 四象限：双高 27 / 安全单高 14 / 民生单高 14 / 双低 106
- 双高前 8（按合计降序）：港务、汕头路、宝联、八一路、东星、张家湾、魏家湾、伍临路
- 前 8 集中度：民生 3444 / 8873 = **38.8%**；安全 510 / 2419 = **21.1%**（8 社区 ≈ 社区总数 5%）
- 前 5 集中度：民生 2637 / 8873 = **29.7%**；安全 406 / 2419 = **16.8%**

### 需 zcode 复核 / 决策的点

1. 阈值用 **p75（27 个）** 还是更严 **p90（约 top 10%）**？图上"凸显几个"建议标注 top ~10，表列 top 12~15，数字段落用 top 5~8 集中度。
2. **合并双高会被 12345 量主导**（民生 8394 vs 体检 757）：体检独有的"结构隐患"信号（西峡/深圳路/金安岭/镇境山，page3 的 42 栋危房）会被稀释。是否需要在图上用独立符号兜住"体检独证·结构隐患"，保留体检独特价值？（Codex 建议：必须兜住，否则丢信息。）

## 三、图方案（综合图·凸显双高）

**主图 = 社区面「双变量着色」（bivariate choropleth）**，不推荐 3D：

- 双色轴：安全 = 红系（浅→深，按安全分位）、民生 = 蓝系（浅→深，按民生分位）；每个社区按（安全分位、民生分位）双向着色
- 「双高」象限（右上角）自然落成深紫/品红，一眼看出"两边都高"
- 双高社区加边框 + 标注社区名（只标 top ~10）
- 底层叠加图斑：体检点（方块符号）+ 12345 点（圆点符号）半透明，证明不是空着色
- 附注符号：圈出 page3 体检隐患社区（西峡/深圳路/金安岭/镇境山），标"体检独证·结构隐患"

**不选 3D 的理由**：柱状高度只能表达单一总量，丢掉"安全×民生"二维语义，静态 PPT 上也难读。

**备选（可加）**：右下角小散点图（X=安全分位、Y=民生分位，每点=社区，右上象限=双高），与主图联动。

## 四、数方案（结论语言·观点先行）

一到两段，明确表达"城市更新必须优先在这里、重点片区必须划在这里"。初拟（数字待 zcode 复核后替换）：

> 中心城区的问题高度集中在少数社区：港务、汕头路、宝联、八一路、东星等 **8 个双高社区仅占社区总数的 5%，却承载了约 39% 的民生诉求和 21% 的安全问题**。这里是"急难愁盼"（民生）与"短板弱项"（安全/设施）双重叠加的区域——**城市更新必须优先在这里开展，重点片区应划在这里。**

> 另有西峡、深圳路、金安岭、镇境山等社区，结构/围护/燃气隐患集中，但市民热线少诉，属于"体检才能发现的底线隐患"，同样必须纳入优先治理。

第二句对应开篇"补齐城市建设发展短板弱项"（体检独证），第一句对应"聚焦解决群众急难愁盼问题"（热线+民生）。
