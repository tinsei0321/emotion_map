## 〇、一句话结论

**全 ns 是真实问题且"输入粒度修正不够"的结论成立；但根因表述三处需修正：①"score 方差小→z 小"机制 sign 反了（Gi\* z ∝ 局部偏差/(S×邻域因子)，S 小反而放大 z；真正主因是**局部邻域均值与全局均值偏差小**——信号弱）②实测 score 分布是双峰非"集中在均值附近"（Very Positive 1068 + Very Negative 784 主导）③"阈值 1.96 严"不是根因——Gi_Z max 仅 1.26，**低于 90% 档 1.65，方案 A（降阈值到 90%）在这个数据上必然仍全 ns**，降阈值救不了。推荐 C 的变体：**polarity_index 换字段（B）先做 A/B 实测 + 阈值三档（90/95/99）参数化 + 距离带权重提前纳入（P1 内 A/B）**——其中**距离带是最可能治本的杠杆**（KNN 2.5km 邻域跨城平均化直接压制局部偏差），但任何方案都不能凭"std 大"断言有效（Gi\* z 对值域线性缩放不变），必须以 z 分布实测为准；统计严谨底线 = 不设"必须出热点"目标，若 A/B 全参数仍无显著聚集，诚实呈现"无显著热点 + 解释"同样是有效演示。**

## 一、逐焦点评估

### 焦点 1：全 ns 根因判定

**判定：partial（结论方向对·根因表述三处需修正）**

证据与修正：
1. **"score 方差小 → z 小"机制 sign 反了**：Gi\* z = 局部加权和偏差 / (S × 邻域因子)（第一轮文档 1.2 公式）——S（全局 std）在**分母**，S 小反而放大 z。真正决定 z 的是**局部邻域均值与全局均值的偏差**（分子）：2500 点 max |z|=1.26 → max 局部偏差 ≈ 1.26 × 0.389 × sqrt(1/8) ≈ 0.17——**局部 8 邻居均值始终贴着全局均值 0.548 走，说明该数据在 KNN 邻域尺度上几乎没有空间对比度**（无/弱聚集信号），这才是全 ns 的机制主因。
2. **"分布集中在均值 0.558 附近"不实**：实测 score 为**双峰分布**（Very Positive 1068 / Very Negative 784 / Neutral 460，score 大量落在 0~0.04 与 0.9~1.0 两端），std 0.389（我实测，与 0.377 接近，差异可能来自样本筛选）——std 本身对 0~1 有界变量是中等值（均匀分布约 0.29），不是"过小"。
3. **"阈值 1.96 严"不是根因（决定性）**：Gi_Z 范围 -1.07~1.26，max |z| **1.26 < 90% 档 1.65**——任何 ≥1.28 的阈值都全 ns。降阈值到 90% 根本不出热点，必须降到 ~80%（1.28）以下才有输出 = 实质放水。
4. **"网格化平滑 Z 但未改变全 ns"成立**：单元修正（500m/200m）在弱信号下只是对弱局部偏差再平均，当然不改变全 ns——**输入粒度修正确实不足以让 Gi\* 出热点**（原 P1 核心需扩围，方向正确）。
5. **KNN 尺度漂移是真实且关键的**：点云 POI 聚集不均（old street 密/郊区疏），50m~2.5km 跨度使邻域尺度跨 50 倍——稀疏区 2.5km 邻域≈跨城平均，局部均值必然贴近全局均值 → z→0。**这是比阈值更接近根因的杠杆**（见焦点 4）。

### 焦点 2：修正方案选择（A / B / C）

**判定：A 不可行（决定性）· 推荐 C 变体（B 先 A/B 验证 + 阈值分档 + 距离带）**

证据与建议：
1. **A（降阈值到 90%/1.65）在此数据上必然失败**：max |z|=1.26 < 1.65——执行即白改；若为出热点把阈值降到 <1.28（80%），则彻底失去显著性意义（见焦点 3 底线）。
2. **B（换 polarity_index）值得 A/B 实测，但"std 0.696 vs 0.377 → z 更大"的理论依据不成立**：Gi\* z 对值域的**线性缩放不变**（分子分母同 scale）——只有 polarity_index 相对 score 是**非线性对比增强**（5 级计数指数：全负格 pi=-2、全正格 pi=+2，格间对比度可能高于 score_mean）时 z 才可能升。我的 area_seed 级粗算 pi std 1.34（978 格、多小样本格）显示 pi 对比度确实大，但 500m 网格（208 格）会稀释——**必须实测 500m 网格 pi 的 z 分布**，不能凭 std 断言。
3. **推荐 C 变体**（P1 内参数化三件套）：`value_col` 参数（score/polarity_index）+ 阈值三档（90/95/99 输出 tier，默认 95 判定 + 90 倾向标记）+ **权重参数（KNN/DistanceBand，见焦点 4）**；默认参数由 A/B 数据表驱动（score+KNN / polarity_index+KNN / polarity_index+500m 距离带 × 逐点/500m 网格，出 z max/p95/显著数矩阵），用户拍板。
4. **invert 语义要重设**：polarity_index 高=正面（与 score 高=正面同向，但 pi 已编码极性），invert 后"高值=负面聚集"方向与 score 一致——需在文档/图例明示并测试，防方向错位。

### 焦点 3：演示价值 vs 统计严谨

**判定：agree（演示需可见热点）+ 3 条严谨底线**

证据与建议：
1. **降阈值到 90% 档 + 诚实标注不算放水**：置信度档位选择本就是分析者决策（ArcGIS 惯例 90/95/99 三档）——前提：图例/口径明示"90% = 倾向聚集"，保留 95/99 档数据供深读；**90% 只是软标记，不能当"显著热点"宣称**。
2. **"必须出热点"不能成为参数选择的唯一动机**：若 A/B 显示任何参数组合（含距离带）都无显著聚集，**诚实的"无显著热点 + 解释（数据在邻域尺度无空间聚集）"同样是有效演示**——工具会用、不造假，这比"调参凑热点"更符合演示逻辑链的"聚焦关注区"（无关注区也是一种结论）。
3. **换 value_col 是合法换检验对象，但理论依据须是"局部对比度增强"而非"方差大"**；**防单数据集过拟合**——xiling_wujia 一个样本调参后，须用第二个数据集（yichang 全域或 ermawu）交叉验证，否则默认参数绑死演示数据。
4. **底线**：阈值禁止低于 90%（1.65）作为默认（80% 以下 = 无统计意义放水）；所有参数显式暴露 + 图例标注，不隐藏。

### 焦点 4：距离带权重能否救（KNN 漂移）· 是否提前做

**判定：可能且是最关键杠杆·建议提前做（P1 内）**

证据与建议：
1. **机制上可能救**：KNN 2.5km 邻域=跨城平均直接压制局部偏差；固定距离带（如 500m，匹配商圈/片区聚集尺度）下局部均值偏差更大 → z 升。**但非保证**——若数据空间随机（无聚集），任何权重都全 ns；必须 A/B 实测（500m 距离带 vs KNN k=8，同 500m 网格 pi）。
2. **实现成本低**：`libpysal.weights.DistanceBand` 已在 hot_spot_analysis 的 import 块（core/spatial_analysis.py:44），esda/libpysal 已在 requirements——权重参数化是一处分支 + 岛屿兜底（无邻居格判 ns，transform='R' 已用 :87）。
3. **建议提前到 P1 内**（而非 P2 实验）：它是"能否出热点"的**关键变量**（比阈值更治本），且与 P1 网格化天然同批次（同一 A/B 矩阵）；P3 后置不受影响（P3 是编排器并行，与统计权重无关）。
4. 注意：距离带 threshold 建议 500m（对齐 500m 格对角线×1.5~2 的既有讨论）+ 可选 300m 对照；岛屿格判 ns 而非降级 KNN（保持尺度一致）。

### 焦点 5：改动范围（P1 内参数化 vs 独立）

**判定：P1 内参数化即可·不需独立专题**

证据与建议：
1. 改动集中：`hot_spot_analysis` 扩展三参数（value_col 已有/阈值档位/权重类型）+ 新增 grid-Gi\* 函数（create_square_grid 复用）+ 测试——单函数级改动，P1 内完成；**不需独立评估轮**（A/B 数据表作为 P1 验收物）。
2. **A/B 矩阵标准化**（P1 交付前出表）：参数 × 数据 = z max / p95 / 显著数（90/95/99 三档）——用户据此拍板默认参数；表随代码入库（docs/），防"调参无记录"。
3. **验收含"无显著热点"路径**：全 ns 时前端呈现方案（"无显著热点 + 解释文案 + 90% 倾向标记（若有）"）作为 P1 完成定义一部分，防演示空转。
4. **红线确认**：本修正不涉及四态出口 / finalStep D019 / diagnose ✓。
