## 〇、B 路径定位（CB-22 架构定稿）

```
问句 → _quickIntent 分流：
  KNOWLEDGE_QUERY_KW（结构化：有哪些项目/体检问题/指标）→ B 路径 query_knowledge_base（确定性 WHERE·先）
  RAG_QUERY_KW（开放语义：如何/为什么/哪些适合·跨文档）→ rag_search（向量·后）
  B 未命中 → 降级 rag_search（召回兜底）
```

**B = 确定性结构化查询**（精确 WHERE·防幻觉）·**RAG = 开放语义召回**（向量相似）·互补不混。
