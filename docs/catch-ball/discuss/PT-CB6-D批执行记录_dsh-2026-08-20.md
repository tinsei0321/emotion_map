## 二、实现说明

### D1：zonal_stats / rank `sort_by`

- `zonal_stats` 新增 `sort_by`，枚举 `point_count|polarity_index|score_mean`，默认 `polarity_index` 保持向后兼容。
  - `point_count`：按件数降序，不做极性加权。
  - `score_mean`：按均值降序。
  - `polarity_index`：维持原 abs 降序。
- `rank` 同扩：
  - `point_count` / `score_mean`：按对应字段降序。
  - `polarity_index`：维持 `by=worst/best` 方向语义。
- 非法 `sort_by` 返回语义化错误。

### D2：zonal_stats 描述

- docstring 增加：
  `layer_output=True 返回 geojson 可直接 render_spec 内联铺图（推荐用于出图链）`

### D3：rag_query 描述

- docstring 明确三点：
  - 策展来源：本地治理知识库
  - 检索维度：知识类、非空间
  - 适用场景：口径·规则·背景问答·非空间分析

### D4：main() stderr

- `_safe_print` 支持 `file` 参数。
- main 的 `[OK]` 启动行输出到 `sys.stderr`，保持 stdout 纯净（仅 JSON-RPC 帧）。

### D10：render_client.js 着色语义分派

- `community_choropleth_v1` 分支：
  - `value_field` 含 `polarity` 子串或等于 `score_mean` → 极性路径：
    - 使用同源 `piToNorm` 写 `_grid_norm`
    - 使用同源 `polarityStops('overall')`
  - 其余 → 维持计数路径：`_normCommunityCount` + `defaultPaint('zonal','polygon','count')`
- 未改默认 `value_field`，未引入第三种着色路径。

### D11：community_caliber K-C1 校验

- 新增 `K_C1_COMMUNITY_SCOPES = (174,154,118,193,130)`。
- dataset 路：
  - 已知 scope（`page7_12345_top10`/`page7_12345_top20`=154，`base_174_aggregate_area`=174）自动填 `community`。
  - 与调用方声明不一致时，返回 `caliber_lite.community_warning` 告警字段（不阻断）。
- inline 路：
  - 非法值（不在 K-C1 枚举）返回语义化 `hint`，不写盘。
- 零 LLM、纯规则查表。

### D12：demo_pioneer.py

- 三处 `zonal_stats` 调用均显式传 `sort_by='point_count'`，与“件数口径/最密集”命名一致。

### D13：render_routes.py

- 新增 `_safe_print(msg, file=None)`。
- 两处裸 `print(..., file=sys.stderr)` 改为 `_safe_print(..., file=sys.stderr)`，消息保持 ASCII `[WARN]` 标记。
