## 二 逐项对接评估（五个工作面 · 四段式）

### 面① ai_qa prompt 体系（人设/范式/分流器/出口卡文案）

**现状**：`ai_qa/prompts.py` 四阶段 prompt builder（diagnose 诊断卡 / agent_step ReAct 每轮 / answer 最终结论 / optimize 优化器，prompts.py:1-11）；`ai_qa/manifesto.py` 领域宪法（核心概念/L0-L4 管线/4×5 归因/意图三分类 A/B/C/四态出口契约，manifesto.py:14-90）；条件注入已精瘦化（人民城市理念仅概念问注入 prompts.py:31-39、final 极瘦去 MANIFESTO prompts.py:168-170、domain_lens 条件注入 prompts.py:176-179）；few-shot 诊断卡示例 6 条全正例（prompts.py:432-460）；诚实出口四态由前端 harness.applyQualityDefense 代码防线守（prompts.py:8 注释）。

**OPUS-5 对应观点**：分层结构（S1/S2：宪法→场景→工具 schema）与 MANIFESTO+TEMPLATE+附录拼接完全同构；条件注入与 P7「知识必须挣得位置」同思想（CB-10 P0-4 省 130B 的决策方向正确）；P2 简洁与回答公约「简短·不废话」（manifesto.py:77）吻合；P3 诚实默认与「禁编造图层名/数字」（manifesto.py:61）吻合。

**差距**：(a) **few-shot 只有正例**——OPUS-5 的 S5 正反例成对（如「Boundaries」组 good/bad 对照 L931-945），对 Flash 的边界判定（general vs knowledge_qa，prompts.py:219-224 的判据对比句）可能有增量；(b) N1 类语言禁令未显式化（中文语境弱相关，EMC 已有「不恭维」manifesto.py:77）。

**可否吸收**：部分可吸收，但受限——diagnose prompt 是 eval-anchor「永不动内容」（prompts.py:626 注册表），动 few-shot = 动 eval 基线（见 F1 焦点）。**结论：吻合度五面中最高，差距一处且被门禁约束。**

### 面② dsh agent loop（思维链成本控制、契约约束、双模预设）

**现状**：思维链成本诊断（内部编号：CB42 讨论线）已钉根因——`reasoningEffort=max` 全局常驻致每步固定推理税（改列名 17 字符 thinking 也要 2-13.6s），总纲定为「让不需要思维的任务不进思维循环」；双模预设已落地：快分析档 emc-analysis（flash/low/EMC 八件+只读检索/15 步硬预算）与研究档 emc-research（max/全工具/无预算），实测快分析 29.7s（`docs/catch-ball/discuss/PT-CB8-T7执行记录_Codex-2026-08-21.md:14-18`）；升级三信号=机械规则禁 AI 分类器（`docs/catch-ball/discuss/PT-CB7-主执行记录_Qoder-2026-08-21.md:85`）；EMC 内部 effort 分档已裁为观察项（QA 壳冻结期不动 llm.py）。

**OPUS-5 对应观点**：P6「按复杂度分档思考」（L2047-2049）是 Anthropic 官方口径的「简单问题不深思考、潜伏复杂性才开 extended thinking」——与 CB42 五契约方案之首「阶段化 effort」完全同构，且是**模型内置行为层面的业界实证**（证明分档是官方认可的合理形态而非权宜）；T14「工具调用规模匹配复杂度」（1/3-8/8-20 分档）与 EMC「最少轮次原则·1-2 轮即答/最多 6 轮」（prompts.py:97）同构。

**差距**：层次差异——OPUS-5 的分档是模型厂商内置（用户不可配），dsh 侧是 harness 配置（reasoningEffort）。「提示词里写简单操作别思考无效——推理深度由参数控制」（CB42 结论）在 OPUS-5 中得到反向印证：Anthropic 是用 thinking_behavior 系统指令+模型训练实现的，不是靠劝说。

**可否吸收**：**引用级吸收**——作为 effort 分档讨论的业界佐证材料登记，非代码吸收。QA 壳冻结期纪律不因此松动。

**OPUS-5 对应观点**（本面是 OPUS-5 最大金矿——记忆文件系统占全文 39%）：
- T3 事实来源纪律（`[stated]` 只记用户原话、排除推断/研究输出/建议）与 T5-T7 校准三原则（一次提及不泛化/确认形状≠确认细节/durable phrasing）——对 RAG 素材卡入库规范有直接参考价值：知识卡应记录「证据说了什么」而非「我从中推出什么」，一次证据不支撑泛化结论，表述优先用耐久措辞而非易过期数值；
