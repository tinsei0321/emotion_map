## 一 工程拆解（逻辑层 → 工程层）

**逻辑层（三条通道两种身份）**：
- 通道 A「注册层直传」：参数为 manifest preset_id → 后端查 usage 精确拦截（本轮主体）。
- 通道 B「已加载层转 fc」：前端 ref() 把地图上已加载的 preset 层解析为匿名 GeoJSON 直传 → 后端无法判身份 → **前端按 presetId 标记拦截**（range-presets.js 加载时标记 `L.presetId`）。
- 通道 C「匿名 send-in」：$n 中间产物 / 用户上传 → 放行（裁决 2）。

**接缝设计（单一权威+多消费方投影）**：manifest=唯一权威 → `/geo/catalog` 透出 usage（投影）→ 前端 `_usageBlocked` Map（投影缓存）+ 后端 `validate_input_usage`（权威兜底）。未来 MCP 工具面直接复用同一 Python 守卫函数（CB42 §三第 5 步的挂点即此）。
