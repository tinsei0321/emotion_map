## 〇 定位与架构

新建 **`tools/mcp_server_emc.py`**：FastMCP stdio server（对齐仓内先例 `.claude/mcp_servers/vision_bridge_server.py` 的 `from mcp.server.fastmcp import FastMCP` 用法），把七个既有后端能力包装为标准插座工具——**任何通用助手（zcode/claude/codex/dsh）经 MCP 协议即插即用**。

架构铁则：
1. **纯只读包装**：七工具零写盘、零副作用、零 LLM 调用（v1）；不改任何既有后端文件；
2. **重依赖惰性导入**：geopandas/rag 等只在工具函数体内 import（server 启动轻快）；
3. **追踪埋点**：模块顶部 `register_track_id` 注册 **F_021-F_027**（连续接 F_020·每工具一号）+ 每个工具函数挂 `@track('MOD_AIQA.F_02x', track_args=False)`；
4. `print` 全走 `_safe_print`（参照 tools/check_caliber.py 的实现拷贝）；代码禁 emoji；
5. **caliber 对象**（三张说明标签之①·拍板清单第 4 项）：每个工具返回值必带 `caliber` 字段：
   ```python
   {'scale': '<尺度>', 'semantics': '<语义>', 'limits': '<禁用边界>', 'refs': ['口径注册表 K-xx', ...]}
   ```
   各工具的取值见下表（refs 指向 `docs/urban-renewal-plan/00-宜昌专项/_口径注册表.md` 的卡 ID）。

## 一 七工具规格（逐一）

### ① list_data（数据说明书·标签②）

- 输入：`{include_demo: bool = False}`
- backing：`core.geo_registry.list_point_layers()`（点层）+ `DATA/boundaries/presets/manifest.json`（面/边界层·直接 json 读）
- 返回：`{point_layers: [{id, label, level, fields, dtypes, crs, usage:'input'}], presets: [{id, label, geometry, usage, name_field}], count, caliber}`
  - geometry 由 file 后缀推断（.geojson→按 nameField 存在否推 point/polygon 不做几何检测·后缀+nameField 有则 'polygon' 否则 'point'·拿不准标 'unknown'）；
  - **不返回任何样例值/样本行**（C1 脱敏纪律 v1 简化——只有字段名与类型）；
  - presets 项 `usage != 'input'` 的仍列出但带 usage 标记（让宿主知道存在但禁作输入·G-2）；sim/demo 项默认不列（include_demo=True 才列·C2）。
- caliber：`{'scale': '数据资产清单', 'semantics': '可供分析的点层与边界层目录（开卷定参的查询面）', 'limits': '结论层（usage=analysis_output）禁作空间操作输入', 'refs': ['G-2', 'K-C1']}`

### ② rag_query（带来源知识检索）

- 输入：`{query: str, k: int = 5 (1-10), synthesize: bool = False}`
- backing：`from tools.rag_index import search` → `search(query, k)`（返回结构见 `api/aiqa_routes.py` post_rag_search·`{results:[{score, source, type, data_dim, text}], count, dim_counts}`）
- 返回：backing 原结构 + `caliber` + `synthesize` 状态字段；**v1 约定**：`synthesize=True` 时**不调 LLM**，返回附加 `guidance` 字段（"v1 未接后端综合：请宿主基于以上带来源素材综合，注明来源与维度；避免把宏观倾向说成微观结论"）并标 `synthesize: 'deferred_v2'`——诚实降级不假装。
- 索引未构建：返回 `{ok: False, hint: '索引未构建：py tools/rag_index.py --build'}` 不抛异常（对齐后端行为）。
- caliber：`{'scale': '知识检索', 'semantics': '本地知识库向量检索（非穷尽）·结果为素材非结论', 'limits': 'Top-K 召回非全量；结论须综合并注来源；勿将倾向表述为精确值', 'refs': ['K-01']}`

### ③ kb_facts（行业事实卡）

- 输入：`{domain: str = '' (checkup|renewal|base 留空=全部), keyword: str = ''}`
- backing：先 `grep -rn "def query_knowledge_base" ai_qa/` 找到真身（Codex R1 记录其在 outlet_kb·F_018 已注册）；按其真实签名调用。
- 返回：`{facts: [...], count, caliber}`；每条 fact 自带 source/年份（既有结构原样）。
- caliber：`{'scale': '事实卡', 'semantics': '本地蒸馏的权威事实（带来源年份）', 'limits': '事实卡非实时数据；引用须带来源', 'refs': ['K-01']}`

### ④ outlet_card（行业出口卡·对话级）

- 输入：`{question: str, result: dict = {}, diagnose: dict = {}}`
- backing：`from ai_qa.outlet_kb.build_outlet_schema import build_outlet_schema` → `build_outlet_schema(diagnose, result, question)`（确定性·零 LLM·参照 `api/aiqa_routes.py` post_outlet_card）
- 返回：`{cards, card, caliber}`（未命中 cards=[]·原样诚实）。
- caliber：`{'scale': '答案级出口', 'semantics': '确定性组装的行业出口卡片（结果范式 agent 第三段·对话级）', 'limits': '字段缺失降级不编造；文件级导出属 v2', 'refs': ['K-01', 'K-03']}`

### ⑤ zonal_stats（单元聚合）

- 输入：`{boundary: str (preset id), layer: str = 'yichang_l2_t1' (点层 id), agg_cols: list = ['score'], top_n: int = 10 (1-20)}`
- backing（三步·参照 `api/geo_routes.py` 同名端点的解析逻辑）：
  1. `from core.geo_registry import resolve_boundary, resolve_points` → 面 gdf/点 gdf；
  2. `from core.spatial_analysis import aggregate_by_polygons` → `aggregate_by_polygons(points, polys, agg_cols, polygon_name_col=<面层名Field>)`；
  3. 排序取 top_n。
- 返回：`{rows: [前 top_n 行 dict], row_count, truncated: bool, caliber}`（**体积纪律**：rows 硬顶 20 行·全量行数用 row_count 表达）。
- description 里声明耗时量级（首次调用含 geopandas 冷启动约 10-20s）。
- caliber：`{'scale': '宏观/中观（单元聚合）', 'semantics': '情绪点按边界单元的统计聚合——宏观倾向判断', 'limits': '非逐户调查结论；社区数口径见 K-C1；勿当精确诊断', 'refs': ['K-01', 'K-C1']}`

### ⑥ buffer（缓冲影响圈）

- 输入：`{center: str (preset id), radius_m: int = 500 (50-3000), layer: str = 'yichang_l2_t1', dissolve: bool = True}`
- backing：`resolve_boundary(center)` → gdf.__geo_interface__ 得 fc → `from core.buffer_analysis import create_buffer` → `create_buffer(fc, radius_m, dissolve)`；圈内点计数用 resolve_points + shapely within（或复用 geo_routes buffer 端点内已有聚合逻辑·以其为准）。
- 返回：`{area_km2, point_count, buffer_fc(仅要素≤5 且顶点少时返回·否则 'fc_omitted': True + 提示用 EMC 前端渲染 v2), caliber}`。
- caliber：`{'scale': '中观（设施影响圈）', 'semantics': '设施周边半径内的情绪聚合（半径语义=尺度表·社区250/区500/主城1000）', 'limits': '半径为可达性近似非服务边界；结论属影响面判断', 'refs': ['K-C1']}`

### ⑦ rank（排序评价）

- 输入：`{by: str = 'worst' (worst|best), layer: str = 'yichang_l2_t1', boundary: str, top_n: int = 5 (1-20)}`
- backing：同 ⑤ 的三步聚合 → 按 polarity_index（或 agg_cols 主列）升/降序 → 取 top_n。
- 返回：`{rows, row_count, caliber}`（同⑤体积纪律）。
- caliber：`{'scale': '中观（排序落点）', 'semantics': '按极性指数的单元排序（最差/最好 Top-N）', 'limits': '排序基于聚合指标非原始诉求逐条复核；"最差"为统计表述', 'refs': ['K-01']}`
