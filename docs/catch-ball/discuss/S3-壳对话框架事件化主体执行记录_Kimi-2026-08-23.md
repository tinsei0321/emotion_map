## 白话摘要

把 AI 聊天窗口的「内部对讲系统」改装成了标准插头式的事件广播——以前窗口和引擎之间是 14 根私家电话线，现在全部改成小区广播电台：谁想听就订阅哪个频道（思考过程频道、工具执行频道、成品渲染频道各走各的线路，互不掺和）。

但这带来一个问题：新广播的「发射塔」（S4 后端）还没建好，怎么证明家里的收音机都好使？答案是造了一个「假电台」（mock 对端）：它按标准事件格式（有 Schema 校验表把关，就像节目单有质检标准）播放一段固定的模拟节目，并且每条节目都盖「模拟」章（provenance=synthesized——绝不冒充真思考）。只要网址后面加 `?acp-mock=1` 就能收听，不加则完全不启用、原样走老引擎。

验收做了五层体检：①35 项映射单测全过（14 根旧线 → 新频道一一对应、无串台）；②浏览器全链路 A（老引擎走 SSE 模拟）答案正常显示、历史正常存档；③浏览器全链路 B（纯假电台直灌广播）同样渲染出完整答案+工具卡+历史存档——证明「未来换真发射塔时家里不用重新装修」；④样式面板（面开关/透明度/线宽）照常工作，零退化；⑤全仓 554 项 Python 测试通过、AI 出题的评分锚点文件一个字没动。

一句话：新房间的电线全部改成了标准插座，且已用假电器验证插座通电——S4 把真电器（原生事件发射引擎）插上即可，墙不用再砸。

**mock 对端设计要点**（S4/BrainAdapter 接远端时的蓝本）：
1. **两层职责分开**：wire=跨进程格式（对齐 `tests/acp_schema/schemas/*.schema.json` 必填字段·additionalProperties:false）；bus=壳内信封（`{family, lane, turn_id, ts, ...payload}`）。适配器做字段映射：`delta→token / verb→name+action.name / result_summary→observation`。
2. **诚实性红线**：mock 事件一律 `provenance:'synthesized'`（契约 v1.1 §5-1·防误把模拟进度当真思考流）；与 emitter 路径的 `'real'` 相对。
3. **turn/render 族 wire schema 未定稿**（S2 v1.1 增补在途）——mock 对这两族直接给 bus 载荷，与 emitter 同形；schema 定稿后 mock 剧本可平滑补 wire 造型。
4. **注入点复用**：直注 `shell._acp.bus`（buildHooks 闭包内创建·渲染订阅已挂）——即刀路图设计决策 3 的「远端引擎未来直注·壳渲染零改动」落地实证。
