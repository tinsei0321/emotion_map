### ① vendor 版本与 CDN 原引用一致

**结论：agree（版本一致·18 文件全有消费方·无冗余）**

### ② UMD 全局名兼容

**结论：agree（全局名逐一匹配）**

**一句话证据**：消费代码实测——maplibregl（search-bar.js Popup/Marker·map-controls.js）·deck（grid-tool 注释）·window.Chart（panel.js 851/877）·window.marked（panel.js 551 marked.parse）·csv2geojson/shpjs/proj4/fflate/topojson（import.js 注释「CDN globals, loaded in index.html」）·DOMPurify/ForceGraph3D（topology）——全部与 vendor UMD 全局名一致。

**P2 观察**：marked-12（index·v12 API parse）与 marked.min（topology·旧版）双版本并存——各自消费方明确（panel.js 用 parse·topology 独立页）·低风险·可后续统一。

### ③ 遗漏 CDN 引用

**结论：agree（index.html 零残留·1 处按需 esm.sh 保留）**

**一句话证据**：index.html 全部 script = vendor/ + css/ + js/ 本地（零 https）·e2e/test 动态 import 是本地 js ✓；**import.js:25 loadEsm 保留 `https://esm.sh/` 动态导入**（wellknown/polyline/togeojson·KML/GPX/WKT 按需·注释明确「无 UMD 构建的库走此通道」·失败抛错「CDN 不可达」）——非页面加载依赖·白屏已解决·断网时仅 KML/GPX/WKT 导入降级。
