## 一、背景与目标

项目 7 个底图（[map.js:21-31](../../frontend/js/map.js#L21-L31)）里 3 个 CARTO 矢量底图（`positron` / `dark-matter` / `voyager`）外链 `basemaps.cartocdn.com`，国内被墙 → style JSON 拉不下来 → `map.setStyle` 静默卡死、灰屏。git `b5081eb0` / `eda9769f` 已记录（vendor 库已本地化，唯独 CARTO style 没本地化——注释"待 CDN 恢复"是误判，国内常态化被墙不会恢复，且矢量瓦片 TB 级无法本地化）。

**连带故障**（同一根因）：
1. 3D 暗底图 `_loadDarkMatter`（[map.js:274-296](../../frontend/js/map.js#L274-L296)）fetch dark-matter 失败被 try/catch 吞掉 → 3D pitch 只剩纯深色背景无路网纹理；
2. 初始态三处打架：HTML 勾 `tianditu-vec-nolabel`（[index.html:1015](../../frontend/index.html#L1015)）/ JS 强制 `setActiveBasemap('positron')`（[main.js:346](../../frontend/js/main.js#L346)，positron 连按钮都没有）/ 地图实际加载 `tianditu-img-nolabel`（DEFAULT_BASEMAP）→ 开页无任何按钮激活；
3. [README.md](../../frontend/README.md) 仍讲老的"必须从根启动引 apps/static JSON"（已废弃为内联 style）；
4. [apps/static/](../../apps/static/) 4 个孤儿 JSON（老 WMTS + http + 单子域，零引用）；
5. 切换面板零容错无回退 + swatch 是纯 CSS 渐变（[dialog.css:104-108](../../frontend/css/dialog.css#L104-L108)）掩盖失效。

**用户要求**：换国内可达源（或国际镜像），稳定 / 高清 / 高级 / 好用，参考业界做法。

## 二、选型策略（待 CB 审计确认）

### 2.1 第一硬约束：坐标基准 = WGS84（不可破）

项目数据（POI / 网格 / 12345 点）与天地图均 WGS84/CGCS2000。**GCJ-02 源（高德/百度/腾讯）做底图 → 路网与数据点错位 50-500m → 空间归因失真**，对分析平台致命。→ 排除 GCJ-02 源做底图（瓦片重投影工程不划算）。

### 2.2 候选源矩阵（业界对标）

| 源 | 基准 | 国内可达 | key | 风格族 | 业界地位 |
|---|---|---|---|---|---|
| **天地图** | CGCS2000/WGS84 | ✅ 最稳 | tk（前端公开·验 Referer）| 影像/矢量/注记 | 国家版图权威 |
| **Esri Living Atlas** | WGS84 | ✅（用户推荐·待实测）| **免 key** | 浅灰/暗灰/彩色/影像/地形 | GIS 事实标准 |
| OSM | WGS84 | ⚠ 不稳 | 免 key | 矢量 | 社区基础（兜底）|
| CARTO | WGS84 | ❌ 被墙 | 免 key | positron/dark/voyager | 当前失效根因 |
| Mapbox | WGS84 | ❌ 被墙+token | token | 全谱 | 标杆但不可用 |
| 高德/百度/腾讯 | GCJ-02 | ✅ | key | 全谱 | 偏移·不兼容（排除）|

### 2.3 替换映射（底图重排）

| 现状 | 新底图 | 源（{z}/{y}/{x}·ArcGIS REST 规范）| 理由 |
|---|---|---|---|
| positron ❌ | **浅灰素图** | Esri `Canvas/World_Light_Gray_Base` | 极简突出数据，positron 同类 |
| dark-matter ❌ | **暗灰底图** | Esri `Canvas/World_Dark_Gray_Base` | 3D 暗态/夜间审美；3D dm 层也用它 |
| voyager ❌ | **彩色地形** | Esri `World_Topo_Map` | 彩色丰富，voyager 同类 |
| tianditu-img ✅ | 影像+注记 | 天地图 img_w+cia_w | 保留（中文注记好）|
| tianditu-vec ✅ | 矢量+注记 | 天地图 vec_w+cva_w | 保留 |
| tianditu-img-nolabel ✅ | 影像无注记 | 天地图 img_w | 保留（默认底图）|
| tianditu-vec-nolabel ✅ | 矢量无注记 | 天地图 vec_w | 保留 |
| _可选新增_ | **高清卫星** | Esri `World_Imagery`（maxZoom 18·Maxar 0.3-0.5m）| 升级天地图影像清晰度 |

**组合逻辑**：国内主源 = 天地图（最稳 + 中文注记）；国际补源 = Esri（补天地图缺的浅灰/暗灰/彩色/高清影像）。全 WGS84 无偏移。

> Esri URL 模板示例（{z}/{y}/{x}，MapLibre 按变量名替换，模板写对即可）：
> `https://services.arcgisonline.com/ArcGIS/rest/services/Canvas/World_Light_Gray_Base/MapServer/tile/{z}/{y}/{x}`
> `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}`（World_Imagery 在 server. 子域）

### 2.4 高级 / 稳定 / 好用增强（业界做法）

1. **容错回退**（治零容错）：`map.on('error')` 监听瓦片失败；`setBasemap` 加载失败 → 自动回退 `DEFAULT_BASEMAP`（天地图）；dm 层加载失败 → 纯深色背景降级。
2. **子域负载**：Esri 走 `services.arcgisonline.com`（World_Imagery 走 `server.arcgisonline.com`）；天地图 t0-t3 已有。
3. **健康探活**：启动探活各源，失效按钮标灰禁用（非现在"看着能点、点了灰屏"）。
4. **{z}/{y}/{x} 规范**：ArcGIS REST 是 `{z}/{y}/{x}`（与 XYZ `{z}/{x}/{y}` 反）；MapLibre 按变量名替换，模板写对即可（MapLibre 不认顺序只认变量名）。
5. **swatch 校准**：`.bm-swatch` 色值校准到 Esri 实际色调（避免色块掩盖失效）。

## 六、风险与验证

### 6.1 关键风险
- **Esri 国内可达性**：项目未实证（frontend 无 Esri 引用）；用户推荐但须实测。退路：Esri 不可达 → 浅/暗/彩色改天地图 + CSS filter（raster 可 `filter:invert()` 反成暗色，无偏移），或接受天地图全包（无暗灰）。
