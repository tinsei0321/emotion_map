## 三、缺失/错配清单

### P1 · 潜伏隐患（非当前错误，建议清理）
- **`checkup_qty_民生_公服设施.geojson`（1,068 点）混入覆盖率面 957 点**：中学覆盖率 535 + 菜市场覆盖率 422（Polygon 转点，覆盖率是面积指标、转点无意义）。当前 page5/矩阵均用 `_问题类`(111) 未误用，但该文件 + `boundaries/presets/manifest.json` 登记 + `77项量化/README.md` 描述（把中学/菜市场和问题类混列为 1,068）构成潜伏误用风险。
  - **建议**：删除该文件（矩阵/page5 都用问题类，它无用）；或重命名 `_含覆盖率.geojson` 并在 README 显式标注「含覆盖率面·勿当问题点」；同步修正 manifest + README。

### P2 · 微量未命中（0.3%，非承重）
- **民生矩阵公服问题类 111 → 矩阵 109，2 点 sjoin 未命中社区面**（范围外/落缝）。
  - **建议**：Codex 核查这 2 点去向（是落在社区面边界缝、还是范围外）；若属边界缝可改 intersects 兜底，若范围外则计入"范围外"列。不影响 page7 结论（2/757=0.3%）。

### P2 · 数据合理性（非管线错误，供确认）
- **营盘路（老城区云集街办·66 栋）安全耐久 0 图斑**：管线无误（源 shp 确实 0），但老城区结构/围护隐患为 0 在常识上偏弱——可能是体检采样未覆盖该社区、或住宅已改造。万达/建设/岳湾路/伍临路（伍家岗·新建/商业区）安全 0 但民生诉求极高（新建区楼新无结构隐患、但有物业/停车诉求），**逻辑自洽**。
  - **建议**：向体检数据提供方确认营盘路是否为采集盲区；若是盲区，0 值语义应为「未采集」而非「无隐患」，需在 page7 口径注标注。
