## 二 逐条建议（对应五问）

### 2.1 一格内两横条怎么实现 + 横条数值口径（Q1）

**结论：字符条 + 换行（唯一稳），数据条要拆列，迷你图不用。**

- **字符条（推荐·Excel 原生）**：一格两行 = `CHAR(10)` 换行 + REPT 公式，例：
  `="安全 "&REPT("█",ROUND(体检安全密度/$体检max$*10,0))&" 21件"&CHAR(10)&"民生 "&REPT("█",ROUND(体检民生密度/$体检max$*10,0))&" 37件"`
  行高固定 ≥32、垂直居中、关闭自动换行（手工 CHAR(10) 控制）。块字符 █（U+2588）在宋体/微软雅黑/WPS 渲染稳定，**复制进 PPT 是纯文本、零失真**——这是「最稳」的核心理由。PPT 侧若最终手动画图，矩形条+文本框更自由，但 Excel 侧字符条保证数据可复制校验。
- **为什么不是数据条**：条件格式数据条每格只能一条，一格两行做不了；要原生数据条只能把可量化拆成「体检安全/体检民生」两子列（可感知同理 → 共 4 子列）——违反六列拍板。**方案 B 保留**：若用户接受拆列，4 子列原生数据条 + 四色是第二稳，且能实现安全/民生分色。
- **为什么不是迷你图**：无标签、每格各自缩放（跨行不可比）、WPS/Excel 渲染不一致、复制进 PPT 丢失——汇报场景三不沾。
- **横条数值口径：条长 = 每百栋密度；条旁数字 = 原始件数。** 理由：条长表达「严重度」（摊薄后防大社区霸榜——若按件数画条，港务 417 件全场最长，与它不在 TOP20 直接自相矛盾）；数字表达「任务量」（讲解最顺：「这里要处理 21 个问题点」）。密度数值不进横条（放综合评估列），一格不塞三套数。
- **刻度：分轨分刻度，轨内同刻度**（体检列两条共用体检刻度·满格=该列最大密度 130.4；热线列共用热线刻度·满格=653.6）。**这与 xlsx 现有图例「两色同刻度·横向并排比较」相反**——理由：体检 928 点 vs 热线 5,717 件量纲差约 5 倍，同刻度会让体检条普遍只剩 1-2 格、被误读成「体检没毛病」；跨轨对比已由分层标签承担（双高=两轨都高），横条的职责是同轨内比谁更密。图例文字随之改为「体检列满格=130 点/百栋·热线列满格=654 件/百栋」。
- **图例/脚注行必备**：「条长=每百栋密度·数字=件数·按轨同刻度」——否则条长与数字不匹配，观众读不懂。

### 2.2 面积写哪个口径（Q2）

- 写**居住用地面积**（resi_km2·小区面聚合），不写行政面积：行政面积含山体水域，宜昌多山、边缘社区被稀释（zcode CB-33 设计已论证；`社区规模分母_174.csv` 已有 resi_km2 列可直接用）。
- 若用户想看两个数：并排小字「行政 km² / 居住 km²」，居住用地为正式口径。
- 标注：表头「面积（km²·仅参考）」+ 脚注「面积仅参考、不参与计算；居住用地=小区面聚合、剔除山体水域」。
- **视觉纪律：不参与权重的列不给视觉权重**——纯数字、右对齐、2 位小数，禁做数据条（一做条就被当成参与排序，误导）。

### 2.3 综合评估列怎么呈现（Q3）

- 三要素，一个都不少：① 层标签（色块底+白字：双高/客观高/主观高）② 密度小字（客观 XX/百栋·主观 XX/百栋，两行小字）③ 层内序（双高①~⑤…）。
- **层内序比全局序好讲解**（「双高第 3」比「总榜第 12」有力）；全局序进备查表。
- 双高标签加 ★（**仅双高**——三档都加符号=符号通胀=没突出）。
- 低置信：备注列已标（鑫鼎/临江溪）——标签旁加灰小字「低置信」；**PPT 结论句与「重点片区」依据不得引用这两个社区**（延续 CB-33 Codex 共识「列而不进结论」）。若 PPT 只讲 TOP8，自然规避。
- 不用：emoji、红绿灯圆点（色弱不友好、投影失真）；标签必须是文字+色底（色弱者靠文字）。

### 2.4 颜色方案（Q4）

| 用途 | 颜色 | HEX |
|---|---|---|
| 体检横条（可量化·冷） | 深蓝 | #1F4E79 |
| 12345 横条（可感知·暖） | 深橙 | #C55A11 |
| 分层·双高 | 深红·白字·★ | #C00000 |
| 分层·客观高 | 深蓝（=体检证据色） | #1F4E79 |
| 分层·主观高 | 深橙（=热线证据色） | #C55A11 |
| 其余行 / 表头 | 浅灰底灰字 / 深灰底白字 | #F2F2F2 / #404040 |

- **语义设计：标签色 = 证据来源色**——蓝标签=体检说它差、橙标签=热线说它差、红=两证据叠加。跨页联动：page3/5（体检结果）冷色系、page4/6（市民反映）暖色系，page7 同源延续，观众无需重新学图例。
- 一格两行内两横条同色（技术边界，见总评 3）；若采纳方案 B 拆四子列，安全=深一档、民生=浅一档（体检：#1F4E79 / #4472C4；热线：#C55A11 / #ED7D31）。
- 投影纪律：深底白字、字号≥10、加粗；避免黄字、浅底深字小字。

### 2.5 整体视觉：双高 > 客观高 > 主观高 一眼突出（Q5）

- **第一位是位置**：分层排序已让双高最先被看到——最强的信号，保持。
- **层小标题行**：三层之间插分隔小标题「① 双高·隐患+诉求叠加（5 个）」「② 客观高·体检独证（8 个）」「③ 主观高·热线独证（7 个）」，小标题底色=该层标签色——扫一眼看清结构，讲解时是现成的路标。
- **双高行强化**：社区名加粗 + 左侧 4pt 红色竖边框（不整行填色——既突出又尽量少撞「禁止颜色填充」）。
- 表头：单行六列即可（子项在格内两行自带「安全/民生」前缀），深灰底白字。
- 表尾三行：条长图例（分轨刻度）、层标签色块图例、低置信说明。
