## 二、双高定义（分轨·待 zcode 复核）

### 核心原则（v2）

**客观轨（体检指标）与主观轨（12345 诉求）分开判双高、分开表达，不合并。** 每个社区维护四个量：

| | 客观轨（体检指标） | 主观轨（12345 诉求） |
|---|---|---|
| 安全 | 体检安全 = 市政管网 + 安全消防 + 住房 | 12345 安全 = 管网安全 + 出行安全 + 消防安全 + 环境安全 |
| 民生 | 体检民生 = 公服 + 住房 + 停车 + 交通 + 物业 | 12345 民生 = 噪声 + 停车 + 住宅 + 出行 + 物业 |

### 三级双高判定

- **客观双高** = 客观安全 ≥ 客观 p75 且 客观民生 ≥ 客观 p75（体检轨内安全+民生都高）
- **主观双高** = 主观安全 ≥ 主观 p75 且 主观民生 ≥ 主观 p75（12345 轨内安全+民生都高）
- **双轨双高** = 客观双高 ∩ 主观双高（体检+12345 都双高 → 双轨互证的最强结论）

### 数据源（三张社区矩阵）

| 轨 | 文件 | 类别 | 社区数 |
|---|---|---|---|
| 体检安全 | `DATA/analysis/安全韧性/安全韧性_社区3类矩阵.csv` | 市政管网 / 安全消防 / 住房 | 70 |
| 体检民生 | `DATA/analysis/民生基础/民生_社区5类矩阵.csv` | 公服 / 住房 / 停车 / 交通 / 物业 | 92 |
| 12345 | `DATA/analysis/12345主观/12345_社区x9类.csv` | 安全4 + 民生5 + 其他 | 145 |

### Codex 初算（待 zcode 复核）

- 客观覆盖（有体检问题）101 社区，主观有诉求 145 社区
- 客观 p75：安全 13 / 民生 6；主观 p75：安全 13 / 民生 52
- **客观双高 16 个**：深圳路、西峡、金安岭、镇境山、幸福路、新隆康路、果园路、桥北、东门外正街、绿萝路、香锦、东湖、常家湾、镇平路、桃花岭、赵家湾（集中在老城中心 + 葛洲坝西坝·体检安全隐患主导）
- **主观双高 32 个**：港务、汕头路、宝联、八一路、东星、张家湾、魏家湾、伍临路、艾家嘴、东站路、东城、花艳、胜利二路、香锦、大学路、古塔、临江溪、冯家湾、花溪路、果园路、临江坪、锦湖、体育场路、黄金卡、枫香树、胜利四路、桃花岭、张家坡、大堰湾、石板溪、东锦苑、柏临河路（集中在港务/汕头路一带·12345 民生诉求主导）
- **双轨双高 3 个**：香锦、果园路、桃花岭

### 关键发现（v2 的核心价值）

**客观轨与主观轨在空间上基本错位**——客观双高 16 个（老城/葛洲坝·安全隐患）与主观双高 32 个（港务/汕头路·民生诉求）只重叠 3 个社区。这不是噪音，而是双轨互补的真实证据：体检测出的是"看不见的结构/围护/消防隐患"，热线喊出的是"体检没测的噪声/停车/物业诉求"。v1 合并后 12345 量主导，把这条结构事实抹掉了。

## 三、图方案（双轨分层·不合并）

**主图 = 一张社区面图，客观轨 / 主观轨两层分开表达：**

- **客观轨层（冷色系）**：体检指标图斑（安全类 / 民生类两种符号）+ 客观双高社区（16 个）用冷色描边/底纹标注
- **主观轨层（暖色系）**：12345 图斑（安全 / 民生）+ 主观双高社区（32 个）用暖色描边/底纹标注
- **双轨双高（3 个：香锦 / 果园路 / 桃花岭）**：最醒目标记（深色填充 + 粗描边 + 标名），这是"双轨互证"的最强落点
- **附注**：客观独证（体检发现、市民没反映，如西峡结构隐患）与主观独证（市民反映、体检没测，如噪声）用图例说明互补关系

**表达形式**：2D 社区面分类着色（客观双高=冷色 / 主观双高=暖色 / 双轨双高=深色），不推荐 3D（柱高只能表达一个总量，丢掉"客观×主观"二维语义）。

## 四、数方案（三段式·观点先行）

对应开篇"聚焦解决群众急难愁盼问题 + 补齐城市建设发展短板弱项"，分三段：

> ① **客观轨（补齐短板）**：体检指标显示，深圳路、西峡、金安岭、镇境山等 16 个社区，结构/围护/消防等安全隐患与设施短板集中（老城中心 + 葛洲坝西坝）——这是"体检才能发现的底线隐患"，必须优先治理。
>
> ② **主观轨（急难愁盼）**：12345 热线显示，港务、汕头路、宝联、八一路等 32 个社区，噪声/停车/住宅/物业等民生诉求集中——这是群众最急最盼的地方，必须优先回应。
>
> ③ **双轨互证（结论）**：香锦、果园路、桃花岭 3 个社区客观+主观双高，是"隐患与诉求双重叠加"的最优先区；客观隐患区与主观诉求区在空间上错位、互为补充，**城市更新必须统筹这两片，重点片区应划在它们叠加的区域**。
