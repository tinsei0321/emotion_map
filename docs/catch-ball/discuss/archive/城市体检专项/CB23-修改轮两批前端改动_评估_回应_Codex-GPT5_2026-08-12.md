## 二、逐项评估

### ① preferConfidence 语义（有 polarity 强走 L1）

**结论：agree（仅 l1 标记层·L2 零误伤）**

**一句话证据**：range-presets.js:92 `detectColorMode(fc, item.l1 ? { preferConfidence: true } : {})`——仅 manifest `l1:true` 层（12345）传参；main.js 上传导入路径不传 → 用户上传 L2 数据走原 polarity 分支不受影响 ✓；import.js:633 `polKey = opts.preferConfidence ? null : ...`·12345 补 `l1_confidence` 列命中 confKey → confidence 分支（L1 橙色·score=l1_confidence）·polarity 属性保留（供 hm-subset 过滤）✓。

**P2 观察**：其他 l1 标记层若缺 confidence 列 → 落 needsAnalysis 灰点（不进工具）——l1 标记契约需保证带 confidence 列（文档注明）。

### ② L1 极性过滤（P/N/O/NO）与 L2 隔离

**结论：agree（完全隔离）**

**一句话证据**：heatmap-tool.js:723 `if (level !== 'L2' && polarity && polarity !== 'ALL')`——POL_MAP 点集过滤（P=Positive/Very Positive·N=Negative/Very Negative·O=Neutral·NO=Neutral/Negative/Very Negative）仅在非 L2 生效；L2 走 resolveSource childByPolarity（原路径）·两路径独立 ✓；selectedTypes（L1 无 type 跳过）·intensityMin（emotion_intensity 0/1·>0 滤弱）交互正常 ✓。

### ③ hm-subset「中性+消极」（NO）在 L2 的行为

**结论：agree（L2 锁 ALL·NO 禁用·无越界）**

**一句话证据**：constrainPolarityOptions——`tier==='overall'` 时 `locked = level==='L2' ? 'ALL' : null`·L2 overall 锁 ALL（`allOff('ALL')`·NO 等全 disabled）·L1 overall `allOn()` 全开放——**L2 时 NO 选项禁用·不会出现「L2+NO 落 ALL」** ✓；细分分析（positive/negative/neutral）对 L1 禁用（constrainLevelOptions 非 L2 强制 disabled·L1 无 emotion_type）✓——L1 强度分析（橙色·深浅高矮）+ 极性过滤符合用户需求。

### ④ range 组放开钉底

**结论：partial（P1 缺陷·放开未真正生效）**

**一句话证据**：`reorderGroupSegment`（state.js:987）仅拦截 `fromCat==='ai'`·range 可拖 ✓；但 **`applyGroupOrder` 的 `PINNED = ['range','ai']`（state.js:960）仍强制 range+ai 末尾输出**——用户拖 range 到中间 → applyGroupOrder 把 range 拉回最末 → **拖拽无效**（state.js:299 注释「range 可拖·放开钉底」与 :960 PINNED 未改矛盾·sidebar.js:387 亦写放开）。

**定稿建议**：
1. **PINNED 改 `['ai']`**（range 从钉底移除·正常参与 `_groupOrder` 排序）·applyGroupOrder 末尾仅输出 ai；
2. 修后测：range 拖到 l2 数据上方（列表上=地图顶）→ 边界线压分析图上·z-order 生效·无拉回；
3. P2 观察：range 面（polygon 线框）与 heatmap/grid 分析层叠加无互斥冲突（enforceMutualExclusion 不含 range）·修后回归确认。

### ⑤ 数据侧 l1_confidence=score 复制列

**结论：agree（可接受·标注即可）**

**一句话证据**：l1_confidence=score 同值两列——L1 逻辑读 l1_confidence（confidence 分支）·L2 逻辑读 score·各为其用避免改逻辑——冗余可接受·导出文档标注「l1_confidence=score 复制·L1 强度分析用」即可。
