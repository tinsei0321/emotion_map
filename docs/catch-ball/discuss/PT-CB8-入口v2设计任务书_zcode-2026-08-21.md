## 一、交互流程规格（模型当向导·已拍板）

```
用户点击左下角「EMC 情绪地图」按钮
 ├─ 插件：若 8080 down → host.openPath('D:/Github/emotion_map/start_silent.vbs') 静默拉起
 ├─ 插件：新建对话 → 以用户身份 send(固定文本·见 §二)
 ├─ 对话流（自动展开）：
 │    用户消息（固定文本）→ 模型轮询 emc_status（工具活动=实时进度·预热中提示含预计时长）
 │    → 就绪后模型简短欢迎（引身份卡）
 └─ 插件：自身并行轮询 /emc-ready（2s 间隔）→ 就绪 → host.openPath('http://127.0.0.1:8080')
      弹**系统默认浏览器**（禁内嵌 tab 自动开——预热期乱码教训）
```

## 二、send 固定文本（流程指令内嵌·不依赖人设）

```
请打开 EMC 情绪地图：用 emc_status 轮询 8080 服务状态（每 5 秒一次，预热约 30-60 秒），
就绪(ready=true)后用一两句话欢迎我（可引 kb_facts 的 EMC 身份卡），并告诉我地图已在浏览器打开。
```

## 三、实现要点（复用初版资产）

- **复用**（08-20 初版已验证）：左下角插槽（`sidebar.footer.action`）、设计 token 全变量引用（`--dsw-alias-*`·零硬编码）、线性 SVG 图标、探测 fetch 不阻塞 UI。
- **新增**：新建对话 + `IConversation.send()` 注入（**对话服务唯一正规接口**——无伪造 assistant 消息的 API，模型回应即真实助手消息）；host.openPath 弹浏览器（home T15 已实证路径）；按钮"进行中"态（点击至就绪内置灰/转圈·防重复开多对话；就绪或 90s 超时恢复）。
- **移除**（v1 行为）：点击直接开内嵌 tab；60s 节流探测复杂度。
- **失败诚实态**：90s 未就绪 → 按钮恢复 + 对话流自然呈现模型侧的未就绪说明（不另弹错）。
- EMC 侧已就绪（本任务书签发前主手已落地）：`emc_status` 第 10 工具（F_032·双态实测过）。
