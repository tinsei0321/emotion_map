## 一、generate_point_layer 实现路径管线（修正版 plan P0-1 落地）

### 管线总览

```
用户追问「能在地图上标记出这些项目的位置吗」
  │  (P0-2 FC 前置) priorTurn=knowledge_qa + 标记词 → 注入上下文提示 + 上轮 final 片段
  ▼
FC diagnose → 契约 when 诱导选 generate_point_layer → names[]（LLM 从上轮 final 提取）
  ▼
generate_point_layer({names, as})   ← P0-1 核心
  │  逐名解析（按主路径→增强→兜底优先级链）：
  │    ① search_place 本地 POI 命中？（S2·主路径）    → 点要素（source=local）+ reverse-geocode 近邻
  │    ② 高德逆地理兜底？（S3·search_place 补全）      → 点要素（source=amap）
  │    ③ GIS 甄别图层增强？（S1·仅带地点名+属性字段者·如停车泊位缺口.小区名）→ 点/面要素（source=gis·交叉验证）
  │    ④ 面 preset 兜底？（S4·行政区/社区/片区）       → 面要素（tier-2）
  │    ⑤ 全部未命中 → 文字列出「未匹配坐标」（tier-3·诚实出口）
  ▼
合成 point FeatureCollection（properties: name/source/match_type/address）
  ▼
addToolboxLayer({kind:'point', paint: circle 显式样式}) → 落图层
  ▼
observation「命中 n/N + 未命中列表 + 来源标注」 → finalStep 诚实说明（不 request_upload）
```

### 三级回退细化（用户「模糊也给大致区域」）

| 级 | 条件 | 产物 | 置信 |
|---|---|---|---|
| **tier-1 点** | GIS 图层或 POI 命中（name 匹配） | 点要素（`match_type:'point'`） | 高 |
| **tier-2 面** | 未命中但为已知片区/行政区名（S4 面 preset） | 面要素 + 名称标注（`match_type:'area'`） | 中 |
| **tier-3 文字** | 聚合类无地点（如「污水厂网一体示范区 16 个」） | 文字列「未匹配坐标」+ 原因（`match_type:'none'`） | 诚实底线 |

> **tier-2 合格口径**：行政区级面 + 名称标注（如「葛洲坝片区 → 西陵区面 + 标注」）——Codex 建议·待用户确认（反评价收敛定稿已列）。

### 关键实现决策（从反评价收敛 + 取证）

1. **GIS 图层作为 S1 最高置信源**（用户提醒纳入）：
   - 启动/首用时读取 31 图层 → 建「图层名→要素」索引（pyogrio 读 OpenFileGDB）
   - `generate_point_layer` 逐名先查 GIS 图层要素 name 字段（停车泊位缺口.小区名 / 结构隐患住宅.小区名）→ 命中即最高置信点
   - **GIS 图层要素名是「问题/项目」而非通用 POI**——「葛洲坝xxx老旧小区」「停车泊位缺口」这类项目名能直接命中·比 search_place 通用 POI 准
2. **渲染**：显式 circle 样式（defaultPaint 无 point 分支·Codex 挑战 2）+ `addToolboxLayer({kind:'point'})`
3. **并发**：上限 50 名·并发 ≤10·单请求 5s 超时·总预算兜底（Codex + glm）
4. **match_type 属性**：`{name, source: gis|local|amap|preset|none, match_type: point|area|none}`——finalStep 据此可读标注（溯源铁律）
5. **诚实出口**：全未命中 → 零图层 + finalStep 文字（绕 runTemplatePath ask_user 陷阱·P0-0-3）
