## 四、新规则（写入 AGENTS.md）

**规则：双环境同步机制考量（2026-08-21 用户令）**——任何任务在拆解/执行前必须回答：本改动的沉淀资产能否在双环境（office/home）同步前提下进行？分三类处置：
1. 进 git 的（代码/文档/配方模板）→ 必须 commit+push 才算完成，未 push 不算交付；
2. 仓外本机的（~/.dsh 配置/插件依赖/进程状态）→ 必须同时产出「复刻清单」或「配方模板」进仓，否则判为不可同步任务，退回重设计；
3. 可重建的（索引/缓存/依赖）→ 只记录重建命令与版本，禁手工搬。
**判据**：任务交付物清单里若出现「只在单机生效且无配方」的项，该任务未达完成定义。目的：避免跨机重复配置的累积成本（每次重配都越来越重）。
