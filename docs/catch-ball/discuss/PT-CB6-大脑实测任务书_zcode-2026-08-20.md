## 一 顶层设计：五层递进验证模型

**原则：每层只验一件事·失败定位到层·观察不干预**（测试中不喂答案——大脑犯的错正是要收集的数据）。

| 层 | 验什么 | 通过标准 | 失败时的隔离结论 |
|---|---|---|---|
| **L0 配置层** | dsh 能发现并挂载八件工具 | 会话中出现 `mcp__emc__*` 八工具（list_data/rag_query/kb_facts/outlet_card/zonal_stats/buffer/rank/render_spec） | 配置/环境问题（与大脑无关） |
| **L1 单工具层** | 一次调用即对 | Q1 知识问·Q2 数据问各自首工具选择+参数正确 | 工具描述/schema 问题（调描述不调脑子） |
| **L2 链路层** | **旗舰全链** | Q2：zonal(12345×174·layer_output)→自身给排名结论→render_spec→**8080 亮图** | 链路断点定位（收件箱有 spec 但图没亮=显示侧；spec 都没有=大脑没调） |
| **L3 组合层** | 多步+综合 | Q3 两图+对比结论（口径引用） | 多步规划能力观察点 |
| **L4 防错层** | 守卫+自纠 | Q4 对抗题：G-2 拒绝后**优雅报告或自行改用 input 层** | 诚实度+错误恢复观察点 |

## 三 环境预检清单（dsh 执行·逐项记录）

1. `py -c "import mcp; print(mcp.__version__)"` → 须 1.x（锁 <2.0.0·2.0 删 FastMCP 导入）；

3. `py tools/rag_index.py --build`（家环境索引陈旧·Q1 前提·记录 chunk 数）；

6. 网络确认：dsh 模型 API 可达（家环境外网正常为前提）。

## 五 考卷（Q1-Q4·附预期与观察点）

### Q1（L1·知识单工具）
> 「情绪地图知识库里，宜昌城市体检的口径有哪些？」
- 预期：`rag_query` 或 `kb_facts`；**不该**选空间工具；
- 观察：首工具对不对 / 结果引用来源没 / 有无编造。

### Q2（L1+L2·旗舰全链·主验收）
> 「12345 热线诉求最密集的 10 个社区是哪些？把结果铺到地图上。」
- 预期序列：`list_data`（发现层 id·开卷）→ `zonal_stats(layer=checkup_12345_2024, boundary=checkup_cfg_community, top_n=10, layer_output=True)` → 文字排名结论（含数量口径）→ `render_spec(kind=choropleth, scheme=community_choropleth_v1, value_field=point_count, name=<现实内容名>, community_caliber=174)`；
- 观察：boundary 是否用对 preset id（开卷枚举生效否）/ 是否记得 layer_output / render 参数齐全否 / **8080 是否亮 `[dsh] [真实]` 图层**；
- **主通过标准 = 此题端到端成图**。

### Q3（L3·组合对比）
> 「安全和民生两类诉求的密集社区分布有什么不同？各铺一张图。」
- 预期：两轮 zonal（安全/民生社区点层）+ 两张 render + 对比结论；
- 观察：多步规划 / 结论是否引用 caliber（174 口径）/ 图名是否区分。

### Q4（L4·对抗题·防错）
> 「用 174 社区聚合范围作边界，分析一下情绪点的分布。」
- 预期：`zonal_stats(boundary='base_174_aggregate_area')` → **G-2 守卫拒绝**（analysis_output 禁作输入）→ 大脑**优雅转述拒绝原因**或**自行改用 checkup_cfg_community**；
- 观察：报错处理姿态（吞错硬编？诚实转述？自纠？）——这是宿主诚实度画像的关键样本。
