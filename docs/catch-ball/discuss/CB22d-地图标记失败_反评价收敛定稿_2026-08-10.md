## 一、用户两想法（客观评估 + 业界对照）

### 想法 1：地点模糊搜索需 LLM 参与，不能纯算法硬匹配

**可行且必要**。用户之前点破「机械剥后缀有对有错」→ 本次进一步「需 LLM 参与」。业界做法支持：

| 环节 | 谁做 | 业界做法 | 本项目落地 |
|---|---|---|---|
| **判意图** | **LLM** | 高德专利：LLM 区分行政区/POI/景区/聚合名 | 诊断卡 intent 体系已有·扩展判「聚合名/规划范围」 |
| **判核心实体** | **LLM + jieba 辅助** | 地址树 + CRF 实体识别 | jieba 分词辅助·LLM 确认核心实体 |
| **解析坐标** | **成熟 API** | 高德 place/text / district API | **先测高德**（能解析就用·不造轮子） |
| **兜底** | **本地匹配** | 本地模糊搜索 | jieba + `_match_score` 分层（离线 fallback） |

**claude 验证**（高德解析能力）：
- 「葛洲坝片区」→ 高德 local 命中（葛洲坝船闸景区 66.7·可接受片区级点）
- 「西坝街道」→ 西坝街道办事处（local·✓）
- 「污水厂网一体示范区」→ 丁家坝/范家湖污水处理厂（amap·**误导命中**·须 LLM 判聚合名挡掉）
- 核心实体（葛洲坝/西坝/二马路/夷陵/伍家岗）→ local 250 高置信 ✓

### 想法 2：无法识别地点就放弃，不能一直 while-loop——像人一样思维

**完全正确·本次最核心教训**。两组都修正了 claude 根因：

- **glm 精确定位**：挂起 = **单轮 `agentStep` 的 `streamChat` 流式 LLM 无超时**（[stages.js:252](frontend/js/ai_qa/stages.js#L252)）·模型 reasoning 不收敛无限挂·while-loop 30s deadline 守卫**够不着**（要等当轮返回才检查）。**非 while-loop 重试·是单轮不返回**。
- **Codex**：零命中后仍调 finalStep LLM → 单调用挂起 6.5 分钟 → 超时异常 UI 卡死。

**「像人思维」两层落地**：
1. **B1 全未命中快速降级**：全未命中 → 直接诚实出口（不调第二轮 LLM·不纠结·像人识别不出就放弃）
2. **agentStep 单轮超时**：任一轮 LLM 超时（30s）强制降级（像人不能无限思考·有思考上限）

## 三、定稿修复 plan（数据层 + 决策层 + 前提修正）

### P0-0 前提修正（最先做·Codex/glm 共识）

1. **装 rapidfuzz + pypinyin**（requirements 已有·本机补装·difflib 退役·place_layer 自动启用）
2. **names 鲁棒化**：`generate_point_layer` 标量/拼接串 **split（中文逗号/顿号/半角逗号/空格）** → 逐名数组·空元素校验
3. **冷加载处理**：place_layer 启动预热 / 前端单请求超时 5s→20s / 后端预热——防首用必全 abort

### P0-1 数据层（用户想法 1：LLM 参与 + 成熟 API + 本地兜底）

**解析顺序（先成熟 API·后本地·LLM 判意图）**：
1. **LLM 判意图**（Smart）：识别「聚合名/规划范围」（污水厂网一体示范区/其他项目）→ 归 unmatched·不匹配
2. **高德 API 优先**（成熟·不造轮子）：place/text / district 解析片区名（葛洲坝片区→葛洲坝船闸景区）
3. **本地 jieba 分词兜底**（离线 fallback）：jieba 分词 → 剔除行政/修饰后缀 → 核心实体 → `_match_score` 双路加权（完整串 + 核心实体·取高分）
4. **GIS 甄别增强**（用户提醒·A1）：停车泊位缺口.小区名/危旧房.住宅名真实坐标·最高置信

**聚合名处理**：归 unmatched + 标注「聚合/概念类名称·无具体坐标·建议上传项目清单或换问具体项目名」（诚实·越维防护）

### P0-2 决策层（用户想法 2：像人思维·放弃 + 有思考上限）

1. **B1 全未命中快速降级**：generate_point_layer 全未命中 → 直接诚实出口（observation 命中 n/N + 未命中列表 + 「建议上传项目坐标」）·exit='answered'·onFinalDone 必触发·**计时必然收尾**
2. **★ agentStep 单轮超时**（glm 核心）：stages.js:252 加 30s timer（仿 fcDiagnoseStep 模式）·超时 throw → harness 降级→ 治所有「模型 reasoning 不收敛」
3. **finalStep 失败兜底**（Codex）：finalStep 超时/异常 → 确定性降级结论（复用 `_composeDegradedConclusion`）

### P0-3 测试与验收（真实数据·三证闭环）

- **用户 16 名实测集**（固定 e2e-seam 断言集）：葛洲坝片区/红星路-二马路/污水厂网一体示范区/达门船厂/三峡青年城/土门片区…→ 断言各名称分类符合口径
- **A0 单测**：jieba 分词 + 核心实体 + 双路加权（葛洲坝片区→命中·污水厂网示范区→unmatched·达门船厂→不误伤）
- **挂起测试**：stub agentStep 返永不收敛流 → 断言 30s 超时降级
- **验收口径**（glm 量化 + Codex 三条件）：
  - 16 名 ≥50% 出标记（点位或面·来源/名称可读）
  - 未命中诚实文字（不编造坐标·不 request_upload）
  - **0 挂起**：任何情况 30s 内必有出口
- **用户复测**：真实数据·眼看地图出标记 + 计时收尾
