### 焦点 4：映射落地方式 — **agree（harness 分支独立组装·非编排层新概念）**

**glm 判定**：**落地在 harness 各短路分支**（非新建编排层）——最小改动 + 对齐现有架构。

**理由**：
- harness 已有短路分支结构（quick-general :940 / rag_query :978）——各分支独立处理。
- **改 rag_query 分支**（:978-1009）：注入成功 → 确定性组装 → onFinalDone → return（禁 finalStep）。
- **不改 quick-general**（:940·暂保留 finalStep·焦点 1 标注风险）。
- **不改 runTemplatePath/runChainPath**（分析路径·finalStep 正确）。
- **无新建编排层**——各分支自己分派范式·最小改动。

**vs 编排层统一**：
- 新建编排层（如 `dispatch_paradigm(intent)`）= 架构重构·改动大。
- harness 分支独立 = 现有结构微调·改动小。
- **glm 倾向分支独立**——最小改动 + 现有架构兼容。

**实现位置（glm 建议）**：
```javascript

// 新增 _assembleRagResults（纯函数·确定性组装）
function _assembleRagResults(results) {
  const lines = results.map((r, i) =>
    `${i+1}. **${_srcName(r.source)}**（${r.data_dim||'社区'}维度·[来源](${r.source})）`
  );
  return `## 知识库检索结果（Top-${results.length}）\n\n${lines.join('\n')}\n\n> **维度声明**：结论不超过检索数据维度·未引用他城数值。`;
}
```
