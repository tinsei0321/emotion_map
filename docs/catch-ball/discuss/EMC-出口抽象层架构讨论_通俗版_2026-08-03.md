## 〇、一句话看懂（TL;DR 通俗版）

情绪地图现在像一台**能出图的机器**：你问"西陵区哪里不好"，它给你热力图、网格、归因结论。但这些结果**只停留在屏幕上**，规划局/更新办**用不了**——因为行业要的不是"一张图"，而是"能填进他们编制文件的具体内容"（比如"这个片区改造需求分析表"里要填的需求类型、需求强度、位置、建议）。

**出口抽象层 = 把情绪地图的"图"翻译成行业能直接用的"表"。** 这是情绪地图从"技术 demo"变成"能立项的产品"的临门一脚。

## 一、为什么这是立项成败的关键（通俗版）

### 1.1 学术价值 ≠ 立项价值

情绪地图的学术价值（用海量评论聚合出城市情绪分布）**已经成立**。但**立项**要回答的不是"这技术多厉害"，而是一个更具体的问题：

> **「你的分析结果，能填进哪个行业/哪个编制流程的哪张表、哪个指标、哪个任务板块？」**

答不出这个问题，情绪地图就是"自娱自乐"——技术再精巧，规划院/更新办/住建局不会采购。

### 1.2 三条铁律（贯穿全文）

| 铁律 | 专业表述 | 通俗解释（= 大白话） |
|---|---|---|
| **A. 情绪地图·EMC 找市场** | 情绪地图主动对接行业既有板块（更新需求分析/片区划定/体检指标），非让行业来适配情绪地图 | = 情绪地图去"适配行业已有的表"，不是让行业来"适配我们的图"。行业已有表格/流程，情绪地图主动去填 |
| **B. 三段式线性** | 意图 agent（判尺度/方法）→ 结果 agent（出图数观点）→ 成果范式 agent（对接行业接口）三段承接，禁一竿子插到底 | = 回答要"分层走"，不能用户问一句宏观问题就直接甩一个微观答案。先判断问题类型（宏观/中观/微观），再分析，再对接行业 |
| **C. 定性+定量+地理按尺度** | 图/数/观点必须耦合分析尺度，地理信息类型按尺度选取 | = 回答的"图、数字、结论"要匹配问题的"大小尺度"——问全市（宏观）就给"全市层面图"，问某个小区（微观）就给"具体点位"，不能拿微观证据答宏观问题 |

## 二、抽象层视角：情绪地图的三层流水线（通俗版）

把情绪地图想象成一条**加工流水线**，三个工位（抽象层）：

```
┌──────────────────────────────────────────────────────┐
│ 【第 1 层 · 入向层】（已有·成熟）                     │
│  输入：用户问句（如"西陵区哪些小区改造需求大？"）      │
│  处理：意图 agent 判断——这是什么类型问题？宏观/中观/微观？│
│        （诊断卡：scale/domain_lens/outlet 等 8 字段）  │
│  输出：诊断卡（判好"分析尺度 + 该用什么方法"）         │
│  通俗说：像一个"接待员"，先搞清楚客人的需求类型        │
└──────────────────────┬───────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 【第 2 层 · 结果层】（已有 + 需增强）                  │
│  输入：诊断卡 + 用户数据                              │
│  处理：结果 agent 执行空间分析（zonal/网格/热力/缓冲） │
│        工具执行 → 图层 + 归因字段                     │
│  输出：标准分析产物（网格/热力图 + 定量+定性字段）     │
│  通俗说：像一个"分析员"，用数据算出"图 + 数字 + 结论" │
└──────────────────────┬───────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│ 【第 3 层 · 出口层】← 本文核心！目前缺失！            │
│  输入：结果层的"图+数+观点"                           │
│  处理：成果范式 agent 把分析结果作为"资源"再理解、再整理│
│        → 格式化对接行业明确接口                       │
│  输出：行业接口对接产物（体检指标对接表/更新需求分析卡/ │
│        片区划定建议/时序排序表/任务清单/项目库条目）   │
│  通俗说：像一个"行政专员"，把分析员的成果"填进行业要的表"│
└──────────────────────────────────────────────────────┘
```

**关键**：第 1、2 层已有且成熟；**第 3 层（出口层）完全缺失**——这是立项风险点。

## 三、行业接口清单（情绪地图要去"填"的表）

> 这些是行业**已经存在、明确要填**的板块——情绪地图要对接的就是这些。

### 3.1 政策骨架（一条主线）

**「先体检、后更新、无体检不更新」** —— 体检发现问题 → 更新解决问题 → 评估效果 → 巩固提升（闭环）。

### 3.2 四类接口（情绪地图要对接的"表"）

| 接口 | 是什么 | 情绪地图能填什么 |
|---|---|---|
| **① 更新八项重点任务** | 中办国办 2025.5《意见》部署的八项任务（既有建筑改造/老旧小区整治/完整社区/老旧街区/城市功能/基础设施/生态修复/历史文化） | 每项任务的情绪诊断（如老旧小区整治 → 海量真实评估替代小样本问卷）|
| **② 城市体检四维度** | 住房→小区→街区→城区（逐级展开）| 每维度的情绪指标（情绪地图三尺度已对齐此四层级）|
| **③ 体检 8 大领域指标** | 住建部体系（生态宜居/健康舒适/安全韧性/交通便捷/风貌特色/整洁有序/多元包容/创新活力）| EMC 4×5 归因能覆盖 8 领域（归因→指标的桥梁）|
| **④ 更新规划三级编制** | 专项规划—片区策划—项目实施方案 | 各层级可填的"料"（宏观诊断/中观归因/微观落点）|

### 3.3 行业痛点（情绪地图的替代价值）

| 行业现状 | 痛点 | 情绪地图替代 |
|---|---|---|
| 问卷调查 | 样本小、时滞、覆盖窄、主观 | 海量评论 → 大样本、实时、空间精准 |
| 实地调研 | 成本高、覆盖窄、难常态化 | 低成本、全城覆盖、可持续 |
| 第三方体检 | 偏客观指标、缺市民主观感受 | 主客观互补 → 补"主观感受"数据真空 |

**一句话**：情绪地图 = 城市体检"社会满意度调查"板块的**海量化、实时化、空间化升级**——从"年度小样本问卷"升级为"持续海量真实情绪流"。

### 四补充 2·案例深挖（真实城市 × 通俗对接）

> 上面的对标对表里提到了上海/广州/南京这些城市。下面用**已搜集的真实城市数据**，每城挑一个最贴近的环节，用大白话讲清楚情绪地图的「图/数/表/观点」怎么落地。数据都是真实数据，没编。

#### 城市体检工作方式（大白话背景：传统怎么做 vs 情绪地图+AI 怎么补）

> 先补一句背景：情绪地图要填的"体检/更新表"，传统上是怎么做出来的？看懂传统城市体检的**做法**，才能看清情绪地图在哪个环节帮你**做得更客观、更有说服力、更科学**。下面分四块讲：表怎么定义（A）→ 中间缺了什么（B）→ 传统数据为什么不靠谱（C）→ 情绪地图怎么补（D）。

##### A. 体检的"表"怎么定义（四维度 + 指标官方三类）

城市体检从**四个尺度**查"满不满意"——住房 → 小区 → 街区 → 城区（住建部 61 项基础指标，地方还能加自己的特色指标）。**重点看住建部**（聚焦更新落地项目和"规建营"）——自然资源部那套（110 项·管空间规划）是另一个视角，了解即可；国家"十五五"《城市更新规划》（10 项指标）是统领性上位纲领。

**四维度 = 落实"规建营"**（把城市体检作为统筹城市规划、建设、管理工作的抓手）：

| 尺度 | 指标数 | 对应规建营 | 查什么 | 数据哪来 |
|---|---|---|---|---|
| 住房 | 10 | 建设（建）| 安全、功能、适老化（隐患/管线）| 普查/鉴定 |
| 小区（社区）| 11 | 管理（营）| 养老/托育/停车/物业 | 普查 + 感知 |
| 街区 | 10 | 规划（规）+ 管理（营）| 运动场/文化/老旧街区 | 普查 + 感知 |
| 城区（城市）| 30 | 规划（规）| 生态/文化/产城融合/韧性/智慧 | 遥感/CIM/大数据 |

指标**官方分三类**（住建部：可量化、可感知、可评价·定量+定性、客观+主观结合）：

| 官方类型 | 大概占多少 | 是什么 | 靠什么拿 | 情绪地图关系 |
|---|---|---|---|---|
| **可量化**（客观）| ~55-65% | 隐患数/管线/绿地率/路网密度 | 统计/普查/遥感/GIS | 不替代·作客观基线 |
| **可感知**（主观满意度）| ~15-20% | 满意度/活力/烟火气/停车便利/物业 | 居民问卷（≥0.2% 样本）| **核心对接口** |
| **可评价**（综合复合）| ~15-25% | 生活圈综合/人居环境综合评价 | 统计+遥感+问卷融合 | **情绪地图增强** |

> **合计约 30-45% 指标涉及"市民感受"维度**（可感知+可评价·需问卷/感知）——比想象的多得多，但全靠小样本问卷采（样本小、一年一次、难定位）——**这正是情绪地图要补的洞**。

> **大白话**：官方把指标分三类——"可量化"（卫星/普查测的·可靠但读不出市民感受·占大头）、"可感知"（问市民满不满意·有民意但样本小不好采）、"可评价"（综合评估·也要靠问卷补感受）。**合起来看，约 3-4 成指标都沾"市民感受"**，可传统方式只靠问卷扛——样本小、一年一次、难落到地图。官方没叫"软指标"，叫"可感知/可评价"——但这层"市民感受"正是传统最弱的一环。中间缺一层"又反映市民声音、又统计可靠、能定位到地图"的软指标——这就是情绪地图要填的。

> **关键洞察（大白话：不是"少"，是"覆盖广但采集弱"）**：涉及市民感受的指标占比看着不高（3-4 成），但**牵涉的面特别广**——宜居、活力烟火气、满意度、停车便利、物业管理、公共服务……几乎每个维度都有"市民感受"那一面（住建部要求指标"可感知"）。可这么多"感受面"，全靠**小样本问卷**采（广州 6.5 万/上海 4.5 万·只占人口 0.6‰~1.5‰）：**代表不了**（配合政府/关心事务的才爱填、老人不熟手机、外来务工被电话调查排除）·**又慢又贵**（设计 30-50 题→发放→回收→统计要好几个月、一年一次、问卷每年改难对比）·**难落到地图**（一个综合分拆不到具体地方/主题）·**难验收**（复查要等下次问卷）。所以真正的问题不是"缺主观指标"，而是**缺一个能扛起这么多感受面、又统计可靠、还能落到地图的采集办法**——情绪地图（全量评论）就是来补这个洞的。

> **承上启下（A→B）**：——这就是体检的"表"：**约 6 成可量化**靠遥感普查（可靠但读不出民意）+ **约 3-4 成可感知/可评价**（有民意但 0.2% 样本·不可靠）+ **地方特色**（因地制宜·在基础指标之上加·以可量化为主）。问题来了：**这样的表，中间缺了什么？**（看 B）

##### B. 中间缺了什么（主观指标可信性缺口·俗称"软指标缺口"）

> 一句话：体检的表中间缺了**一层"又反映市民声音、又统计可靠、还能定位到地图上"的主观指标（俗称"软指标"）**。
> - 客观指标太硬：可靠但不含民意（遥感测得出绿地率·读不出市民觉得好不好）
> - 主观指标太飘：含民意但不可靠（问卷样本小·有时滞·难定位·难统计）
> - **缺口** = 一个既反映市民声音、又统计可靠、可空间定位的主观指标——**这正是情绪地图要填的位置**。

> **观点补充（官方怎么说·大白话）**：住建部要求体检指标**"可量化、可感知、可评价"**——"可感知"就是"市民感受"，官方**认了这层不能少**，但靠问卷采（样本 ≥0.2% 常住人口）**不可靠**。更尴尬的是**主客观反差会伤公信力**：客观数据说"车位/设施达标"，居民却照样抱怨停车难——两套数据对不上，体检结论就被人质疑。这正是 B 缺口（主观指标无可靠采集）的现实后果。

> **承上启下（B→C）**：——缺的这层"**可靠软指标**"，正是**传统做法最做不好的地方**。为什么做不好？看 C 的四条硬伤。

##### C. 传统数据为什么不靠谱（不靠谱 ≠ 主观·是量不够/太慢/不牢）

> **"不靠谱"不在于"主观"**（情绪地图也是主观数据），而在于"量不够、太慢、不牢"。体检里"满意度/活力/烟火气/宜居感知/停车便利"这类**主观/感知类指标**全靠问卷/座谈拿数据——恰恰是不靠谱的短板所在：

1. **量不够**：抽样（广州 6.5 万 / 上海 4.5 万·只占城市人口的 0.6‰~1.5‰·最低 1500 份）vs 全量评论——覆盖有限，老年/低收入群体基本缺席（数字鸿沟）·**样本有偏差**（配合政府/关心事务的居民更可能填）·外来务工被电话调查排除·高学历偏多
2. **太慢**：一年一次；设计问卷 → 发放 → 回收 → 统计要好几个月，没法持续追踪，事件/舆情这种动态捕捉不到；**问卷每年调整**，**好几年都难对比**（缺乏延续性）
3. **不牢**：问卷自评主观（"满不满意"打个综合分如上海 93.60 分，难落到具体空间/主题）；题目预设（只问已知的，发现不了新痛点）；开放建议人工归纳费力（上海 2431 条）
4. **难闭环**：体检 → 问题清单 → 整治建议 → 项目库 → 实施；验收 = 整改完成率 + **满意度复查（还得等下次问卷回访·慢）**——从发现问题到验收要以年计，没法实时追踪

> **承上启下（C→D）**：——传统方式四条硬伤（**量不够/太慢/不牢/难闭环**）叠加，体检结论"**难闭环**"：发现问题靠年度问卷·**验收还靠下次问卷**。情绪地图怎么破？看 D。

##### D. 情绪地图+AI 怎么补（更客观/更有说服力/更科学）

| 维度 | 传统方式 | 情绪地图+AI |
|---|---|---|
| 覆盖 | 抽样（0.6‰~1.5‰·≥1500 份）| 全量评论·不遗漏沉默多数·无数字鸿沟 |
| 时效 | 一年一次·数月周期 | 实时·持续流式·任意时间窗 |
| 定位 | 问卷难定位（区/街道级）| 网格/POI 级·精准到栋/路 |
| 拆解 | 综合分难拆 | 4×5 归因·政策→情绪→项目 |
| 验收 | 靠下次问卷回访 | 持续极性对比·改造前后效果·可实时验收 |

一句话：情绪地图 = **更客观（全量非抽样）· 更有说服力（真实评论，不是问卷自评）· 更科学（空间+主题+极性三维·可追踪可验收）** 的评级方式，作为城市体检/更新的支撑（之一）——正好填 B 里那道"主观指标可信性缺口"（俗称"软指标缺口"）。

> **观点补充（主客观交叉验证·大白话）**：情绪地图还能和客观指标**对着看**——**对上**（客观达标 + 大家满意 = 建设到位）；**对不上**（客观说达标、大家却说不好 = "城市病"：设施有了但不好用/不方便，比如车位够但就是停车难）——对不上的地方，恰恰是**该找问题、该立项更新**的地方。

> **承上启下（C→D）**：传统数据"不靠谱"（量不够/太慢/不牢）+ 难闭环 → 情绪地图 + AI 正好补这个**采集空缺**（全量/实时/空间准/可归因/可追踪）——从 B 的"缺口诊断"到 D 的"填补方案"，一条线闭环。

> **承上启下**：——情绪地图用全量评论填补"**软指标缺口**"：**更客观**（全量非抽样）、**更有说服力**（真实评论）、**更科学**（可定位可追踪）。下面四个真实城市案例检验这套逻辑——每个传统环节的"不靠谱"点，情绪地图用哪种图/数/表/观点去填。

#### 案例 1：宜昌 · 望洲岗 10 号楼"原拆原建"（本地示范工程 · 证明做得好）

> **对比聚焦（传统短板 → 情绪地图怎么补）**：传统摸底靠**坝坝会/敲门/问卷**，痛点 = 众口难调、出资政策不理解（改造前期 **48 户只有 8 户签字**）。情绪地图怎么补 = 用**全量评论**覆盖没参会/没填卷的"沉默多数"，并对**改造后效果**做空间化评估——**更客观地证明望洲岗做得好、好在哪里**，给"原拆原建"推广做背书。

> **定位**：望洲岗是宜昌的**示范工程**（湖北第一个"原拆原建"，央视都报道了）。这里情绪地图不是去挑它改造前的毛病，而是**用数据证明它做得好、好在哪里**——给"原拆原建"这个模式做背书。

**① 行业当时是怎么做民意/需求调研的**（真实做法·大白话）：
- 望洲岗 10 号楼在宜昌西陵区葛洲坝片区，是 70 年代末的"筒子楼"（没有独立厨房卫生间）。
- 2023 年列入危旧房改造试点，2024 年 3 月开工，**湖北第一个"原拆原建"**，2025 年交房（比原计划提前一年）。
- 总投资约 6300 万，**居民只出 500 多万**，每户还有 3 万奖补。
- 新建 2 栋 74 户：25 户回迁、49 户市场卖，户型 68/88/103/135㎡，配 75 个停车位（原来想都不敢想）。
- 居民出资规则：回迁 1000 元/㎡；新增面积阶梯价（10㎡ 内 8 折、20㎡ 内 9 折、以上原价）。

**他们当时是怎么摸底、怎么说服居民的**：
- **"坝坝会"（社区议事会）+ 入户调查（"敲门行动"）+ 居民骨干"算账"说服**：改造前挨家挨户摸底意愿、讲清"出多少钱、得多少好处"。
- **数据**：90%+ 居民有改造意愿；但原拆原建试点前期 **48 户只有 8 户签字同意**（大家不理解"为什么拿不到补偿还要出钱"）→ 靠居民骨干两周内**"算账"签约到 80%+**。
- **过程**：居民成立**湖北第一个危旧改联合社**，全程民主协商参与 → 4 天盖一层、9 个月完工、**零投诉零上访**、提前一年交房。
- **难点短板**：① 众口难调/意见分歧大；② 出资政策不理解；③ 资金平衡难（6300 万，居民只出 500 万）；④ 部门协调难。
- 带动了常湾幸福里等 6 个项目推进；宜昌"十四五"要改造 1360 个老旧小区、23.11 万户、58 万人。
- （来源：宜昌住建局·湖北日报·荆楚网）

**② 情绪地图怎么对应**（把这些"摸底/民意"结果对应到图/数/表/观点）：

| 情绪地图能给什么 | 对应到哪 | 一句话效果 |
|---|---|---|
| **新居积极情绪**（"翻天覆地/满意/有盼头"）| 按格子/地点归因 → 图上"积极聚集区"+ 高积极极性指数 | 居民满意的**空间证据**，不是嘴上说好 |
| **好在哪**（厨卫/电梯=设施·停车/绿化=环境·物业=服务）| 各自正向归因占比 | 精确到**哪类改善最被认可** |
| **对照看**（旁边未改造筒子楼偏消极）| 改 vs 未改极性对比 | 改造"获得感"是真的 |
| **可复制**（居民只出 500 多万+高满意度）| 样板数据背书 | **样板不只故事，可量化、可复现** |

- **落到具体的人**：杨女士 58㎡ 换 91㎡"翻天覆地"；李严国花 11.3 万加 10㎡——个案都落回情绪归因点，"人住得舒不舒服，地图上看得见"。
- **规模意义**：宜昌 1360 个小区是"原拆原建"要铺开的盘子，望洲岗是第一个被证明成功的样板——情绪地图让推广"有据可依"。

**③ 情绪地图·对标对表**（更专业/全面/科学·大白话）：

| 维度 | 传统需求调研 | 情绪地图 | 更优之处 |
|---|---|---|---|
| **更专业** | 小样本问卷 + 座谈（枝江 68 份 · 秭归 4000 份 · 60% 参与）| 全量评论持续流 | 不遗漏**沉默多数**（没参会/没填卷的居民）|
| **更全面** | 定向问预设问题（停车/管网/花坛）| 开放评论自动归类 4×5（设施/环境/服务/文化/事件）| 发现**预设之外的新痛点** |
| **更科学** | 问卷自评（主观·时滞·一次性）| 持续流式极性指数 + 归因 | 可**前后对比**（改造前 vs 后）·可**追踪效果**·可**定位到栋/路** |

**这些结论能填进哪张"体检/更新的表"**（直接指向指标）：
| 行业指标 | 情绪地图的结论 |
|---|---|
| **体检·住房维度（居住品质）** | 居民"翻天覆地/环境好了心情也好/以旧换新还是值了"（来源：湖北日报·宜昌住建局 2025）|
| **体检·健康舒适（设施完善）** | 75 停车位"一户一位"+ 完整社区配套（公园/BRT/便民超市）（来源：宜昌住建局 2025）|
| **更新·老旧小区整治（效果评估）** | "零投诉零上访"+ 提前一年交房（来源：宜昌住建局·湖北日报 2025）|

**小结：情绪地图四方面逻辑闭环**（一句话：问需求 → 评片区 → 立样板 → 排先后）

| 环节 | 情绪地图在这环节的作用 |
|---|---|
| 广泛需求调研 | 全量评论流替代小样本问卷（枝江 68 / 秭归 4000 份 → 海量评论）·补"沉默多数" |
| 更新片区评估 | 情绪画像（极性+4×5 归因）→ 片区改造评估·精准到栋/路 |
| 典型示范片区选择 | 望洲岗高积极情绪=成功样板·可量化可复现 → 支撑"原拆原建"推广（宜昌 1360 小区）|
| 更新事项紧迫性 | 改造前后极性对比 + 未改造对照 → 更新紧迫性排序依据 |
| **闭环** | 需求（哪里呼声高）→ 评估（片区好/差）→ 示范（样板成功）→ 排序（先改谁）|

#### 案例 2：上海 · 社会满意度调查（体检）

> **对比聚焦（传统短板 → 情绪地图怎么补）**：传统 = **45,578 份问卷 + 综合 93.60 分**，痛点 = 一年一次**有时滞**、综合分**难定位**到具体地方/主题。情绪地图怎么补 = **全量评论持续流**替代一次性问卷，按住房/小区/街区/城区**四个尺度自动算满意率**，低分项（老旧小区/停车）直接标到地图上。

**① 行业当时是怎么做民意/需求调研的**（真实做法·大白话）：
- 2025 年度回收有效问卷 4.5 万份，满意度 93.60 分（比上年 +3.4%），开放建议 2431 条。
- 2024 年度 5.4 万份，满意度 83.9 分。
- 分 4 类场景（住房/小区/街区/城区）× 8 维度，约 200 项指标。
- 满意度较高的：安全韧性/多元共享/绿色低碳；较低的：老旧小区改造/商场活力/物业/路边停车。

**他们当时是怎么调研的、难在哪**：
- **线上问卷**（发在"上海发布/随申办/政府官微"上，一年一次）+ **社区座谈/访谈会**（比如 2025 年 6 月闵行漕河泾街道的城市体检访谈会）+ 联合**市人民建议征集办** + 现场踏勘。
- **数据**：2025 年度有效问卷 **45,578 份**、满意度 **93.60 分**（+3.4%）、开放建议 **2,431 条**；2024 年度 5.4 万份、建议 13,650 条、90.52 分。
- **产出**："一表三清单"（指标评估表/优势清单/问题清单/整治建议清单）；2024 年针对问卷制定了 **35 项行动建议**（停车难治理/电梯安全评估/社区养老）；"**无体检不修缮**"。
- **难点短板**：老旧小区改造/路边停车/物业满意度低（中心城区更明显）；问卷一年一次**有时滞**；开放建议 2,431 条**人工归纳费力**。
- （来源：上海市住建委 2025-10-24）

| 4 个尺度"满不满意" | 按住房/小区/街区/城区自动算"自动满意率"，对照 93.60 分 |

| **更专业** | 年度问卷（45,578 份·一次性·时滞）| 全量评论持续流 | **实时**·**可持续**·不靠集中填卷 |

#### 案例 4：南京 · 大数据定位

> **对比聚焦（传统短板 → 情绪地图怎么补）**：传统 = **百度/高德大数据**定位堵点，痛点 = 大数据只有"**堵在哪**"（客观位置），**缺"堵得多难受"**（市民主观感受）。情绪地图怎么补 = **评论情绪**补主观维度——"堵在哪"（客观）+ "堵得多难受"（主观）叠加 = 改造排队**双重证据**。

## 七、讨论焦点（两组讨论后的定案）

> 用户要参与讨论。以下是六焦点的**通俗 + 专业**双版本，附两组讨论后的倾向。

### 焦点 1：出口层放在哪？（架构位置）

**通俗说**：出口层这个"行政专员"，是放在后端（服务器算）还是前端（浏览器显示）还是 LLM（AI 组织语言）？

| 方案 | 通俗说 | 专业 |
|---|---|---|
| A. 后端层 | 服务器算好结构化数据，但不让 AI 说人话 | `core/outlet_adapter.py` 纯函数 |
| B. prompt 层 | 让 AI 用自然语言组织对接建议 | `build_outlet_prompt` |
| C. 分层 | 服务器算数据 + AI/前端渲染语言 | 后端 schema + 前端/LLM 渲染 |

**讨论定案（Codex + claude组 一致 + claude组 修订）**：
- **后端确定性组装**（build_outlet_schema 纯函数）——定量数字必须代码算，不能让 AI 编造
- **不新增 LLM 阶段**（claude组 修订：原报告倾向 build_outlet_prompt 会撞 final 极瘦红线）→ 前端模板渲染结构化卡
- **条件触发**（不是每问都出卡，只有"行业接口类"问句才触发）

### 焦点 2：DOMAIN_OUTLETS 升级（从"启发词"到"接口契约"）

**通俗说**：行业"出口范式"现在是给 AI 的提示词，要升级成"能填表的接口定义"。

**定案**：`paradigm.py` 的 DOMAIN_OUTLETS **不动**（它是 diagnose 承重源）；新增出向契约（OUTLET_CONTRACTS）定义每个出口的接口标识/产出 schema/尺度/字段映射。

### 焦点 3：尺度耦合校验（要不要加校验层）

**通俗说**：要不要加一道"检查"，防止宏观答案里混入微观点位？

**定案（claude组）**：**不需要**——已有两层约束（SCALE_PARADIGM prompt + 前端 _outletLine）足够；靠"模板按尺度分派"（macro 模板不读 POI）保证。

### 焦点 4：与 CB-15 数据认知协同（实施顺序）

**通俗说**：出口层（填表）依赖数据认知重构（让网格能落到具体地点）吗？

**定案（claude组 关键发现）**：
- **macro 出口零依赖**（用面域名+极性面即可）→ **可立即做**（解阻塞）
- **meso/micro 出口依赖 CB-15**（要 place_name + POI 清单）→ CB-15 后做
- **两波**：Wave 1 = 出口骨架 + macro；Wave 2 = CB-15 完成后 meso/micro

### 焦点 5：MVP 范围（先做哪些场景）

**通俗说**：六场景先做哪几个？

**定案（claude组 修订）**：**先 S2 单场景打穿**（用户亲举例·覆盖 meso+micro·端到端演示"情绪地图找市场"）> 三场景半成品。

### 焦点 6：行业知识库出向扩展

**通俗说**：行业知识库要加"出向字段"（定义对接接口）吗？

**定案**：**不新建目录**，`urban_renewal.py` 同文件加 OUTLET_CONTRACTS（入向+出向同政策一体两面·防漂移）。
