### 关键新增（两组深化·合并入定稿）

1. **Codex 补⑤（根因深化）**：「限制」为**分析确定性**设计·但知识问答需「自由综合」——**两套需求共用一个受限 harness 是根因·增强应分通道**（分析=确定性红线不动·问答=自由综合）——PARADIGM_MAP 分类→范式映射深化
2. **glm 分 tier（最直接缩小差距）**：CB-12 强制 flash 是**分析类速度决策**·知识问答通道应开 pro（综合深度·pro 延迟值得）——分通道 tier（知识=pro·分析=flash·概念=flash）
3. **Codex pro 停用张力**：CB-12 与 tier 差距·知识问答是否开 pro → **待用户决策**
4. **通道质量基线**：知识问答黄金集 + 分析 B3 双轨回归（增强后两侧守住）

## 一、定稿架构（三通道路由 + 意图判断归位）

```
意图判断 agent（diagnoseStep·LLM）→ 路由三通道：
  知识问答（intent=knowledge_qa）→ rag_search 检索 → 注入素材 → finalStep LLM 综合
  GIS 工具（intent=gis_operation）→ 14 工具执行 → 图层

统一表达层三段式（观点 + 方法/分级 + 对标）·内容通道化（各通道按自身产物填三段）
```

**知识问答通道**（本次修复核心）：diagnose 加 `knowledge_qa` 枚举（LLM 判）·短路降级加速器（明显命中直通）·**两者合流**统一范式（rag_search→注入→finalStep）。
