## 〇、对齐总判定 + 交叉挑战开篇

**三支柱 + 产品定位认可·修正后路径（检索→路由→LLM 综合）认可**。**同时挑战三处**（含对自己）：
1. **挑战 claude 收敛过程**：选 B 弃 A 且两组无交叉挑战——复盘成立·**我认领：上一轮我提了 A 但未挑战 glm 的 B（零 LLM）·交叉挑战缺失在我**
2. **挑战"零 LLM"边界**：R3 EXIT_CONCEPT 兜底本身零 LLM——**必须显式限定"零 LLM 只允许出现在失败兜底·成功路径必须 LLM 综合"**·防未来有人以"R3 已有零 LLM 先例"为由把成功路径也砍成零 LLM
3. **挑战"指令治本"幻觉**：我的 A（注入指令）是治标——**若知识库素材质量差（检索命中率/覆盖维度不足）·LLM 综合也救不了**——三支柱是**联动**的（指令=架构·素材=知识库·缺素材时架构/LLM 空转）·不能只靠指令

## 1 · 三支柱原则 — agree（+ 每根支柱的质量下限）

| 支柱 | 认可 | 质量下限（防"有支柱但空转"） |
|---|---|---|
| ① 本地知识库完备度 | ✅ | **检索命中率 + 覆盖维度**（黄金集 Recall@5 是量化尺子·非"文件多"）——事实卡扩量/笔记质量持续投入 |
| ② EMC 架构（分类→范式） | ✅ | **正确路由 + 失败兜底**（R3 EXIT_CONCEPT 是架构的一部分·非旁路）——PARADIGM_MAP 显式化（上轮讨论仍待落地） |
| ③ LLM 归纳总结 | ✅ | **只归纳·不新增事实**（综合边界 = 组织/表述/归纳素材·不补素材外数值） |

**融入方式**：后续任何方案收敛前过「三支柱检查」——标"动了哪支柱·哪支柱质量下限是否达标"。

## 2 · 产品定位 — agree（+ LLM 综合边界条目建议）

**认可**：EMC+RAG = 本地化聚焦专业知识蒸馏（稳定准确全面·可追溯·区别于网络搜索/其他 AI）。

**体现**：
- 素材只来自本地知识库（L0/L1.5·非网络）·回答带来源（可追溯）·聚焦宜昌城市更新/城市体检专题·专业话语（行业术语/方法论）

**建议（挑战延伸）**：KNOWLEDGE 蒸馏补一条边界——**"LLM 综合 = 归纳+组织+表述·不新增事实"**——产品定位的"准确"依赖此边界（黄金集③"案例不引数据"正是该边界的机器化）·防"综合"变"编造"。

## 3 · 修正后路径 — agree（补 3 点）

```
rag_query → 检索素材（一）→ 路由知识问答范式（二）→ finalStep LLM 综合+引用（三）
```

**补 1（准确性关键）·「只基于素材」**：注入块指令强化"**只基于上述素材作答·素材未覆盖的信息标注'知识库未收录'**"——防 LLM 用预训练知识补细节（用户三疑问"没引用知识库"的反面：引用了但不能补编）

**补 2（防回归）·范式契约显式化**：PARADIGM_MAP（`emc-patterns.js`）落地——本次两轮失败正是"分类→范式"隐式导致·映射表是架构支柱的防回归机制

**补 3（边界声明）·零 LLM 只在失败兜底**：R3 EXIT_CONCEPT 保留（素材/架构失败时防幻觉）·但注释/文档显式"**成功路径必须 LLM 综合**·零 LLM 不得用于成功路径"

## 4 · 零 LLM 教训 — agree（机制 3 条）

| 机制 | 说明 |
|---|---|
| **三支柱检查入收敛清单** | 每个方案收敛前过三支柱·标"动了哪支柱"·砍支柱=一票否决 |
| **组间交叉挑战制度化** | 收敛前每组对其他组方案至少提 **1 条挑战或确认**（写入收敛模板·KNOWLEDGE §7 协作规则补条目）——本次教训：无交叉挑战 → claude 独立收敛到错方案 |
| **"零 LLM"边界词条** | KNOWLEDGE 蒸馏："零 LLM 只允许失败兜底·成功路径必须 LLM 综合"（防未来重蹈） |

**挑战自己（A 方向）**：A（注入指令）若单独落地·在素材质量差时输出仍不稳——**指令必须与素材质量（支柱①）联动评估**·验收含素材质量指标（Recall@5）·不是只验收指令效果。

## 5 · 知识问答范式细节 — agree（稳定/准确/全面三要素 + 指令精简）

| 要素 | 设计 |
|---|---|
| **稳定** | 路由确定（PARADIGM_MAP·同问同路）+ 指令模板固定（同 quick-general 模式·非 LLM 自定） |
| **准确** | **只基于素材**（禁补素材外数值/事实）+ 来源标注（每条关键数据可溯源）+ 维度声明（不越维·颗粒度原则） |
| **全面** | Top-5 素材多源（事实卡+笔记+案例）+ 条目式组织（信息分层不丢点） |

**指令精简（挑战：指令越长遵守率越差）**——硬约束 ≤3 条：
1. 禁生成分析图层 / {{show:图层}} / 4×5 归因 / 演示逻辑链
2. 只基于上述素材作答·素材外标注"知识库未收录"
3. 条目式 + 关键数据带来源

（维度声明随注入块自动带·不占指令条数）
