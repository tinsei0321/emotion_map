## ② 发现清单

### P2 级（2 件）

**P2-1［B·grid_aggregate］空点层/boundary 裁剪后零点 → 错误语义化不达标**（实证复现）

- 证据：[mcp_server_emc.py:603-605](tools/mcp_server_emc.py#L603) `stats = {'total_cells': row_count, 'nonzero_cells': int((merged['point_count']>0).sum()), 'max_count': int(merged['point_count'].max())}`——空结果时 pandas `max()` 返回 nan，`int(nan)` 抛 `ValueError: cannot convert float NaN to integer`（本审计 py 实测复现）→ 落入通用 `except Exception` → 返回模糊错误 `grid_aggregate 失败: cannot convert...`；若 `create_square_grid` 对空输入返回无列空 df → `merged['point_count']` KeyError → 走 [mcp_server_emc.py:608](tools/mcp_server_emc.py#L608) `_UNKNOWN_HINT`「未知层 id」——**层是合法的、只是裁剪后没点，报"未知层"是误导**。
- 触发面：用户 boundary 给错（裁剪零点）或空点层——真实可发生。
- 影响：不崩溃（except 兜住）但违反派发单铁则 7「错误语义化」；宿主收到误导 hint 会去查 list_data 而非改 boundary。
- **修复条件（commit B 过审条件）**：stats 前判空——`row_count == 0` → 语义化返回 `{'ok': False, 'hint': '聚合结果为空（点层为空或 boundary 裁剪后零点）…', 'caliber': ...}`；补 1 用例。约 5-8 行。建议随 Kimi 件回收批或 P2 批顺手合入。
- **佐证测试盲区**：commit B 的 11 用例无空集边界用例（mock 全用非空 fake·主手真实链路复测用真实大层）——**两侧验证结构都没覆盖此边界，独立审计补位**。

**P2-2［A·render_policy］前缀通配无边界**（张力项·非漏洞实锤）

- 证据：[render_policy.py:41](core/render_policy.py#L41) `DATASET_PROP_PREFIXES = ('polarity','score','domain','element','poi','place')` + `field.startswith(...)`——任意 `poi_xxx`/`place_xxx`/`domain_xxx` 后缀字段自动放行（如假想的 `poi_private_note`）。该前缀集**自 render_routes 原样迁移**（C2-4 既有语义·非本批新增），且现库无敏感字段命中此前缀面。
- 判定：与「默认拒绝·不放行含个人信息字段」纪律存在张力·当前零实际外流（三 preset renderFields 全为统计字段·已逐项核）。
