## 任务 D：服务新旧核查工具（R7 预防·新建小工具）

**业务背景**：调试记忆 R7 两次实战（旧进程载旧码致修复"失效"/守卫"消失"）——做一个一键核查脚本，报告当前服务进程是否早于最新代码提交（= 载旧码风险）。

**产出**：`tools/check_server_freshness.py`（新建·不改任何旧文件）+ 文末演示输出。

**逻辑**：netstat 查 8000/8080 LISTENING PID → 进程启动时间（wmic process get CreationDate）→ `git log -1 --format=%cd` 最新提交时间 → 对比 → `[OK] 服务晚于最新提交` / `[WARN] 服务早于最新提交 X 分钟——载旧码风险，建议重启（R7）`。无服务在跑 → `[OK] 无服务运行`。

**限制**：纯报告型（**不杀进程不重启**）；ASCII 标记铁律（[OK]/[WARN]）；`_safe_print` 惯例；无第三方依赖。

**验收**：本机演示运行一次并记录输出（当前 8080 服务在跑·应报实际状态）。
