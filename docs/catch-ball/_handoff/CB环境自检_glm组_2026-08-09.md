## 三、⚠️ 机制提醒（1 项 · 非阻塞 · 供 claude组 分配参考）

### EMOTION_TRACE_SESSION 对 pytest 单测无效

**glm组 实测发现**：
- 带 `EMOTION_TRACE_SESSION=glm-selfcheck2` 跑 `tests/test_outlet_schema.py`（41 passed）→ `trace_query --stats --session glm-selfcheck2` 查询返 **0 行**。
- 根因：pytest 单测**不调 LLM/工具链**（不走 FC/agentStep/finalStep）· trace.log 只记运行时 LLM 调用 · 单测不触发 trace 写入。

**含义与建议**：
| 测试类型 | 是否需带 session | 说明 |
|---|---|---|
| pytest 单测回归 | ❌ 不需要 | 单测不产 trace · session 标签无意义 |
| B3 飞轮 / e2e 浏览器 | ✅ **必须带** | 走真实问答链路（FC→工具→finalStep）· 必须用 `EMOTION_TRACE_SESSION=glm-<批号>` 隔离取证 |
| 静态核验（代码级） | ❌ 不需要 | 不跑运行时 · 无 trace |

**给 claude组 的分配建议**：分配任务时标注测试类型·若 B3/e2e 则提醒带 session 标签·glm组 会按标签隔离 trace 取证。
