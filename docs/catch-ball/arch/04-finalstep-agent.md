## 一、职责

> 收到工具 observation → 生成面向用户的结论 + 追问胶囊。

## 二、改造

### 2.1 Light Prompt

```
系统指令（~500 字节）：
  基于 observation 写 2-3 句结论 + 生成追问胶囊。
  
  规则：
  1. 直接引用 observation 中的参数值和统计
  2. 包含 {{show:图层名}} 按钮
  3. 诚实——工具失败就说失败·不要编造
  4. 不追加"建议进一步分析"等多余操作

输入：用户 NL + observation（结构化·模块三统一格式）

输出：结论 markdown + 追问胶囊列表
```

| | 当前 | 重构后 |
|------|:---:|:---:|
| Prompt | 20-44KB | ~1-2KB |
| Prefill | 20-35s | <1s |
| 生成 | 5-15s | 2-3s |
| **总计** | **25-50s** | **3-5s** |

### 2.2 追问胶囊三级体系

| 级别 | 特征 | 需要 | 举例 | 耗时 |
|:---:|------|------|------|:---:|
| **L1 直达** | 同工具·不同参数 | 无·直接执行 | "切换消极热力图" | <2s |
| **L2 轻判** | 跨工具·单步·参数可派生 | Pro 确认参数·跳过 Flash | "对结果按最差排序" | 5-8s |
| **L3 计划** | 跨工具·多步·需完整推理 | CPD 多轮引导·走完整管线 | "看西陵区归因" | 15-20s |

**L3 不作为追问胶囊**——由 CPD 在下一轮重新走完整管线。

### 2.3 追问胶囊结构

```javascript
{
  label: "切换消极热力图",    // 用户看到
  level: "L1",                // L1/L2
  tool: "density",            // 目标工具
  params: {                   // 预填参数
    analysis: "negative",
    polarity: "N"
  }
}
```

**L1**：点击 → 直接执行·不经 Diagnose

**L2**：点击 → 跳过 Flash → Pro 确认参数 → 执行

**安全约束**：LLM 只能从 observation 上下文中派生追问——不能提 EMC 做不到的事。
