# 阶段交接段模板（八字段）— PT-CB18(W1-1)

> 落点：`STATE.md` 末尾「## 手写区」。
> 触发条件：**里程碑级阶段结束才手写本段**；小批只跑 `py tools/gen_state.py` 刷机器骨架。
> 红线：禁写密码、密钥、令牌；生成器逐字节保留手写区，不会被覆写。

## 使用口径

- 一段交接 = 八字段齐，缺字段写「无」，不删字段（方便下手机器化核对）。
- 每段一行为主，长内容落文档后给路径，不在交接段堆正文。
- 在途状态只写 `STATE.md`；每日记忆只记一行式结论与决策，**状态字段禁写**（防双头漂移）。

## 模板

```
### 交接段：{阶段名}（{日期}·{写段人}）

1. 当前目标：（一句话·本阶段要达成什么）
2. 已完成内容：（可核验的事实清单·带 commit 或文档路径）
3. 关键技术决策：（决策 + 一句理由·ADR 有编号给编号）
4. 修改过的核心文件：（路径清单·不贴代码）
5. 测试与验证结果：（门禁数/契约用例/实测口径·如 618+1 零失败）
6. 已知问题：（未修项 + 影响面·无则写「无」）
7. 尝试过但失败的方案：（方案 + 失败原因·防后人重踩·无则写「无」）
8. 下一步开发顺序：（有序清单·接手者照做即可开工）
```
