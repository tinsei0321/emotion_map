# AUTHORITY（权威数据）

权威范围/点/线数据，作为 RAG 的权威数据层。命名规则：`boundaries_` / `points_` / `lines_` 前缀，`_` 后接数量（去重后）。

## 当前清单

- `boundaries_中心城区范围_8.geojson`：中心城区范围 + 组团/行政区（MC 已修正：小溪塔组团、龙泉、白洋·顾家店组团；龙泉绿心已并入龙泉，保留生物产业园）。
- `boundaries_核心主城_西陵伍家_2.geojson`：西陵区 + 伍家岗区，两个面保留分隔线。
- `boundaries_核心主城_西陵伍家_1.geojson`：西陵区 + 伍家岗区 dissolve 为单面（去分隔线）。
- `boundaries_街办_22.geojson`：体检对象街办面（22 个，来源 2025）。
- `boundaries_社区村_193.geojson`：体检对象社区面（193 个，社区 + 村）。
- `boundaries_小区_1562.geojson`：体检对象小区面（1562 个）。
- `points_住宅_26426.geojson`：体检对象住宅点（26426 个）。

## RAG 注入约定

- 这些文件同时是分析取数入口：优先用 `list_data` / `resolve_boundary` / `resolve_points` 调用，禁止反复上传。
- 权威范围语义：中心城区正式行政区为西陵区、伍家岗区、点军区、夷陵区、猇亭区；在中心城区描述中，“小溪塔/龙泉/白洋”为组团，其中夷陵区含小溪塔和龙泉，白洋全称为“白洋·顾家店组团”。
