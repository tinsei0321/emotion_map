## 五、字段映射 → checkup schema（阶段 1 适配器）

点层/面层截断中文 → checkup 公共列子集：

| checkup 字段 | 来源（dbf 截断中文 / GDB 拼音缩写） |
|---|---|
| `indicator` | 文件名语义（停车/学位/充电桩/结构隐患…） |
| `dimension` | 住房/小区/街区/城区（分组目录语义） |
| `region` | 行政区/街办（GDB 层 xzqhdm 系列 / 面层空间 join） |
| `value` | 停车泊/小学学/新能源/电动自（缺口数）·栋数=要素数 |
| `lon/lat` | 点层直接读；面层质心化生成 |
| `source` | 源文件路径（{URENEWAL_ROOT} 占位） |
| `year` | 2025（体检年度） |

> 坐标**直接透传 WGS84**，无 GCJ 二次转换（对照 tests/test_geocode.py 红线 #2：漏转/错转 = 50-500m 静默偏移）。
