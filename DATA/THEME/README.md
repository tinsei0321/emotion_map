# THEME（专题数据）

专题数据层，作为 RAG 的专题数据与信息。命名规则：`themes_` + 集合类型（point/polygon/line）+ `_` + 主题 + `_` + 数量（去重后）。

## 子目录

- `theme_城市体检/`：城市体检问题指标点数据（去掉“两个方面”结论，按问题类型组织）。
- `theme_12345政务热线/`：12345 政务热线 L0-L3 数据（L0 原始、L1 情绪点、L2 极性点、L3 归因点；L1-L3 待重做）。

## 约定

- 专题数据不包含“安全韧性/民生基础”两大方面的结论性标签；仅保留问题类型与问题描述。
- 12345 数据同时是情绪地图主项目的原始数据之一：城市体检视角的派生分析只能作为城市更新专题知识，不能当作情绪地图分析结论。
