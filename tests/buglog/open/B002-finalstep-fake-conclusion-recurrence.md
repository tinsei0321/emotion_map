# B002 · finalStep 假结论 — "只说不做/只做一半"（复现）

## 标准化用例

**问句**：「剪裁出西陵区范围内的商业+居住+公园广场用地」

**数据前提**：行政区面层（含西陵区边界）+ 商业/居住/公园广场用地面层

**预期行为**：
① clip 工具被选中，以西陵区边界为裁剪范围
② 分别对商业、居住、公园广场三类用地执行裁剪（或用 merge 合并后一次裁剪）
③ 生成「西陵区_商业_居住_公园广场」面图层
④ 结论诚实描述实际产出（不编造未生成的图层）

## 诊断摘要

**根因**：`harness.js:523` 的 finalStep context 注入只有计划描述（「单技能路径·已执行 extract_feature」），不区分执行成功/失败。LLM 收到的上下文是"计划已执行"的陈述，于是按计划写出了完整结论，但实际工具执行并未产生对应图层。

**治本方向**（CB-09 P1-1）：finalStep context 注入执行结果摘要（成功/失败/产出图层数），让 LLM 依据实际结果而非计划来写结论。
