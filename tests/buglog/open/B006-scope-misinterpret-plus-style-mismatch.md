# B006 · 意图理解偏差 + 图层样式不匹配（部分新）

## 标准化用例

**问句**：「能帮我筛选出西陵区的情绪点吗？」

**数据前提**：积极/中性/消极三个独立情绪点层 + 西陵区边界

**预期行为**：
① LLM 正确理解"情绪点"= 三个极性的情绪点（非仅积极）
② 方案 A：先 merge 三个极性点层 → 再 clip 西陵区 → 生成「西陵区全量情绪点」
③ 方案 B：分别 clip 三个极性 → 生成三个独立图层
④ 生成的图层**严格匹配标准图例样式**（颜色/大小/透明度按图例规范）
⑤ 如果当前无法一步完成，诚实告知并提供选择（合并 or 分极性）

## 诊断摘要

**问题 A — 意图缩窄（Scope Misinterpretation）**：
用户问"情绪点"（无极性限定），LLM 在 thinking trace 中自我推理"我先裁剪积极情绪点——数据最多（9922条），给用户一个直观感受"，主动将范围从"全极性"缩窄为"积极"。这是 LLM 的"过度帮助"偏误——在缺乏明确指引时倾向于选择"最安全/数据最多"的选项而非"最完整"的。

**问题 B — 图层样式不匹配（NEW，CB-09 未覆盖）**：
用户明确指出"筛选出的情绪点并未按照标准图例进行样式匹配。这是个大问题，所有生成的图层都要严格匹配我制作的图例和成图样式。"这说明：
- 当前 `clip` / `extract_feature` 等工具生成的图层使用默认样式
- 没有读取/继承源图层的图例配置（如情绪点的极性颜色映射、大小、透明度）
- 缺乏"样式继承"机制——新图层应该保持与源图层相同的视觉语言

**治本方向**：
- 问题 A：FC system prompt 加指引——当用户未限定极性时，默认操作全部极性而非自行选择
- 问题 B（新）：工具生成的图层需继承源图层的样式配置（symbology propagation），或在生成后自动应用对应图例的默认样式
- 架构层面：需要一个「样式解析器」——根据图层类型（情绪点/热力图/面层）和图例系统自动匹配样式
