# 飞轮失败归属表（deferred · 手动维护）

> **用途**（CB-10 飞轮审查 F-6）：no-llm/llm 飞轮的**已知失败项归属**——每条必二选一：建 buglog 条目 或 进本表（原因 + 归属）。防「长期红无主」——pass% 失去参照意义。
> **原则**：已识别原因 + 明确归属的失败进本表；新失败先进 buglog 排查，排查清楚后移本表或修复。
> **与 buglog 关系**：本表 = 已知/已诊断失败；buglog = 待修 bug（含根因指针）。失败归属后不再「无主」。
