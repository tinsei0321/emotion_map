# EMC 测试用例目录（飞轮测试基准）

> **用途**：EMC AI 问答全链路测试用例（15-20 个·聚焦 LLM 路径）。供飞轮自动验证 + 人工对照。
> **分类**：🟢 路由 / 🔵 参数 / 🟡 层引用 / 🟠 追问 / 🔴 降智 / 🟣 诚实 / ⚡ 速度 / 📝 语言
> **数据前提**：L2 情绪点数据已加载（yichang_l2_t1 或 t3）+ 行政区边界已加载 + （部分用例）中心城区范围面层。

---

## 一、路由类（FC 选对工具）

### TC-01 生成综合热力图 🟢⚡
- **问句**：「帮我生成一张 L2 数据的情绪热力图」
- **预期**：FC 选 density(polarity=overall) → 2D 彩虹热力图 → 结论含分布描述
- **断言**：① density 被选中 ② 图层已生成 ③ 结论含「综合/全域/分布」④ 结论无英文术语
- **标签**：路由/速度

### TC-02 切换消极热力图 🟢🟠
- **问句**：（上轮综合热力图后）「进一步分析消极情绪点的分布」
- **预期**：plans[] 优先匹配 density(polarity=negative) → 消极热力图 → 结论含消极区域描述
- **断言**：① 不走 FC（plans 复用）② 不选 filter_attr ③ 消极热力图已生成
- **标签**：追问/路由/降智（pre-refactor 版本此处失败）

### TC-03 区域排序 🟢
- **问句**：「哪些区域情绪最差？排序看看」
- **预期**：FC 选 rank(by=worst) → Top N 排序表 + 高亮图层
- **断言**：① rank 被选中 ② 排序结果含区域名+极性值 ③ 高亮图层已生成
- **标签**：路由

### TC-04 区域归因 🟢
- **问句**：「这几个街道的情绪归因分析」
- **预期**：FC 选 zonal(boundary=admin_district) → 每单元归因 + 4×5 矩阵
- **断言**：① zonal 被选中 ② 含 domain/element 归因 ③ 聚合图层已生成
- **标签**：路由

### TC-05 区域对比 🟢
- **问句**：「对比西陵区和伍家岗区的情绪差异」
- **预期**：FC 选 compare(boundaries=西陵区,伍家岗区) → 并排对比
- **断言**：① compare 被选中 ② 含两区差异描述 ③ 对比图已生成
- **标签**：路由

### TC-06 抽取面层要素 🟡🔵
- **问句**：「帮我从中心城区范围中裁剪出西陵区的范围」
- **预期**：FC 选 extract_feature(layer=面层, where=name/eq/西陵区) → 抽取西陵区面
- **断言**：① extract_feature 被选中 ② 字段自纠正（MC→name）③ 西陵区面已抽取
- **标签**：路由/层引用/参数（pre-refactor 版本此处失败：MC 字段幻觉）

### TC-07 概念问短路 🟢⚡
- **问句**：「什么是情绪地图？」
- **预期**：_quickIntent general 短路 → finalStep 直接回答（不走 FC/diagnose）
- **断言**：① 不走 FC ② 回答含情绪地图核心概念 ③ 回答风格生动（非技术日志）
- **标签**：路由/速度/语言

## 二、参数 + 层引用类

### TC-08 缓冲分析 🔵🟡
- **问句**：「滨江公园周边 500 米的情绪分布」
- **预期**：FC 选 buffer(center=滨江公园, radius_m=500) → 缓冲面 + 圈内聚合
- **断言**：① buffer 被选中 ② radius=500 ③ 缓冲图层已生成
- **标签**：参数/层引用

### TC-09 叠置分析 🔵
- **问句**：「商业用地和居住用地的交集区域」
- **预期**：FC 选 overlay(layer_a=商业用地, layer_b=居住用地, how=intersection)
- **断言**：① overlay 被选中 ② 交集面已生成 ③ 面积统计正确
- **标签**：参数

### TC-10 裁剪点层 🟡
- **问句**：「西陵区范围内的情绪点」
- **预期**：FC 选 clip(range=西陵区) → 点子集
- **断言**：① clip 被选中 ② 点层裁剪结果 ③ 不报「无点层」（有点数据）
- **标签**：层引用

### TC-11 极性切换（积极） 🟠🔵
- **问句**：（上轮综合后）「换个角度看看积极情绪的分布」
- **预期**：plans[] 匹配 density(polarity=positive) → 积极热力图
- **断言**：① 不走 FC ② 积极热力图已生成
- **标签**：追问/参数

## 三、降智 + 诚实类

### TC-12 无点数据时拒绝执行 🔴🟣
- **前提**：只加载面层（无情绪点层）
- **问句**：「生成情绪热力图」
- **预期**：data gate 触发 strategy=request_upload → 优雅提示「需上传情绪点数据」
- **断言**：① 不硬跑 density ② 不报「[ERR] 无已加载的情绪点层」③ 提示友好
- **标签**：降智/诚实（pre-refactor 版本此处报错降智）

### TC-13 失败后智能建议 🔴🟣
- **前提**：只有面层·无点层
- **问句**：「帮我裁剪西陵区的点」
- **预期**：clip 失败（无点）→ ask_user 含 extract_feature 建议
- **断言**：① 失败不裸报 ERR ② 建议含「抽取面层」选项
- **标签**：降智/诚实

### TC-14 编造图层名拦截 🟣
- **问句**：「生成热力图」（正常流程）
- **预期**：工具执行成功 → finalStep 出结论 → applyQualityDefense 校验产出层
- **断言**：① 结论不声称不存在的图层 ② applyQualityDefense 不崩（reg.filter 已修）③ 胶囊正常显示
- **标签**：诚实（pre-refactor 版本此处 reg.filter 崩溃）

### TC-15 FC 失败降级 ⚡🔴
- **模拟**：FC 端点超时或返无 tool_calls
- **预期**：降级→旧 SSE diagnose 或极简 fallback → 仍出结论
- **断言**：① 不裸报「请求失败」② 用户最终得到回答
- **标签**：速度/降智

## 四、语言风格类

### TC-16 禁英文术语 📝
- **问句**：「分析情绪热度」
- **预期**：结论全中文·无 extract_feature / density / polarity / emotion_intensity 等
- **断言**：grep 结论文本·不含英文字段名/工具名/参数名/箭头符号
- **标签**：语言

### TC-17 禁箭头符号 📝
- **问句**：「排序最差区域」
- **预期**：结论用逗号/句号断句·不出现 → 箭头
- **断言**：grep 结论·不含 → 或 →
- **标签**：语言

### TC-18 生动专业表达 📝
- **问句**：「什么是情绪地图？」
- **预期**：回答含「人民城市」「温情治理」「急难愁盼」等背景词汇·生动不学术
- **断言**：① 回答 >50 字 ② 含至少 1 个背景关键词 ③ 非纯技术描述
- **标签**：语言

## 五、复合 + 追问链

### TC-19 多轮复合追问 🟠🔵
- **流程**：R1「生成热力图」→ R2「分析消极」→ R3「哪些区域最差」→ R4「裁出最差区域」
- **预期**：R1 density(overall) → R2 plans 复用 density(negative) → R3 rank(worst) → R4 extract_feature/rank 结果
- **断言**：① 每轮不失败 ② 追问胶囊出现 ③ 层引用不幻觉
- **标签**：追问/复合

### TC-20 胶囊点击执行 🟠⚡
- **前提**：上轮结论含追问胶囊（如「切换积极热力图」）
- **操作**：点击胶囊
- **预期**：runCapsule 跳 FC → density(polarity=positive) → 积极热力图
- **断言**：① <2s 出图 ② 不走 FC 诊断 ③ 图层正确
- **标签**：追问/速度
