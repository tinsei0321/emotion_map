## 一、路由类（FC 选对工具）

### TC-01 生成综合热力图 🟢⚡
- **问句**：「帮我生成一张 L2 数据的情绪热力图」
- **预期**：FC 选 density(polarity=overall) → 2D 彩虹热力图 → 结论含分布描述
- **断言**：① density 被选中 ② 图层已生成 ③ 结论含「综合/全域/分布」④ 结论无英文术语
- **标签**：路由/速度

### TC-02 切换消极热力图 🟢🟠
- **问句**：（上轮综合热力图后）「进一步分析消极情绪点的分布」
- **预期**：plans[] 优先匹配 density(polarity=negative) → 消极热力图 → 结论含消极区域描述
- **断言**：① 不走 FC（plans 复用）② 不选 filter_attr ③ 消极热力图已生成
- **标签**：追问/路由/降智（pre-refactor 版本此处失败）

### TC-03 区域排序 🟢
- **问句**：「哪些区域情绪最差？排序看看」
- **预期**：FC 选 rank(by=worst) → Top N 排序表 + 高亮图层
- **断言**：① rank 被选中 ② 排序结果含区域名+极性值 ③ 高亮图层已生成
- **标签**：路由

### TC-04 区域归因 🟢
- **问句**：「这几个街道的情绪归因分析」
- **预期**：FC 选 zonal(boundary=admin_district) → 每单元归因 + 4×5 矩阵
- **断言**：① zonal 被选中 ② 含 domain/element 归因 ③ 聚合图层已生成
- **标签**：路由

### TC-05 区域对比 🟢
- **问句**：「对比西陵区和伍家岗区的情绪差异」
- **预期**：FC 选 compare(boundaries=西陵区,伍家岗区) → 并排对比
- **断言**：① compare 被选中 ② 含两区差异描述 ③ 对比图已生成
- **标签**：路由

### TC-06 抽取面层要素 🟡🔵
- **问句**：「帮我从中心城区范围中裁剪出西陵区的范围」
- **预期**：FC 选 extract_feature(layer=面层, where=name/eq/西陵区) → 抽取西陵区面
- **断言**：① extract_feature 被选中 ② 字段自纠正（MC→name）③ 西陵区面已抽取
- **标签**：路由/层引用/参数（pre-refactor 版本此处失败：MC 字段幻觉）

### TC-07 概念问短路 🟢⚡
- **问句**：「什么是情绪地图？」
- **预期**：_quickIntent general 短路 → finalStep 直接回答（不走 FC/diagnose）
- **断言**：① 不走 FC ② 回答含情绪地图核心概念 ③ 回答风格生动（非技术日志）
- **标签**：路由/速度/语言

## 二、参数 + 层引用类

### TC-08 缓冲分析 🔵🟡
- **问句**：「滨江公园周边 500 米的情绪分布」
- **预期**：FC 选 buffer(center=滨江公园, radius_m=500) → 缓冲面 + 圈内聚合
- **断言**：① buffer 被选中 ② radius=500 ③ 缓冲图层已生成
- **标签**：参数/层引用

### TC-09 叠置分析 🔵
- **问句**：「商业用地和居住用地的交集区域」
- **预期**：FC 选 overlay(layer_a=商业用地, layer_b=居住用地, how=intersection)
- **断言**：① overlay 被选中 ② 交集面已生成 ③ 面积统计正确
- **标签**：参数

### TC-10 裁剪点层 🟡
- **问句**：「西陵区范围内的情绪点」
- **预期**：FC 选 clip(range=西陵区) → 点子集
- **断言**：① clip 被选中 ② 点层裁剪结果 ③ 不报「无点层」（有点数据）
- **标签**：层引用

### TC-11 极性切换（积极） 🟠🔵
- **问句**：（上轮综合后）「换个角度看看积极情绪的分布」
- **预期**：plans[] 匹配 density(polarity=positive) → 积极热力图
- **断言**：① 不走 FC ② 积极热力图已生成
- **标签**：追问/参数

## 三、降智 + 诚实类

### TC-12 无点数据时拒绝执行 🔴🟣
- **前提**：只加载面层（无情绪点层）
- **问句**：「生成情绪热力图」
- **预期**：data gate 触发 strategy=request_upload → 优雅提示「需上传情绪点数据」
- **断言**：① 不硬跑 density ② 不报「[ERR] 无已加载的情绪点层」③ 提示友好
- **标签**：降智/诚实（pre-refactor 版本此处报错降智）

### TC-13 失败后智能建议 🔴🟣
- **前提**：只有面层·无点层
- **问句**：「帮我裁剪西陵区的点」
- **预期**：clip 失败（无点）→ ask_user 含 extract_feature 建议
- **断言**：① 失败不裸报 ERR ② 建议含「抽取面层」选项
- **标签**：降智/诚实

### TC-14 编造图层名拦截 🟣
- **问句**：「生成热力图」（正常流程）
- **预期**：工具执行成功 → finalStep 出结论 → applyQualityDefense 校验产出层
- **断言**：① 结论不声称不存在的图层 ② applyQualityDefense 不崩（reg.filter 已修）③ 胶囊正常显示
- **标签**：诚实（pre-refactor 版本此处 reg.filter 崩溃）

### TC-15 FC 失败降级 ⚡🔴
- **模拟**：FC 端点超时或返无 tool_calls
- **预期**：降级→旧 SSE diagnose 或极简 fallback → 仍出结论
- **断言**：① 不裸报「请求失败」② 用户最终得到回答
- **标签**：速度/降智

## 四、语言风格类

### TC-16 禁英文术语 📝
- **问句**：「分析情绪热度」
- **预期**：结论全中文·无 extract_feature / density / polarity / emotion_intensity 等
- **断言**：grep 结论文本·不含英文字段名/工具名/参数名/箭头符号
- **标签**：语言

### TC-17 禁箭头符号 📝
- **问句**：「排序最差区域」
- **预期**：结论用逗号/句号断句·不出现 → 箭头
- **断言**：grep 结论·不含 → 或 →
- **标签**：语言

### TC-18 生动专业表达 📝
- **问句**：「什么是情绪地图？」
- **预期**：回答含「人民城市」「温情治理」「急难愁盼」等背景词汇·生动不学术
- **断言**：① 回答 >50 字 ② 含至少 1 个背景关键词 ③ 非纯技术描述
- **标签**：语言

## 五、复合 + 追问链

### TC-19 多轮复合追问 🟠🔵
- **流程**：R1「生成热力图」→ R2「分析消极」→ R3「哪些区域最差」→ R4「裁出最差区域」
- **预期**：R1 density(overall) → R2 plans 复用 density(negative) → R3 rank(worst) → R4 extract_feature/rank 结果
- **断言**：① 每轮不失败 ② 追问胶囊出现 ③ 层引用不幻觉
- **标签**：追问/复合

### TC-20 胶囊点击执行 🟠⚡
- **前提**：上轮结论含追问胶囊（如「切换积极热力图」）
- **操作**：点击胶囊
- **预期**：runCapsule 跳 FC → density(polarity=positive) → 积极热力图
- **断言**：① <2s 出图 ② 不走 FC 诊断 ③ 图层正确
- **标签**：追问/速度

## 六、CF-09 新采集用例（2026-07-29）

> 以下 TC-21 ~ TC-27 来自用户实测反馈，经标准化后注入飞轮。关联 buglog：`tests/buglog/open/B001~B007`。

### TC-21 多类用地裁剪 + 诚实结论 🆕🔴🟣
- **问句**：「剪裁出西陵区范围内的商业+居住+公园广场用地」
- **前提**：西陵区边界 + 商业/居住/公园广场三份用地面层
- **预期**：
  ① FC 规划多步链（clip 商业 + clip 居住 + clip 公园广场 → merge，或 merge 三类用地 → clip 西陵区）
  ② 所有步骤执行完毕后才进入 finalStep
  ③ 结论诚实描述实际产出（不编造未生成的图层）
  ④ 生成面图层「西陵区_商业_居住_公园广场」
- **断言**：① 有图层产出 ② 图层类型=面层 ③ 图层含三类用地 ④ 结论无假产出声明
- **标签**：诚实/多步链/层引用
- **关联 Bug**：B002（finalStep 假结论）、B005（多步链断裂）
- **已知失败**：2026-07-29 — 仅生成西陵区边界，未裁剪用地图层（finalStep 假结论）

### TC-22 数据清单查询 — 短路径 🆕⚡🟢
- **问句**：「我上传了哪些数据？」
- **前提**：已上传多份数据（情绪点 + 边界 + 用地 + 水系）
- **预期**：
  ① _quickIntent 识别为 general 类（数据清单查询，非地理分析）
  ② 直接短路回答（不走 FC / diagnose）
  ③ 回答按类型分组（情绪评价点 / 行政边界 / 用地类型 / 水系），附数量统计
  ④ 响应时间 < 5s
- **断言**：① 不走 FC ② 回答含数据分类 ③ 响应时间 < 5s ④ 不出现推理螺旋
- **标签**：路由/速度/诚实
- **关联 Bug**：B003（LLM 推理螺旋）
- **已知失败**：2026-07-28 C2 — 7 轮推理螺旋后答错；2026-07-29 — 7 轮推理螺旋后答对但耗时久

### TC-23 点层裁剪执行验证 🆕🟣
- **问句**：「将西陵区范围内的积极情绪点筛选出来单独显示。」
- **前提**：西陵区边界 + 积极情绪点层
- **预期**：
  ① clip 工具被正确调用（target=积极情绪点层，range=西陵区边界）
  ② 生成「西陵区积极情绪点」点图层
  ③ 图层实际可在地图上查看
  ④ 结论中不出现"（注：未实际生成）"等自相矛盾标记
- **断言**：① 图层已生成 ② 图层类型=点层 ③ 点数量 > 0 ④ 地图上可见
- **标签**：诚实/层引用
- **关联 Bug**：B004（finalStep 假结论）
- **已知失败**：2026-07-29 — 结论称产出 1,247 条，实际未生成图层

### TC-24 多步链完整性 🆕🔴
- **问句**：「将西陵区+伍家岗区范围内商业用地筛选出来。」
- **前提**：行政区面层（含西陵区/伍家岗区）+ 商业用地面层
- **预期**：
  ① Step 1：获取/确认西陵区+伍家岗区合并范围
  ② Step 2：用合并范围 clip 商业用地面层
  ③ 所有步骤执行完毕后才出结论
  ④ 生成的图层含西陵区+伍家岗区两区的商业用地
- **断言**：① plans[] 中所有步骤均已执行 ② finalStep 仅描述已完成步骤的结果 ③ 有最终图层产出
- **标签**：多步链/诚实
- **关联 Bug**：B005（多步操作只做一半）
- **已知失败**：2026-07-29 — Step 1 产出范围，Step 2 未执行，finalStep 出具完整假结论

### TC-25 全极性操作 + 样式继承 🆕🎨🟡
- **问句**：「能帮我筛选出西陵区的情绪点吗？」
- **前提**：积极/中性/消极三个独立情绪点层 + 西陵区边界
- **预期**：
  ① LLM 理解"情绪点"= 全部三个极性（非仅积极）
  ② 合并三个极性后裁剪，或分别裁剪
  ③ 生成的图层**自动继承源图层的图例样式**（颜色/大小/透明度）
  ④ 如果无法一步完成全部极性，诚实告知并给用户选择
- **断言**：① 产出覆盖三个极性 ② 图层样式与标准图例一致 ③ 不自行缩窄用户意图
- **标签**：层引用/UI/诚实
- **关联 Bug**：B006（意图缩窄 + 样式不匹配）
- **已知失败**：2026-07-29 — 仅筛选积极情绪点，且图层未匹配标准图例样式

### TC-26 图层类型一致性 🆕🟡
- **问句**：「筛选出西陵区中的商业用地。」
- **前提**：西陵区边界（面层）+ 商业用地面层（面层）
- **预期**：
  ① clip 引用正确的图层（商业用地面层，非情绪点层）
  ② 生成的图层类型与源图层一致（面层 → 面层）
  ③ 结论中描述的图层类型与实际产出一致
- **断言**：① 产出图层类型 = polygon ② 图层名为商业用地图层 ③ 结论与实际类型一致
- **标签**：层引用/诚实
- **关联 Bug**：B007（图层类型混乱）
- **已知失败**：2026-07-29 — 结论文本称"面层"，实际产出为"点层"

### TC-27 网格聚合视角适配 🆕🎨
- **问句**：「对当前区域做 500m 方格网聚合」
- **前提**：情绪点数据已加载 + 地图支持 2D/3D 视角切换
- **预期**：
  ① 2D 视角下 → 生成 2D 网格图（色块填充，平面展示）
  ② 3D 视角下 → 生成 3D 柱体图（挤出高度，立体展示）
  ③ 视角切换后重新触发聚合时，输出自动匹配当前视角
- **断言**：① 2D 视角产出 fill 图层 ② 3D 视角产出 fill-extrusion 图层 ③ 两者样式配置独立
- **标签**：UI/参数
- **关联 Bug**：B008（网格聚合 2D/3D 视角未解耦）
- **已知失败**：多次 — 无论 2D/3D 视角，始终生成 3D 柱状图
